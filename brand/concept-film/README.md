# 汤崎 · 品牌概念片《动静之间》

72 秒，横版 1920×1080 与竖版 1080×1920 各一条，30 帧 / 秒，带原创配乐。画面全部由代码按品牌书的图形、色彩与字体规范画出来，没有用照片、现成的视频或音乐素材。

> **两份品牌书各管什么**（店主 2026-11-11）：《汤崎品牌书》是内部规格（标志、色彩、字体、图形怎么做）；《TANGQI Branding & VI Strategy》（系综文化事务所，2026-03）是对外宣传用的（定位、口号、影像与版式方向）。概念片是对外的片子，说什么、怎么排照 Strategy；标志与图形的画法照品牌书。

## 讲的是什么

一句话：**城市的节拍慢下来，是山与水；山与水，就是「汤崎」。**

「汤」的偏旁是水，「崎」的偏旁是山；标志的三横三竖是这一山一水；三横三竖又拼成五幅图景。片子把这条线从头走一遍，再把五幅图景排成到店的半日，最后落到口号上。

| 时间 | 场 | 画面 | 字 | 出处 |
| --- | --- | --- | --- | --- |
| 0–8 秒 | 城市节奏 | 一排竖条像城市的节拍一样急促地跳；一句话响起，节拍慢下来，竖条落定成高低错落的山，下面浮出长短不一的横线 | 今天就先到这里吧，接下来，先放松一下。／ 山是层次 · 水为间奏 | 品牌书「颜色系统」里那句友人的召唤；「层次 & 间奏」两页的竖条与横线 |
| 8–16 秒 | 提取山水 | 宋体的「汤」「崎」，偏旁依次亮起；其余笔画退去，偏旁化成品牌的三横、三竖 | FLOW 流动 ／ ROOTED 根深 ／ 三横 · 横流为水 ／ 三竖 · 矗立为山 | 品牌书「起源山水」；Strategy「品牌世界观」 |
| 16–24 秒 | 标志成形 | 两组笔画合成图形标，水面上有倒影 | 矗立为山　横流为水 ／ 三横三竖，一幅极简符号展开的山水图境 | 品牌书「图形标志」 |
| 24–44 秒 | 五种景象 | 五幅图景一层层盖上来，每幅 4 秒，笔画各有各的动法（水波荡、洞口呼吸、竹子摆、叶片抖、小舟行） | 14:00 入汤 · 16:00 疗愈 · 18:30 烟火 · 21:00 欢聚 · 23:30 停泊，各配一句话 | 品牌书「衍生」五幅图景的原稿；Strategy「新旅形式」里的半日闲 |
| 44–56 秒 | 品牌文字 | 深褐底，一段话一行行浮出来；随后 ALIVE / AMUSE / AWAKE 三个词 | 在动与静之间，在松弛与活力之间。一处身体停泊的所在，一座城市闲暇时光的入口。让每一次到访，都成为日常之外的小小旅程。 | Strategy「品牌文字方向」（略有删减）与 A³ |
| 56–64 秒 | 口号 | 三个词缩成上方一排，三行口号依次升起，五种景象的五个颜色连成一条线；下方左边字标、右边图形标 | YOUR NEXT ／ URBAN PLEASURE ／ 都市新旅生活目的地 | Strategy 品牌屋与字体应用页 |
| 64–72 秒 | 落版 | 竖排字标：三横流出来，山立起来，其余笔画显出来 | 都市新旅生活目的地 ／ YOUR NEXT URBAN PLEASURE | Strategy 调整后的主标志 |

五种景象配的五句话是这次新写的（品牌书里只有图景的名字）：把自己交给一池温热 ／ 筋骨松开，呼吸慢下来 ／ 一餐手作的人间烟火 ／ 和朋友把夜晚玩尽兴 ／ 今晚不赶路，就停在这里。「入汤、疗愈、烟火、欢聚、停泊」与五个时刻也是新排的，对应门店实际有的泡汤、按摩、餐饮、娱乐、休憩。**要改字，改 `film/scenes/landscapes.js` 开头的 `LANDS` 再渲染一遍就行。**

## 照着品牌规范做的地方

- **标志**：路径从两份 PDF 里原样取出，没有重画。落版用 2026 年调整后的竖排字标（方形比例）；图形标与字标分开用，没有拼在一起；全片不出现 TOUCHILL（Strategy：「汤崎」与 TOUCHILL 不同时并用）。
- **图形**：五种景象的笔画与底色是品牌书的原稿，只加了动作；上面那层麻布纹照品牌书的做法。品牌书那几页里的照片（竹子、小舟、蕨叶等）没有用。
- **色彩**：深褐取自 Strategy 的规范封面与章节页；麻色、木色取自品牌书的六个主色。
- **字体**：中文用鸿蒙黑体（HarmonyOS Sans SC），口号三行左对齐、行距收紧，上方一排 ALIVE AMUSE AWAKE，都照 Strategy 的字体应用页。拉丁字母见下面「授权」。
- **影像**：暖色、低对比、柔光，带一点颗粒与虚焦（Strategy「影像风格」的调整方向）；文字少，把情绪留给画面。

## 素材与授权

片子要能商用，所以每一样东西的来路都写在这里。

| 东西 | 来路 | 能不能商用 |
| --- | --- | --- |
| 标志、五种景象、色彩 | 店主提供的两份品牌书 | 品牌自己的资产 |
| 中文字体 HarmonyOS Sans SC | 华为官网下载 | 许可写明：用它做出的作品可以自由发布、销售；字体文件本身不得单独再分发、不得修改。所以字体文件不进仓库，渲染前用脚本下载 |
| 拉丁字体 TeX Gyre Heros | GUST 官网下载 | GUST Font License，可自由使用。**品牌规定的是 Helvetica，Helvetica 要另买授权**；这里用的是它的开源同形字体，字形几乎一样。门店有 Helvetica 授权的话，把 `fonts/heros-*.otf` 换掉再渲染 |
| 宋体「汤 崎 山 水」四个字 | Noto Serif SC（思源宋体） | SIL OFL 1.1，可商用 |
| 配乐与声音 | `audio/score.py` 用 numpy 合成 | 原创，没有用任何现成的音乐、采样或音效 |
| 照片、视频、人像 | 没有用 | — |

这是按各家许可的原文整理的，不是法律意见；投放付费广告、平台要版权证明时，以许可原文为准（字体许可在 `fonts/HarmonyOS_Sans_LICENSE.txt`，下载字体时一起取下来）。

## 配乐

60 拍 / 分钟，一小节 4 秒，和画面的场次对齐；D 调五声，音色只有垫底的长音、拨片、木头的「笃」、水滴、颂钵、很轻的鼓与沙锤。开头的「城市」是密集的滴答声，随着那句话慢下来。响度调到 -14 LUFS，峰值留 1 dB。

**配乐是程序写的，开发会话听不到声音，只看过频谱、波形、各频段的能量与响度（音色偏暖、偏柔）。请先听一遍。** 不合适的话换音乐很容易，画面不用重新渲染：

```bash
node tools/set-audio.mjs out/tangqi-concept-film-16x9-1080p.mp4 <你的音乐.wav>   # 几秒钟，响度自动调到 -14 LUFS
```

画面的节点都在 4 秒的整数倍上（8、16、24、28、32、36、40、44、56、64 秒），60 或 120 拍 / 分钟的曲子直接能对上。

## 自己渲染

```bash
./tools/fetch-fonts.sh                       # 下载字体到 fonts/（约 33 MB，不进仓库）
pip install numpy scipy && python3 audio/score.py   # 合成配乐到 audio/score.wav
node tools/render.mjs --size 1920x1080 --out out/tangqi-concept-film-16x9-1080p.mp4
node tools/render.mjs --size 1080x1920 --out out/tangqi-concept-film-9x16-1080p.mp4
```

要有 Node 22、ffmpeg 与 Playwright 的 Chromium（仓库根目录 `npm ci`，再 `npx playwright install chromium`）。一条约 5 分钟。别的尺寸直接改 `--size`（比如 `3840x2160`），版式按横竖自动排。

- `--cta "深圳 · 福田口岸 ｜ 小程序搜「汤崎」"`：落版下面加一行门店或活动信息（默认不加）。
- `--from 24 --to 44`：只渲染一段；`--no-audio` 出无声的。
- 静帧与封面：`node tools/still.mjs --times 26.5,62 --format jpg --out out/covers`。
- 预览：在这个目录起一个静态服务（比如 `python3 -m http.server`），浏览器打开 `film/index.html`，空格播放、拖时间轴。

## 没做的

- **实拍**：没有门店的实拍素材，全片是图形动画。要拍实景版的话，五种景象那 20 秒正好换成五段实拍（泡汤、按摩、餐饮、娱乐、休憩），其余的图形、口号与落版照用；拍法照 Strategy「影像风格」的调整方向。
- **旁白**：没有配音，靠字幕与音乐（短视频多数是静音看的）。
- **4K**：没出，渲染时把 `--size` 改成 `3840x2160` 就行，约 20 分钟。
