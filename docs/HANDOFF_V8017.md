# v8.0.17 交接说明 · 后台架构重新整理（第一步：后台的一级分组与二级页签）

店主 2026-11-13：「对整个后台系统的架构进行重新整理……规则和规则不在一起，配置和配置不在一起，前台和后台混乱，erp 有一些非 erp 的功能……没有类似一级页二级页，很多东西都一股脑放在一起没有收纳。」方案见 `docs/IA_V8017.md`，分三步；**这一版是第一步：管理后台**。默认规则 IA1–IA8 在 `docs/PENDING_DECISIONS.md`「8.0.17」（待确认）。

只动「东西放在哪、怎么进去」。**没有迁移、不改接口、不改业务规则、不改权限**。

## 1. 范围

| 哪里 | 改了什么 |
| --- | --- |
| 一级分组（`src/shared/admin.ts` 的 `ADMIN_GROUPS`） | 侧栏、窄屏的横排、后台首页的分区卡片都按同一份分组排：概览、规则中心、会员与营销、营业项目、场地设备与线上、人员与权限、数据与审计。原来分组写在侧栏组件里，「设备」漏了，侧栏一直没有它 |
| 改名（地址不变） | 「经营规则」→「门店基本规则」；「会员与渠道」→「渠道与标签」；「券与会员权益」→「券」；「期初导入」→「期初与旧账」。页面上指路的话（「在后台 → 经营规则里改」之类）一起改了 |
| 二级页签部件（`src/client/components/SubNav.tsx`，新） | 页面标题下面一排页签，写进地址 `<分区>/<页签>`；不带页签的地址是第一个页签，不认识的页签回到第一个；换页签不卸掉别的页签里的内容 |

| 后台外壳 | 换分区才重新挂载页面（原来地址一变就重新挂载）：分区里换页签，别的页签里填到一半的还在 |

## 2. 要知道的变化（给用后台的同事）

1. **第一个页签变了的两页**：
   - 「券」打开先看到的是「发券规则」（原来是「券模板」）。
   - 「电子菜单」打开先看到的是「设置」（原来是「分类与版面」）。
   - 顺序统一成「规则 → 清单 → 导入与工具」。
2. **原来一页往下翻的，现在要点页签**：比如技师名册在「技师 → 技师名册」，桌台在「餐饮 → 桌台」，交班方式在「门店基本规则 → 交班方式」。
3. **旧地址、旧书签都能用**；分区的地址没有变。

## 4. 验收要点

1. 侧栏 7 个分组，「设备」在「场地、设备与线上」里；后台首页的分区卡片是同样的分组。
2. 任选三个拆了页签的分区：点页签地址跟着变；刷新仍在这个页签；浏览器后退回到上一个页签；手打一个不存在的页签回到第一个。
3. 门店基本规则：在「基本与收款」改一项不保存，切到「可调的数值」再切回来，改的还在；换到别的分区再回来，没保存的不留。
4. 各分区原来能做的事都还能做（建技师、加桌台、建房型、导入价目表、登记设备、发券规则……），只是多点一下页签。
5. 窄屏（平板竖屏、手机）：一级分区横排在顶上、二级页签在标题下面，都能横向滑，页面不横向滚动。
6. 权限：值班经理进「手牌与前台」只看得到「手牌池」「建牌与导入」两个页签（没有「前台规则」）；没有某个分区权限的照旧进不去。
7. 回归：全量浏览器用例通过；`check` 全部 ✓（这一版没有碰服务端的业务代码，属于例行确认）。

## 6. 已知的限度

- 页签里的内容是藏起来、不是卸掉：一个分区里所有页签的数据在进分区时一起取（与原来一长页时一样），页签多的分区第一次打开不会更快。
- 电子菜单、券、空间台账这三页换页签时仍是卸掉重画（它们原来就是这样）；其余 8 个分区换页签不卸掉。
- 「可调的数值」「库存与采购」里属于 ERP 的规则暂时还在后台，下一步挪走。
