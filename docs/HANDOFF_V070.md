# v0.7.0 交接说明 · S6 技师第一步：技师名册、挂项目时选技师、技师业绩

ROADMAP 第 10 节 S6 的第一步。**技师功能默认关闭**：升级后不开启时，前台挂账、结账、交班、日结、对账包的金额与升级前完全一样（对账包多一个技师表，内容为空）。开启后，挂「需要技师」的项目要选技师与点钟 / 轮钟，多档项目按技师等级取价——这会影响前台挂账的金额，按 T0 验收；店主决定在门店开启前，建议在测试服演示库按第 5 节走一遍。钟房看板、轮钟排队、上下钟计时与提成是第二步（G6），本版没有。

## 1. 范围

| 项 | 内容 |
| --- | --- |
| 后台「技师」 | 新分区：技师规则（只有店主能改）、技师名册（新权限「维护技师名册」，默认店主、店总）、需要技师的项目（能管理价目的岗位，按分类勾选）；规则总表新增「技师」一组 |
| 价目与套餐 | 项目编辑里加「需要技师」；旧页面不带这一项时保持原值，导入价目表不改它 |
| 前台挂账 | 加项目时需要技师的项目先选技师与点钟 / 轮钟（按性别筛选，显示等级、按等级的价格、今日钟数；不能做的灰掉写明原因）；同一项目可以分给不同技师 |
| 显示 | 账单明细（「技师服务」一组）、作废明细、来访记录、80mm 结账单、对账包异常清单写明「08 号 小李 · 点钟」 |
| 技师业绩 | 看板新页（新权限「看技师业绩」，默认店主、店总、值班经理）：任选时段每位技师的钟数、点钟 / 轮钟、金额，未指定技师单列；每日对账包新增 `06-技师业绩.csv` |

## 2. 迁移与数据

- 迁移 `020_technicians.sql`：新表 `technicians`；`service_items.technician_required`（默认否）；`bill_lines.technician_id`、`call_type`（二者同空同非空）。只加不改：已有项目都不需要技师，已有明细没有技师。
- 重建明细保护触发器 `yuzu_bill_line_guard()`：唯一允许的变化仍是「有效 → 已作废」；不可改的字段补上 009 之后加的价格档、票种、门票段数，以及新加的技师与上钟方式。
- 新设置项 `technician_rules` 有代码默认值，迁移不写入。
- 演示数据没有改（`src/server/seed*.ts` 归测试会话）：演示库里没有技师，所有项目都不需要技师。E2E 用例自己建一个专用项目「E2E 技师足疗」和技师 `E8`，结束时关闭技师功能。需要演示技师时测试会话可以补到演示数据里（建议另起固定预期）。
- 对账包的文件清单多了 `06-技师业绩.csv`：按文件名读取的脚本不受影响，按文件个数核对的要改成 7 个。

## 4. 验收要点

| # | 操作 | 预期 |
| --- | --- | --- |
| T1 | 升级后不开启技师功能，照常接待、挂账、结账、反结账、交班、日结 | 与 v0.6.0 一致；加项目对话框没有「选技师」；对账包 `06-技师业绩.csv` 只有表头、合计 0 |
| T2 | 店主在后台「技师」建技师（工号 08，专业），勾选「足疗」类需要技师，开启技师功能 | 名册显示「专业技师」；规则总表「技师功能」显示开启并写明谁改的；操作审计有「保存技师」「调整需要技师的项目」「修改规则」 |
| T3 | 店总、值班经理、店员分别打开后台「技师」 | 店总能建技师、勾项目，规则只读；值班经理、店员进不了（403）；店总调 `PUT /api/admin/technicians/rules` 403 |
| T4 | 店员给手牌加一个三档价格的足疗：先选技师 08（点钟） | 价格按专业档；账单在「技师服务」下写「08 号 … · 点钟」；不选技师直接提交被拒（`TECHNICIAN_REQUIRED`） |
| T5 | 技师停用、只做「理疗」的技师、没有优选档价格的项目选优选技师 | 前台灰掉写明原因；直接调接口被拒（`TECHNICIAN_UNAVAILABLE`）；不需要技师的项目带技师被拒（`TECHNICIAN_NOT_NEEDED`） |
| T6 | 页面按标准档提交、技师是专业（价格跟等级开启时） | 拒绝（`TECHNICIAN_TIER`）；后台改了技师等级后用旧页面提交：`PRICE_CHANGED` 或 `TECHNICIAN_TIER`，不会按错价挂上 |
| T7 | 同一操作编号重提；同一编号换技师重提 | 重提返回同一结果、不重复挂；换技师 409 `IDEMPOTENCY_CONFLICT` |
| T8 | 结账、反结账后看「技师业绩」（今天） | 结账后计入；反结账冲回；在店未结的不算；合计 = 各行之和；某一分类全是需要技师的项目、且都在开启技师功能后挂的时，这一类的技师业绩金额 + 未指定 = 经营总览部门构成里这一类的金额（同一口径） |
| T9 | 打印结账单 | 技师项目下面一行写「技师 08 号 … · 点钟」 |
| T10 | 关闭技师功能 | 前台不再选技师，需要技师的项目照常挂（记在「门票与洗浴项目」）；带技师的请求被拒（`TECHNICIAN_DISABLED`）；已挂的技师明细照常显示 |
| T11 | 手机（393 宽）与 1280×720 打开后台「技师」、看板「技师业绩」、加项目对话框的选技师 | 不横向滚动，表格在卡片内滚动 |
