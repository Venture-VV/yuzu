# v0.7.21 交接说明 · 初期开发收口：RQ-001 硬件连接接口 v0.1、测试缺口、上线评测说明

店主 2026-11-03 合并 v0.7.20 后定：**这一版把排期上剩下的任务全部收口，初期开发到此结束，准备上线让大家评测**。排期上剩下的开发只有飞书需求 **RQ-001 硬件连接接口**（P2，D12 排最后），这一版做完；同版补齐测试报告里列的浏览器用例缺口，写上线评测说明 `docs/EVALUATION.md`。迁移 **`038_devices.sql`**。设计（定稿）见 `docs/HARDWARE.md`；默认做法（待确认）见 `docs/PENDING_DECISIONS.md`「硬件连接」。不涉及收款口径（不动钱包、结账、日结），按普通候选版本验收；版本号仍按最后一位加（1.0.0 留给正式切换）。

- **阻断项**：
  - 设备登记、打印任务、设备事件写进了试用库或正式库之外不该写的地方，或按采购清单导入在门店库里没经店主同意就 `--apply`（与其他真实门店数据导入一样）。
  - 同一操作编号打出两张（测试打印重提、没收到结果再点）；确认作废后原请求又打出来。
  - 发到一半断开的打印任务被自动重发；发完后打印机复位连接或没确认收完的被当成「已打出」；设备离线时提交的任务被攒着、恢复后又打出来（这一版不做断网打印队列）。
  - 停用、修改设备后，这台排着还没发的任务还发了出去，或改投到新地址；探测期间改了设置，旧地址的心跳结果覆盖了新设置的状态。
  - 越权：没有「测试打印」的人能发打印任务；没有「维护设备」的人能登记、修改、停用、导入；没有「看设备状态」的人能看设备页或替终端上报。
  - 拔线后页面超过 10 秒还显示在线；插回后不自动恢复。
  - 升级后原有数据变了，或 `check` 在升级后的库上不全 ✓；原有页面（尤其是门店主导航多了「设备」之后的矮屏、手机导航）不能用。
  - 演示数据命令在试用、正式环境写入了数据（与之前相同）。
