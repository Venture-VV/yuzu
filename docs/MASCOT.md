# 看板娘「柚子」· Q 版设定（初稿，待店主确认）

> 店主 2026-11-06：系统叫浴族（yuzu），总被 AI 认成「柚子」，干脆做一个自己的看板娘，就叫柚子；先出 Q 版，要生动活泼，人设参考品牌设计。

## 人设

- **身份**：浴族汤泉的看板娘，兼柚子饭堂的饭堂代言人。
- **生日**：冬至（泡柚子汤、吃顿热乎饭的日子）。
- **性格**：元气、爱泡汤、能吃，有点小迷糊。口头禅「泡一下就好啦～」「开饭啦！」。
- **搭档柚柚**：原来柚子饭堂的柚子吉祥物（`src/canteen-app/Mascot.tsx`），现在坐在她头顶的汤巾上。

## 造型与配色（只用已有品牌色，见 `docs/DESIGN.md`、`docs/MINIPROGRAM.md` 第 13 节）

| 部位 | 做法 | 颜色 |
| --- | --- | --- |
| 头顶 | 叠好的白汤巾，两道松林绿条纹；柚柚坐在上面 | 白、`#24493A`、`#F2C230` |
| 头发 | 栗木色短发、一根呆毛，右侧柚子切片发夹 | `#7A5638` / 暗部 `#5A3D27`，取汤崎木色一系 |
| 眼睛 | 琥珀到柚黄的渐变 | `#5A3418` → `#F2C230` |
| 衣服 | 米白麻浴衣，松林绿领口与腰带，柚黄绳结 | `#FBF8F1`、`#24493A`、`#F2C230` |
| 手里 | 小木桶（漂着柚子）/ 饭碗；木屐 | 汤崎木色阶 `#937051`–`#D2B993` |

表情五个，与现有 `Mood` 一致：开心 `happy`、好吃 `yum`、困了 `sleepy`、哎呀 `oops`、眨眼 `wink`；待机动作（上下轻晃、眨眼、热气、柚柚摇）在「减少动态效果」下停。

## 文件

- `docs/mascot/yuzu-mascot.cjs`：唯一的画法源码（纯 SVG，`yuzuSVG({ mood, pose })`）。
- `docs/mascot/export.mjs`：`node docs/mascot/export.mjs` 导出 `yuzu-*.svg`。
- `docs/mascot/yuzu-sheet.html`：设定稿页面（浏览器直接打开）。

## 用在哪儿

只在有温度的地方：登录页、空状态、成功 / 出错提示、柚子饭堂；收银、对账等工作区不放。表情跟结果走，同时保留文字说明。
