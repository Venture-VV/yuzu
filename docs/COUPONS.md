## 1. 券模板

| 项 | 做法（待确认） |
| --- | --- |
| 代金券 | 面额 ¥X，满 ¥Y 可用（Y 为 0 不限）。抵扣 = 面额与适用金额取小的，不找零 |
| 折扣券 | 几折（1 折到 9.9 折，按百分比存，88 = 8.8 折），可设「最多减 ¥Z」，也可以设门槛。抵扣 = 适用金额 ×（1 − 折扣），算到分、分以下舍去，不超过 Z |
| 兑换券 | 指定一个价目项目或一个票种，抵扣账单上这个项目（票种）的一份：单价最高的那一份（门票是一位客人的门票金额，含跳档）；可设「最多抵 ¥Z」（例如只抵 12 小时档） |
| 适用范围 | 代金券、折扣券：整单，或指定部门（门票、客房、价目表的分类、其他），或指定价目项目。门槛与抵扣都只按适用的明细算；储值充值、押金不是账单明细，本来就用不了券 |
| 有效期 | 按营业日：固定起止日期，或「发券后 N 天」（发券当天算第 1 天）。过了最后一个营业日自动失效 |
| 限定发放等级 | 可选（第 1–5 级里选几级）；限定了的模板只发给这些等级的会员，发出去以后等级变了照样能用；无记名券不能用限定等级的模板 |
| 改与停用 | 发过券的模板，面额、折扣、门槛、范围、有效期都不能改（只能改名称、备注、停用），要改另建模板——已发的券始终按发券时的条件算。停用后不能再发（自动规则也跳过），已发的照常可用 |

## 2. 发券

| 方式 | 做法（待确认） |
| --- | --- |
| 手动发 | 会员详情 →「发券」：选模板、张数（1–10）、写原因。客户经理、值班经理及以上（新权限「发券给会员」）。带操作编号，断网重试不会重复发 |
| 充值赠券 | 后台「发券规则」给充值套餐挂券（模板、张数）；用这个套餐充值时在同一事务里发，与赠金并存。充值页选套餐时显示「另赠：……」 |
| 开卡礼 | 会员建档时发（期初导入的会员不发） |
| 升级礼 | 某次充值让会员等级升高时，发新达到的每一级的升级礼；每位会员每条规则只发一次（余额口径下等级降了再升不再发）；期初导入不发 |
| 生日礼 | 会员生日当月发：定时任务（每 10 分钟）检查，每位会员每条规则每年一次；当月才建档或才补填生日的也补发；没填生日的不发。按发券时的等级选规则 |
| 发券规则 | 一条规则 = 种类（开卡礼 / 升级礼 / 生日礼 / 充值赠券）+ 等级（升级礼、生日礼）或充值套餐（充值赠券）+ 模板 + 张数；同一等级可以配几条。规则不能改，只能停用后另加（以入账时的规则为准） |
| 无记名纸质券 | 后台按模板生成一批券码（1–500 张），导出券码清单交印刷；结账时输入券码使用，一码一次；可以按批次作废还没用的 |
| 券码 | 12 位字母数字（去掉易混的 0、O、1、I），显示成 4-4-4；会员的券也有券码，结账时在列表里选、不用输 |

## 3. 用券（结账）

- 前台结账、桌台结账的收款里加「券」：会员的券在列表里选——本次结账客人里的会员的可用券，显示能抵多少，不能用的写明原因（没到门槛、没有适用的项目、还没生效、已过期）；无记名券输入券码。
- **每张结账单最多 1 张**；不与「优惠 / 免单」同时用；可以与储值、团购、现金等一起收；满足门槛才能用；不找零。
- 会员的券只能用在这位会员在本次结账里的单（与储值同一条规则：同行朋友合并到同一张结账单）。
- 服务端按此刻的明细（含刚算出的门票）重新算抵扣，与员工确认时看到的不一致时拒绝（`COUPON_AMOUNT_CHANGED`），刷新后重新核对。
- **记账**：用券是优惠（营业额减少），不是收款方式；收款明细记一笔「券抵扣」（券、适用的明细）。部门营业额快照：抵扣按适用明细的金额比例分摊（与 v0.7.6 优惠分摊同一算法，最大余数法），记进各项的优惠。
- **加锁**：在结账已有的锁之后——账单 → 会员（储值）→ 赠金批次 → 券（一行）。
- **反结账**：用掉的券退回（过了有效期的，退回后就是已过期）。
- **退款单**：用券的结账单可以按项退款，每项最多退实收（已扣掉分摊的券抵扣），券不退回；要连券一起退请反结账。

## 4. 过期与作废

- **过期**：过了有效期最后一个营业日自动失效，不用人工处理，也不改数据（列表按日期显示「已过期」）。
- **作废**：没用过的券（含已过期的）店主、店总可以作废（新权限「作废券」），写原因；无记名券可以按批次作废还没用的。
- 券的每次变动（发、用、退回、作废）只追加记录，记经办人与原因。

## 5. 统计与对账

- **后台「券与会员权益 → 统计」与「会员总览」看板**：按模板列发券、用券（张数、抵扣金额）、过期、作废，可选日期范围。
- **日结**：「优惠」下单列「券抵扣」，与手工优惠 / 免单分开；净营业额 = 应收 − 优惠 − 券抵扣（− 退款）；实收不含券抵扣。
- **交班表**：单列券抵扣（不是现金）。
- **对账包**：新增 `10-券.csv`：当天发券、用券、退回、作废逐笔（无记名券的券码只显示后 4 位）。
- **自检**：`check` 加「券的状态与变动记录一致」「用券的结账单与券的使用记录一致」；「部门营业额快照与结账单一致」改为快照的优惠 = 优惠 / 免单 + 券抵扣。

## 6. 页面

- **管理后台新分区「券与会员权益」**：券模板、发券规则（开卡礼 / 升级礼 / 生日礼 / 充值赠券）、无记名券（生成、导出券码、作废没用的）、统计。
- **会员详情**：账户内券（可用 / 已用 / 已过期 / 已作废）、发券、作废。
- **充值**：选套餐时显示另赠的券。
- **结账**（手牌、桌台）：收款方式加「券」。
