## 2. v0.7.16 房态图

### 2.1 入口与权限

- 「客房」页加「平面图」视图，与原来的房态看板并列（门店主导航已经满了，1280×720 下不再加入口）。
- 看得到「客房」的岗位都能看（客房入住、客房打扫、收银）；在用底图的只读接口 v0.7.15 已经给这些岗位开了。
- 开房、退房等操作照旧按各自的权限（`room.operate` 等），平面图只是另一个入口，不另开权限。

### 2.2 画什么

- 楼层切换（L1、L2、L3，按在用那一批）；底图是那一层的 SVG，房间是多边形，没配上轮廓的编码画位置点。
- 每个空间按业态与状态着色，图上写编码，放大后写显示名；图例常显，颜色与图例一一对应。
- 筛选：业态（多选）、只看可开的房、搜编码或显示名（定位并闪一下）。
- 缩放平移：滚轮、双指、拖动；「适应屏幕」一键回到整层。底图只加载一次，状态每 5 秒刷新一次（只刷状态，不重画几何）。

### 2.3 状态从哪来

| 业态 | 状态 | 来源 |
| --- | --- | --- |
| 客房（挂接了房间的空间） | 空闲（已打扫）/ 在住 / 待打扫 / 维修 / 停用 | 客房房间与入住单（v0.7.4），与房态看板同一个口径 |
| 客房（没挂接房间） | 未挂接 | 空间台账；提示到「客房 → 房间」挂接 |
| 技师服务类（SPA、按摩、踩背、头疗、足浴、投影足浴） | 空闲 / 服务中（几位技师、剩几分钟）/ 已派钟待上钟 | 钟单：**派钟时选房间**（迁移 `034` 给钟单加「服务的房间」，可空，选台账里在用的技师服务类空间）；一间多人间可以同时有几个钟，显示「2/4」 |
| 其他（派对房、宠物轰趴房、娱乐室……） | 只显示业态，不显示占用 | 目前没有对应的业务单据；以后有了再接 |
| 停用、不可售的空间 | 灰色 | 空间台账 |

### 2.4 点房间

- 客房：侧栏显示房号、房型、打扫状态、在住客人（手牌、入住时间、应退时间、房费与押金）；按状态给按钮：**开房**（空闲已打扫）、**查房 / 续住 / 换房 / 押金**（在住，打开原来的入住单）、**退房**（在住）、打扫 / 维修。全部复用「客房」页现有的对话框与接口，平面图不另写一套。
- 技师服务类：侧栏显示这间房里的钟单（技师、手牌、项目、开始时间、剩余分钟），链到「钟房」。
- 其他：显示空间信息（编码、显示名、业态、容量、面积）。

### 2.5 迁移 `034`

- `technician_sessions` 加「服务的房间」（`space_id`，可空，引用空间）。派钟对话框加「房间」选择（可不选）；已有的钟单为空，不影响提成与对账。
- 自检加一项：钟单记的房间是在用的技师服务类空间。

### 2.6 性能与验收

- 一层的 SVG 底图（v0.7.15 实测 84–208 KB）+ 一层多边形，合成 300 个空间的数据下首屏 2 秒内；浏览器验收在 1440×900、1024×768、820×1180 与 1280×720 下各跑一遍。
- 合成数据：E2E 用 v0.7.15 的样例图纸（`docs/data/floorplan-sample.dxf`）启用后挂接房间；性能用合成的 300 个空间。

## 3. v0.7.17 第一级实时位置（初稿）

### 3.1 数据结构（按二级定位预留）

- **刷卡点登记**：每个读卡器（编号、名称、所在区域或空间、在用），后台维护；16 个 RC300 的位置由现场补。
- **位置事件**（只追加）：谁（客人 = 来访 / 手牌；技师）、在哪（空间或区域、楼层）、怎么知道的（来源：刷卡点、发手牌、消费、点单、开房、退房、上钟、下钟、结账离场……）、哪条业务单据、什么时候；为第二级预留坐标、精度、设备编号几列，现在为空。
- **当前位置**：每个人一行，最新一条事件写进去（当前所在空间 / 区域 / 楼层、时间、来源）；离场后清掉。
- **区域轨迹**：由位置事件按时间排出「进入—离开」段，接口按段返回；第二级来了只是事件更密。
- **上报即定位**：`POST /api/locations/report`（设备桥、以后的 UWB 网关调用）：报「某张卡在某个读卡器 / 某个点」，服务端写事件、更新当前位置。RQ-001 设备桥做好之前用合成数据测试。

### 3.2 业务动作怎么推导位置

| 动作 | 推导 |
| --- | --- |
| 发手牌入场 | 客人在接待区 |
| 刷卡点刷卡 | 客人在那个读卡器所在的区域 |
| 消费入账 | 按消费项目所在的区域（项目或部门对应区域，后台配置；没配的不推导） |
| 餐饮点单 | 客人在桌台所在的区域（桌台挂区域） |
| 客房开房 / 退房 | 客人在那间房 / 离开那间房 |
| 技师上钟 / 下钟 | 技师在钟单记的那间房 / 回到技师休息区（没记房间的只记「服务中」） |
| 结账离场 | 客人不在店，当前位置清掉 |

### 3.3 平面图上

- 区域上显示在场人数，点开看名单（手牌号、进入时间、最近一次动作）；技师显示在房间里。
- 只显示手牌号与技师名，不显示会员姓名、手机号。

## 4. 待确认 / 要现场补的

- 16 个刷卡点各自装在哪个区域、读卡器编号（需求文档只有区域分布）。
- 消费项目（或部门）对应哪个区域，用来推导「客人在哪」。
- 派对房、宠物轰趴房、娱乐室怎么算「在用」：目前没有对应的业务单据。
- 技师下钟后回到哪个区（技师休息区在台账里是哪个区域）。
