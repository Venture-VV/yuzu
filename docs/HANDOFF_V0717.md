# v0.7.17 交接说明 · 飞书需求 RQ-004 第三段（下）：第一级实时位置

店主 2026-11-02 合并 v0.7.16（房态图）后开工。第一级 = 业务推导定位（D17、D24）：不加硬件，由刷卡点刷卡与业务动作推出客人在哪个区、技师在哪间房，精度到区域与房间，位置停在上一次业务动作。表结构按第二级精确定位预留，第二级只换数据源。设计见 `docs/ROOMMAP.md` 第 3 节（定稿）；默认做法（待确认）见 `docs/PENDING_DECISIONS.md`「第一级实时位置」。同版补了 v0.7.15 验收报告提的五项测试缺口（第 5 节）。

- **迁移 `035`**：
  - 新表 `location_readers`（刷卡点：编号唯一、装在区域或空间二选一、版本号、不能删）、`location_events`（位置事件，只追加；第二级预留 `x_mm`、`y_mm`、`accuracy_mm`、`device_id`）、`location_tracks`（轨迹段，每人最多一段没结束，结束了的段不能改）、`current_locations`（当前位置，每人一行）。
  - `service_items` 加 `zone_id`（项目所在区域，可空）。
  - 只加表、加列；升级后开关关着（`location_rules` 没有就按默认：关、不选区域），业务照旧，不产生任何位置数据。
- **阻断项**：
  - 位置推导让业务出错或变慢到超时（发牌、挂账、开房、上下钟、结账任何一步因为位置报错、不生效）。
  - 越权：没有「看实时位置」的岗位能取 `/api/locations/current`、`/tracks`；没有「上报位置」的能上报；后台配置不是店主、店总也能改。
  - 位置接口或页面带出会员姓名、手机号。
  - 离店的客人还在平面图上；同一个操作编号重发记了两条；迟到的刷卡改了当前位置。
  - `check` 不是全 ✓；破坏原有客房、钟房、前台、空间台账、底图、房态图功能。

## 1. 范围

| 项 | 内容 |
| --- | --- |
| 推导 | 发手牌 → 接待区；挂账 → 项目所在区域（几个区域按项目多的，一样多按先挂的；没配的不记）；派钟马上上钟 / 上钟 → 技师与客人在钟单的房间；在钟上换房间 → 一起到新房间；下钟、退钟、结账时一起下钟（只算上了钟的）→ 技师回技师休息区（没设的离开那间房、位置不明）；开房、换房 → 那间房；退房、撤销入住 → 离开那间房（位置不明）；技师上牌 → 休息区（没设的清掉之前的位置）；技师下牌、结账、撤销来访 → 离店。补录不推导；开关关着只清不记 |
| 上报 | `POST /api/locations/report`：`{ opId, source: 'reader' | 'position', readerCode? , tagCode? / technicianNo?, spaceCode? / zoneId?, at?, x?, y?, accuracy?, deviceId? }`；返回 `{ eventId, applied, replayed, current }` |
| 拒绝 | 开关关着 409 `LOCATION_OFF`；手牌没有在店客人 422 `TAG_NOT_IN_STORE`；刷卡点没登记、空间不在台账、技师工号不存在 404；刷卡点停用 422 `READER_INACTIVE`；装的地方停用 422 `PLACE_INACTIVE`；时刻早于 24 小时或晚于服务器 2 分钟 422 `REPORT_TIME`；同一个编号内容不同 409 `OP_KEY_REUSED`；格式不对 400 |

| 接口 | `GET /api/locations/current`、`GET /api/locations/tracks?visitId=` 或 `?technicianId=&date=`（`location.view`）；`POST /api/locations/report`（`location.report`）；`GET /api/admin/locations`、`PUT /api/admin/locations/rules`、`POST /api/admin/locations/readers`、`PUT /api/admin/locations/readers/:id`（`{ …, expectedVersion }`，对不上 409 `READER_STALE`）、`PUT /api/admin/locations/items`（`settings.manage` 或 `catalog.manage`）；`GET /api/floormap` 的空间带 `zoneId` |
| 权限 | 新增「看实时位置」（默认店主、店总、值班经理、收银；后勤、客户经理没有）、「上报位置」（默认店主、店总），后台「岗位权限」可调 |
| 规则总表 | 加「实时位置」一组：开关、接待区与技师休息区（待确认） |
| 自检 | `check` 加三项：当前位置与最后一条位置事件一致、轨迹段与当前位置一致、离店的客人与下了牌的技师没有当前位置（演示库共 49 项） |
