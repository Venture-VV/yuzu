# 合同与法务审查（v0.7.31）

店主 2026-11-05 定了财务、法务审批的分期（`docs/ERP_FINANCE_LEGAL_PLAN.md`），第二期是合同与法务审查（第 4.2 节）。v0.7.31 照这个做：合同台账与四要素、审查流程（业务 → 财务 → 法务 → 负责人，法务按审查清单逐条给意见）、签署与用印登记、归档、采购单挂合同、变更单、到期提醒。审批都走 v0.7.30 的审批中心（`docs/APPROVALS.md`），不另写一套。规则没定的按下面的默认（第 10 节 C1–C12，`docs/PENDING_DECISIONS.md`「合同与法务审查」，待确认）。

## 1. 范围

| 做什么 | 怎么做 |
| --- | --- |
| 合同台账 | ERP「合同」：合同号、类型、相对方、经办、部门、起止日、总价与税率、状态；四要素做成字段（第 2 节）；扫描件按页拍照上传 |
| 审查 | 提交审查走审批中心（单据类型「合同」）：默认 财务 → 法务 → 负责人 三级；法务那一级按审查清单逐条给意见（第 3 节） |
| 签署、用印、归档 | 审批通过后登记签署（签订日、双方签署人）、用印申请（走审批中心，单据类型「用印」）、归档（归档编号、存放位置、扫描件）（第 4 节） |
| 采购单挂合同 | 采购单选合同；单价超过合同价、数量超过合同剩余量时提示，提交时要写原因、审批里看得到（第 5 节） |
| 变更单 | 改价、改量、延期走变更单，同样走审查（单据类型「合同变更」），同意后合同按新内容生效、旧版本留着（第 6 节） |
| 到期提醒 | 结束日前 60 天进待办，没续签的标红（第 7 节） |

不在这一版的：付款计划与付款申请（v0.7.32 付款流按这里的付款节点排期）、发票台账（v0.7.34）、验收标准模板化与不合格挂起付款（v0.7.35）、合同模板库与在线起草（以后再看，先把四要素录准）。

## 2. 合同台账与四要素

- **合同的基本信息**（起草时填，变更单不改）：合同号（自动，`HT` + 日期 + 序号）、类型（采购 / 服务 / 租赁 / 其他，C1）、相对方（采购合同从供应商档案里选；其他类型可以选供应商，也可以只写名称）、经办人（默认起草的人）、部门（可空；审批规则按它匹配）、续签自（续签的新合同指向旧合同）。
- **合同内容**（走审查、走变更单的部分）：标题、签订后生效的起止日（结束日可空 = 长期）、合同总价（含税，整数分）、主要税率、运费与卸货谁承担（供方 / 我方 / 不涉及）、备注，以及四要素：
  1. **单价表**：每行一个物料（从物料档案里选）或一项服务（写名称），规格、单位、含税单价、税率、合同数量（可空 = 不限量）。采购单挂合同时按这张表核对（第 5 节）。
  2. **付款节点**：预付 / 到货 / 验收 / 质保四段，每段的比例（加起来 100%）与触发条件（一句话）。默认模板见 C5；v0.7.32 付款流按它排付款计划。
  3. **质保**：质保金比例、起算依据（验收合格日 / 到货日 / 签订日）、期限（月）。默认见 C6。
  4. **验收标准**：按什么验、谁签字、不合格怎么扣（各一段话）。
- 金额一律整数分；比例存万分比（30% 存 3000），页面上按百分比填。
- **状态**：起草中 → 审查中 → （已退回 → 审查中……）→ 审批通过（待签署）→ 已签署（生效）→ 已归档；另有已终止、已作废。到了结束日还没终止的显示「已到期」（只是显示，不改状态）。
- 起草中、已退回的可以改（带版本号，两人同时改后保存的被拒 `VERSION_CONFLICT`）；审查中的不能改（要改先撤回）；审批通过以后内容不能直接改，改走变更单。
- 起草中、已退回、审批通过（还没签署）的可以作废（写原因）；已签署、已归档的可以终止（写原因与终止日期）。作废、终止都留经办人与原因，不删记录。

## 3. 审查流程（法务）

- 提交审查时把当时的合同内容存成一份「提交记录」（只追加），审批中心开一张审批单（单据类型「合同」，金额 = 合同总价，部门 = 合同的部门）。退回修改后再提交是新的一份提交记录，每一份都留着当时的内容与各级意见（「退回修改留每一版的内容与意见」）。
- **审查链**：按审批规则（单据类型「合同」）；没有规则命中时三级：财务（对账付款、成本核算）→ 法务 → 负责人（C2）。没有规则命中时与审批中心的默认规则一样（A3），起草的人有那一级的职责也能审（小店常常一人多岗，不然会卡住）；要「起草的人不能审自己的合同」就建一条「合同」的审批规则（新建的规则默认提交人不能审自己的单）。
- **法务**：新加的岗位组「法务」= 员工档案里有「法务」职责的人（新加的职责，单独一组、不和别的职责兼任），店主在每一组里（C4）。合同、合同变更的审批规则必须有且只有一级是「法务」，别的单据类型不能用「法务」这一组。
- **审查清单**（C3）：法务那一级同意或退回时逐条给结论——主体资质、标的与规格、价格与税、付款、交付验收、质保售后、违约责任、争议解决、保密、期限与续签——每条「通过 / 要修改 / 风险提示」并可写意见：
  - 同意时每条都要给结论；有「要修改」的不能同意，只能退回；「风险提示」要写意见（至少 2 个字）。
  - 退回时可以只填有问题的几条，退回原因照旧必填。
  - 清单的结论记在这份提交记录上（只追加），后面的审批人与起草的人都看得到；店主或代理人审法务这一级时一样要填。
- 财务、负责人那两级照审批中心的同意 / 退回（意见选填，退回写原因）。最后一级同意后合同变成「审批通过（待签署）」，这一份提交记录就是合同的第 1 版。
- 撤回：审查中的合同经办人可以撤回（审批单一起关掉），回到起草中。

合同详情里的审批对话框按打开时的那一次提交与级别同意、退回：对话框开着时单据撤回重提（或到了别的级别），提示「审批已经变了」、不能按这次填的清单与意见提交，关掉重开、看过新的内容再审（服务端照旧核对审批单与级别，对不上拒绝 `APPROVAL_MOVED`）。

## 4. 签署、用印与归档

- **签署登记**（审批通过以后）：签订日、我方签署人、对方签署人，登记后合同「已签署」（生效）。采购单只能挂已签署、已归档的合同。
- **用印申请**（审批通过以后、归档以前，可以多次）：印章种类（公章 / 合同专用章 / 财务专用章 / 法人章）、份数、用印人、用印日期、用途；提交后走审批中心（单据类型「用印」，金额 = 合同总价）；没有规则命中时一级「店主」（C7）。同意后这条用印登记生效；退回的改了再提交，或撤回。新建的用印申请没收到结果时记在「结果待确认」里，查回、按原内容重新提交或作废之前不能另起一条（Codex 自动审查 315e7f7）。
- **归档**（已签署、至少一条用印登记已生效、至少一张扫描件）：归档编号（自动，`GD` + 日期 + 序号）、存放位置（一句话），归档后合同「已归档」。扫描件随时可以追加（一次可以选多张，逐页上传，中途失败时提示传到第几页）；归档以前可以删掉传错的（留记录），归档以后只能追加（归档后终止的也一样）。扫描件与需求单、采购单的图片分开存（迁移 `079` 图片的「用途」）：只经合同的接口看（要「查看合同」、合同模块开着），通用的图片接口给不出，需求单、采购单的行挂不上。

## 5. 采购单挂合同

- 采购单（新建、修改）可以选一份合同：同一供应商、类型「采购」、已签署或已归档、今天在起止日内（结束日为空不限）（C9）。
- 页面与提交时按合同的单价表逐行核对（同一物料、同一单位）：
  - 单价超过合同价：标出合同价与超出的金额；
  - 数量超过合同剩余量：剩余量 = 合同数量 − 挂这份合同、没撤回的采购单（已提交、待确认、已确认、收货中、已完成，不含草稿与撤回的）已经下的数量；
  - 物料不在单价表里、单位不一样：只提示「合同里没有这一项 / 单位不同」，不算超出。
- 有超出的，提交时要写原因（至少 2 个字，`CONTRACT_DEVIATION_REASON_REQUIRED`）；原因记在采购单上，审批中心的卡片与详情里显示合同号、超出的行与原因。没超出的照常提交。
- 没有合同的零星采购照旧走询价比价（v0.7.29）与免确认门槛，不受影响。

## 6. 变更单

- 已签署、已归档的合同可以开变更单（同一合同同时只有一张没结束的变更单）：变更类型（改价 / 改量 / 延期 / 其他，可多选）、变更原因（至少 2 个字），以及改后的合同内容（在当前版本上改：标题、起止日、总价、税率、运费与卸货、四要素、备注）。
- 提交后走审批中心（单据类型「合同变更」，金额 = 改后与改前总价之差的绝对值，部门 = 合同的部门）；没有规则命中时与合同一样三级（财务 → 法务 → 负责人），法务那一级同样按审查清单逐条给意见（C10）。
- 最后一级同意后合同按新内容生效：版本号加 1，旧版本（含单价表）留着可以查（合同详情「提交记录与审查结论」里每一次提交都能展开当时的内容与单价表），变更单记下改后是第几版。已经挂了这份合同的采购单不动，之后按新的单价表核对。
- 变更单可以撤回（审查中）、作废（起草中、已退回）。开变更单时带上打开页面时合同是第几版，这期间别的变更单先生效了就拒绝（`VERSION_CONFLICT`）；修改合同、修改变更单按打开表单时的版本号保存，别人先存过的提示刷新后再改，不覆盖。
- 合同详情的变更单展开变更后的内容（审查中的默认展开），在合同详情里审变更单的人看得到改了什么；总价按变更前那一版标涨跌（金额字段是给审批规则匹配用的绝对值，另给变更前的总价）。

## 7. 到期提醒

- 已签署、已归档、没终止的合同，结束日在 60 天内（含已经过了结束日的）进待办：ERP「合同」页顶部「到期提醒」一栏，导航「合同」上的数字是没续签的份数（有「维护合同」权限的人看；采购经办不一定能进审批中心，所以不放在审批中心）（C11）。
- 有续签的新合同（「续签自」指向它，且新合同没作废）的显示「续签中」或「已续签」，不标红；没有续签的标红。
- 终止了的、续签的新合同已签署的，不再提醒。

## 8. 权限（C12）

| 权限 | 默认 |
| --- | --- |
| 查看合同（台账、详情、提交记录与审查意见、扫描件；扫描件只经合同的接口给） | 店主、店总；采购、对账付款、成本核算、负责人、法务职责 |
| 维护合同（起草、修改、提交、撤回、作废、终止、签署登记、用印申请、归档、变更单、上传扫描件） | 店主、店总；采购、法务职责 |
| 审批（合同、合同变更、用印） | 审批中心照旧：按审批规则（岗位组或指定的人），要有「审批中心：审批」权限（法务职责默认有） |

部门账号（只有「部门申购」职责的）看不到合同。

## 9. 锁与并发

（实现写进 AGENTS.md「开发约定」的锁顺序。）

- 合同的修改、提交、撤回、作废、终止、签署、归档：先锁合同一行（带版本号，对不上拒绝）→ 审批单一行。
- 审批（同意、退回）：合同（或变更单、用印申请）一行 → 审批单一行，与审批中心的其他单据一样；变更单最后一级同意时：变更单 → 审批单 → 合同一行（写新版本）。
- 用印申请、变更单的新建先锁合同一行（核对状态与「同时只有一张没结束的变更单」，部分唯一索引兜底）。
- 新建合同、变更单、用印申请带操作编号（同一编号重提返回原来那条），接入「结果待确认」（与 ERP 单据一样：查回、按原内容重新提交、确认作废）。
- 采购单挂合同：采购单的保存、提交照旧锁采购单一行，读合同与合同剩余量不加锁；提交时在锁住采购单以后再核对一次。
- 提交记录、审查清单的结论、版本只追加（触发器拦改、删）。
