# v8.0.16 交接说明 · 后台整体 UI 优化：动效套件

店主 2026-11-13：「对整个后台系统的 UI 进行优化，可以参考 github 上 motion harness 这个项目，学习参考，一些好的动效套件内化到我们的项目里。」设计见 `docs/UI_V8016.md`；默认规则 UI3–UI9 在 `docs/PENDING_DECISIONS.md`「8.0.16」。

这一版只做「怎么动、怎么顺」，做在公共部件上，所有页面跟着生效。**没有迁移、不改接口、不加依赖、不挪页面**（收纳与信息架构是 8.0.17）。

## 1. 范围

## 2. 影子是怎么回事（验收时最要看的一处）

弹窗、抽屉、菜单、提示条关掉时：

1. React 照旧**马上**把它卸掉——页面上没有 `role="dialog"` 了，焦点还给原来的按钮，Esc 关哪一层、后面的页面能不能点，都与 8.0.15 一样。
2. 卸掉之前把它的 DOM 复制一份（去掉 id、role、测试标记，输入框停用），放进页面最后面一个**关着的容器**（closed shadow root，`<div data-mo-ghosts>`）里，播 0.18–0.22 秒的退场，0.32 秒后删掉。
3. 关着的容器从外面查不到里面的东西：`document.querySelector`、按文字 / 标签 / 占位字的查找、读屏、浏览器用例都认不到影子。容器上记着两个数：`data-count`（现在有几个影子）、`data-total`（一共留过几个），排查与用例用。
4. 容器里看不到页面的样式表，所以把页面的样式表照抄一份给它（抄一次记住，规则条数没变不再抄；页面打开后空闲时先抄好）。
5. 系统开了「减少动态效果」、或浏览器太老（不支持上面的做法）时不留影子，直接消失，功能照常。

## 4. 验收要点

1. 开、关一个弹窗与一个抽屉：进场、退场都顺；关掉后马上能点后面的页面；紧接着再开一个，新的画在正在退场的影子上面。
2. 弹窗里填了字、滚到一半再关：退场时看到的就是关掉那一刻的样子（字还在、滚动的位置不变）。
3. 提示条从右边进、往右边出；一句很长的提示停得比「已保存」久。
4. 分段开关：白色滑块滑到选中的那格；窗口缩放、换成窄屏以后滑块仍与选中的那格重合。
5. 三处导航：点相邻的分区底块滑过去，点隔得远的直接在新位置淡入；窄屏的横排导航同样。
6. 系统开「减少动态效果」：没有动画、没有影子，功能照常。
7. 后台首页、ERP 首页、数据看板：卡片依次出现只在进页面时播一次；看板换时间范围后数字对、不重复乱闪。
8. 回归：全量浏览器用例照旧通过（这一版没有改任何用例的等待或选择器）。

## 5. 已执行的验证

见本节末尾的数字（以 PR 上最后一次 CI 为准）。

- 本机：`npm run typecheck`、`npm run build` 通过；`tests/motion.test.ts` 6 条（提示条停留时间；时间与曲线的变量都在、套件自己的动画不用匀速；退场不超过 220 毫秒且用退出的曲线、影子留的时间比最慢的退场长；页面上写的每一种退场在样式表里都有；减少动态效果时全关、影子不能点；没有引入动画库）。
- 浏览器（新建的独立演示库、构建产物）：`e2e/motion.spec.ts` 3 条（弹窗关掉马上卸掉、影子按文字和标签都找不到、马上能再开；减少动态效果时不留影子；分段开关与后台导航的滑块跟着当前项）。
- 在动画中途截图看过：弹窗进场 / 退场、提示条、分段开关、导航、依次出现、用户菜单。
- **没做的**：
  - 没有在真的门店电脑、平板上看手感与流畅度（只在无头浏览器里看）；老机器上如果卡，系统里开「减少动态效果」即可全关。
  - 没有在 Safari / 火狐上看（折叠块的高度过渡只在 Chrome / Edge 129 起有，别的浏览器照旧直接展开）。
  - 读屏软件没有实测（影子在关着的容器里并带 `aria-hidden`、`inert`，按规范不会被念到）。

## 6. 已知的限度

- 导航的滑块、分段开关的滑块靠量位置：容器没显示时量不到，退回到「当前项自己带底色」的老样子（功能不受影响）。
- 影子是关掉那一刻的静态副本：里面的视频、画布不会继续动（0.2 秒内看不出来）。
- 提示条最长停 10 秒：比这更长的话请写进页面，不要放提示条里。
