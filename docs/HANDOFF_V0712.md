RQ-002「ERP 多项需求」第二步，补完 Batch 4 已定未做的部分（店主 2026-10-27 定的 #15、#16、#17 后半句、#18、#20、#22、#25；#18 原排期漏了，并入本版）。设计见 `docs/SUPPLIER_SETTLEMENT.md`；默认做法（待确认）见 `docs/PENDING_DECISIONS.md`「供应商结算与库存采购收尾」。

- **迁移 `030`**：退货单加「待供应商确认」与供应商答复几列、`return_applied_cents`（退货抵了原收货单多少）；核销（`ap_offsets` + `ap_offset_lines`）、供应商退款（`supplier_refunds`）两张新表，只追加；应付流水加「供应商退款」类型；费用科目加「运费」；物料加「提醒天数」；导入记录表；设置加免确认门槛、用量统计天数；「确认作废」登记认核销、供应商退款。只加表、加列、加约束；**迁移前已生效的退货照旧算数**，按「付款优先」补记它抵了原收货单多少，不改金额、不改流水。

## 1. 范围

| 项 | 内容 |
| --- | --- |
| 退货待供应商确认（#20） | 退货单提交（不超过门槛）或负责人确认后进「待供应商确认」：库存、货款都不动，内容不能再改；采购经办（新权限「登记供应商对退货的答复」）或店主登记「供应商已同意」（同意日期、对方联系人或说明）才出库、扣款，流水记在同意日期；「供应商不同意」写原因，单据撤回；等待期间登记人、负责人、采购经办可以撤回；超过 7 天在库存工作台标红 |
| 退货余额（#20、#25） | 挂账的退货扣款先抵原收货单还没付、也没在待确认付款里的部分；多出来的是这张退货单的「退货余额」 |
| 预付款（#25） | 付款可以不全部核销：勾选「其余记为预付款」并在备注写明用途，差额记为预付款；付款的预付部分已经核销或退款的，要先冲销那一笔才能冲销付款 |
| 核销 | 预付款、退货余额统称「可抵扣」；对账付款在对账单的「可抵扣」把它核销到同一供应商以后的收货、期初未付；登记即生效，不记应付流水、只改未付 |
| 供应商退款 | 对账付款登记（日期、方式、凭据）；挂账的记应付流水「供应商退款」（正数）；现付供应商的退货不记应付，整笔等供应商退款（关联退货单，不记应付） |
| 冲销 | 核销、供应商退款按财务单据：当月、对账付款或成本核算；收货单有核销时、退货单的余额已核销或退款时不能冲销，要先冲销那一笔 |
| 运费（#15） | 费用科目加「运费」；报销按采购单时可以单独加一行运费（不对应物料、不进物料成本），台账单列 |
| 可用天数（#22） | 物料档案加「提醒天数」（1–90，可空）；按近 28 天（规则总表可调 7–90）这个仓的用量算日均用量与可用天数，少于提醒天数时提醒（总仓在库存工作台、部门小仓在「本部门小仓」）；没设或没有用量的仍按固定提醒数量 |
| 批量导入（#16） | ERP「应付货款 → 导入」：下载模板 → 选 CSV（自动识别 UTF-8 / GBK）或 Excel（第一张工作表）→ 预览逐行校验 → 写入；有错误的整份不写；编码已存在的供应商不覆盖；同一个文件（按内容摘要）只能写入一次；导入的期初未付按「期初」规则走确认，超过门槛的负责人可以一次确认整批 |
| 分岗不兼任（#17 后半句） | 五组：仓库（物资经办）、采购（采购经办）、部门（部门申购）、财务（对账付款、成本核算可以同时有）、负责人（确认）；后台保存员工时跨组拒绝（`DUTY_CONFLICT`，店主与停用的员工不查）；已有跨组的员工后台员工页标出来提示 |
| 免确认门槛（#18） | 后台「规则总表 → 库存与采购」加「免确认门槛」（默认 ¥2,000.00）：采购单、报损、退供应商、付款、期初未付、期初库存在勾选「需要负责人确认」时，金额不超过门槛的提交即生效；报损、期初库存按参考价估算，有一行没有参考价的照旧要确认；总仓盘点调整照旧要确认 |
| 页面 | 应付货款页：「核销与退款」视图、供应商表的已退款与可抵扣两列、对账单的可抵扣与核销 / 退款记录、导入入口；付款登记页的预付款；库存单据详情的供应商答复与退货余额；物料档案的提醒天数；库存与本部门小仓的可用天数；报销登记的运费行；后台员工页的跨组提示；规则总表的门槛与统计天数 |
