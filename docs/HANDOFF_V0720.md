# v0.7.20 交接说明 · 收银完善：退款单与券、会员权益（飞书 RQ-006）

店主 2026-11-02 合并 v0.7.19 后开工：飞书需求 RQ-006（收银完善）一版做完——离店后按项**部分退款**（退款单），与按常用营销规则搭的**券与会员权益**（券模板、发券、无记名券、结账用券）。RQ-001（硬件）排在最后。迁移 **`037_refunds_coupons.sql`**。设计（定稿）见 `docs/CASHIER.md` 第 3 节、`docs/COUPONS.md`；默认做法（待确认）见 `docs/PENDING_DECISIONS.md`「收银完善」「券与会员权益」。涉及收款口径，按资金候选版本验收（快速开发周期：CI 全绿后店主合并，验收在 main 的版本标签上补做）。

- **阻断项**：
  - 退款记错账：退款单的金额 ≠ 退的项目合计 ≠ 退款方式合计；同一项累计退超过份数或实收、同一种方式累计退超过原单这种方式收的钱；退了会员储值、团购券、优惠或券抵扣；反结账过的结账单还有生效的退款单，或有生效退款单的结账单还能反结账（`check`「退款单与结账单一致」不 ✓）。
  - 退款的现金没记进交班表（应有现金没减），或作废后还在算；日结、部门营业额、看板、ERP 营业数据、对账包里的退款对不上；交班后、过了营业日还能作废退款单。
  - 券记错账：一张券用了两次；用券的结账单与券的使用记录对不上；反结账后券没退回；券抵扣算进了实收或收款方式；超过门槛、范围、有效期、归属规则照样用了；与优惠 / 免单同时用了，或一张结账单用了两张券（`check`「券与使用记录、结账收款一致」不 ✓）。
  - 断网时退款、发券、生成无记名券重复生效，或确认作废后原请求又生效；同一位会员同一条规则（升级礼、生日礼、开卡礼、充值赠券）发了两次。
  - 越权：没有「开退款单」的人能开或作废退款单；超过撤销时限（默认 48 小时）不是店主也能开；没有「维护券模板」「发券给会员」「作废券」的人能做对应的事。
  - 发过券的模板改了面额、折扣、门槛、范围、有效期（已发的券应始终按发券时的条件算）。
  - 升级后原有数据变了，或原有的结账单、部门快照、交班表、日结金额变了；`check` 在升级后的库上不全 ✓。
  - 演示数据命令在试用、正式环境写入了数据（与之前相同）。
