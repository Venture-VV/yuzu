# v0.7.7 交接说明 · 飞书需求 RQ-005 第一步：费用报销与备用金每日平账（资金候选版本）

店主 2026-10-31 定：门店同事的需求从店主的飞书文档来，按文档的优先级排期（ROADMAP 第 10 节第 9 项）。RQ-005「采购与费用闭环」是 P0，分三版，这一版做费用报销与备用金每日平账，让 11 月起的新账（D9）能记进系统。设计见 `docs/EXPENSES.md`；默认规则（待确认）见 `docs/PENDING_DECISIONS.md`「费用报销与备用金」。

- **迁移 `026_expenses.sql`**：新职责「成本核算」；供应商的结算方式（挂账 / 现付），收货与退货记下确认时的结算方式；备用金打款、退回 / 补付、费用报销三种单据（内容不可改、只能撤回或冲销，数据库触发器兜底）。已生效的收货与退货补记「挂账」，与原来的做法一致，不改其他已有数据。
- **资金候选**：现付供应商的收货不再记应付；报销与备用金是新的资金台账。账错（平账算错、应付多记或少记）、越权（不该登记的人能登记、确认）、破坏库存 / 采购 / 应付货款原有流程是阻断项。

## 1. 范围

| 项 | 内容 |
| --- | --- |
| 费用报销 | ERP「费用与备用金 → 费用报销」：按次报销，或按现付供应商的采购单报销；用途、发票类型与税点、费用科目都是固定选项并互校；有发票必须填发票号；购买与到货数量不一致要写原因；单笔超 2000 元（D13，可调）要负责人确认，进「审批待办」 |
| 备用金 | 「备用金与每日平账」：登记打款（按部门、经办人留名）；每笔打款单独平账，登记退回或补付；超 7 天（可调）没平标「超期未退」；每日平账按付款日与部门汇总，可导出 |
| 现付供应商 | 供应商档案加「结算方式」；现付的收货不记应付、不能在「应付货款」里付款核销，退货也不记应付扣款 |
| 规则 | ERP「模块设置」里的「费用报销规则」（店主）：门槛、超期天数、用途、发票类型与税点 |
| 权限 | 新职责「成本核算」；新权限：查看、登记报销、登记打款退回、确认与冲销、导出（见 `docs/EXPENSES.md` 第 5 节） |
| 自检 | `check` 库存之后加三项：费用报销单与明细一致、备用金台账一致、现付供应商的收货不记应付 |

## 2. 验收要点

| # | 操作 | 预期 |
| --- | --- | --- |
| E1 | 成本核算登记按次报销：用途、发票类型、税点、费用科目都只能从固定选项里选 | 专票选 0 税点拒绝（`TAX_RATE_MISMATCH`）；专票 / 普票不填发票号拒绝（`INVOICE_NO_REQUIRED`）；购买与到货数量不一致不写原因拒绝 |
| E2 | 登记 ¥2,000.00 与 ¥2,000.01 的报销 | 前者登记即确认；后者待确认、进审批待办，负责人确认 / 退回，登记人重新提交或撤回 |
| E3 | 对账付款登记打款 ¥1,000 → 成本核算用这笔钱报销 ¥600 → 退回 ¥300、再退 ¥100 | 应退回 ¥400 → 未退回 ¥100 → 已平；退回超过未退回拒绝（`RETURN_EXCEEDS`） |
| E4 | 已平的打款再报 ¥50 | 未退回 −¥50「待补付」；补付 ¥50 后已平 |
| E5 | 打款日期是 10 天前、还没平 | 标「超期未退」，部门卡片显示超期笔数 |
| E6 | 把一个供应商改成「现付」，按它的采购单收货 | 应付货款不变，付款核销里看不到这张收货；按采购单报销取采购与到货数量，同一行不能报两次（冲销后可以重报） |
| E7 | 挂账供应商的采购单按采购单报销 | 拒绝（`CREDIT_SUPPLIER`） |
| E8 | 打款下面还有有效的报销或退回时冲销打款 | 拒绝（`ADVANCE_IN_USE`）；先冲销下面的单据再冲销就可以 |
| E9 | 物资经办、采购经办、负责人登录 | 只能看；前台店员看不到费用与备用金；导出只有店主、对账付款、成本核算、负责人 |
| E10 | 断网时登记（响应丢失） | 「结果待确认」：按原内容重新提交只登记一次 |
| E11 | 从 v0.7.6 的演示库升级 | 迁移 026 后 `check` 全 ✓；原有收货的应付与对账单不变 |
