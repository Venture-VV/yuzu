# v0.7.13 交接说明 · Batch 4 收尾：台面日耗品与称重、每月盘点与供应商对账提醒

店主 2026-11-01 定先把 Batch 4 剩下的 #14、#23 做完，再做 RQ-004。设计见 `docs/STOCK_CYCLES.md`；默认做法（待确认）见 `docs/PENDING_DECISIONS.md`「台面日耗品、称重与盘点对账提醒」。

- **迁移 `031`**：物料加 `counter_use`（台面日耗品）、`weighed`（称重，约束：称重的小数位至少 1 位）；供应商加 `reconcile_cycle`（`monthly` / `batch`，默认月结）、`reconcile_since`（改成按批次的日期）；对账登记 `supplier_reconciliations`（月结的月份与登记时对账单的七个数，或按批次的合计）与 `supplier_reconciliation_docs`（按批次登记的收货单与当时的货款），只追加，撤销人 / 时间 / 原因只能写一次，同一供应商同一月份最多一条有效的月结登记；操作编号与「确认作废」登记认 `supplier_recon`。只加表、加列；升级后原有物料都不是台面日耗品、不是称重，供应商都是月结。
- **阻断项**：账错（台面日耗品在部门小仓留下结存、自动耗用与领料数量不一致、冲销后部门小仓或总仓结存不对、称重超过容差还能收、货款不按实收算）、越权（采购能登记月结对账、仓库能登记对账、部门能登记台面日耗品的期初 / 耗用 / 报损 / 盘点）、同一张收货单能登记两次对账、同一供应商同一月份有两条有效登记、`check` 不是全 ✓、破坏原有库存 / 采购 / 货款功能。

## 1. 范围

| 项 | 内容 |
| --- | --- |
| 台面日耗品（#14） | 物料档案勾选；领料生效（或部门急采验收生效）时，台面日耗品的行在同一张单上接着记一笔部门小仓的「耗用」，部门小仓结存回到 0；部门的耗用（收发汇总的「耗用」列、近期用量）算上这笔；总仓照常结存、盘点 |
| 台面日耗品的限制 | 部门小仓不能登记它的期初、耗用、报损、盘点（`COUNTER_USE_NOT_ALLOWED`，物料是提交后才改成台面日耗品的，生效时同样拒绝）；不能领料退回（领错了当月冲销整张领料单）；部门小仓里还有结存时不能改成台面日耗品（`COUNTER_USE_DEPT_STOCK`，列出哪些部门） |
| 称重（#14） | 物料档案勾选（小数位至少 1 位，勾选时自动设 2 位）；已有流水的物料可以增加小数位、不能减少（`UNIT_LOCKED`）；按采购单收货可以比这一行的订购数量多出容差（默认 10%，按这一行累计的实收算），超过 `RECEIPT_EXCEEDS_ORDER`（写明称重容差）；货款 = 实收重量 × 单价；采购单显示「称重多到」 |
| 每月盘点提醒（#23） | 每月盘点日（默认 1 号）起到月底提醒、宽限天数（默认 3 天）后标红；每个在用的仓按「月初（1 号 0 点）有结存的物料，本月的盘点单（已提交或已生效）都盘到了」算盘完；显示「已盘 x / y 种」与还没盘的物料（最多 30 种）；部门小仓不算台面日耗品 |
| 盘点提醒给谁看 | 库存工作台：总仓——仓库、成本核算、负责人；所有部门小仓——成本核算、负责人（「去盘点」链接到那个部门小仓的盘点）；本部门小仓页：本部门；负责人待办：「盘点与对账」一栏 |
| 对账方式（#23） | 供应商档案里挂账供应商选「月结」（默认）或「按批次」；改成按批次那天记下，之前的收货不提醒；现付供应商不对账 |
| 月结对账提醒 | 每月对账日（默认 1 号）起，上个月有往来（收货、退货、付款、核销、供应商退款）或上月底余额不为 0、还没登记上个月对账的月结供应商；宽限天数（默认 5 天）后标红；登记后那个月对账单的数字变了列为「登记后有变动」 |
| 按批次对账提醒 | 按批次供应商改成按批次以后生效的每张挂账收货单，没登记对账的；收货日起宽限天数（默认 3 天）后标红；已登记的收货单被冲销了列为「登记后有变动」 |
| 对账登记 | 「货款 → 对账」：月结的「登记已对账」（只能登记已经过完的月份，`MONTH_NOT_ENDED`；同一月份已有有效登记 `RECON_EXISTS`），记下当时对账单的期初、收货、退货、付款、退款、期末；按批次勾选同一供应商的几张收货单登记（一张只能在一条有效登记里，`RECON_DOC_TAKEN`）；可写备注；撤销写原因，撤销后可以重新登记 |
| 谁登记对账 | 月结：对账付款（店主）；按批次：采购经办或对账付款（店主）；其他人 403 |
| 结果待确认 | 对账登记带操作编号、提交前存本机（ERP 待确认类型「对账登记」）；断网后货款页上方查回、按原内容重新提交或作废（作废后原请求晚到 `OP_ABANDONED`）；同一编号换内容 `IDEMPOTENCY_CONFLICT` |
| 规则 | 后台「规则总表 → 库存与采购」：称重收货容差（0–30%）、每月盘点日（1–28）与宽限天数（0–27）、月结对账日（1–28）与宽限天数（0–27）、按批次对账宽限天数（0–30）；规则总表的说明里有这三条 |
| 页面 | 物料档案的两个勾选与列表标签；供应商档案的「对账方式」与「按批次对账」标签；收货单的称重提示；领料单详情「已记部门耗用」；本部门小仓的台面日耗品标签与盘点提醒；库存工作台的盘点提醒；货款页新视图「对账」（可以打开那个月的对账单）；负责人待办的「盘点与对账」 |

## 2. 演示数据与固定预期

- 演示数据不变：没有台面日耗品、没有称重物料，供应商都是月结（演示场景由测试会话按需要加）。库存结存、应付余额与 v0.7.12 一样（`inventory-demo.json` 的 `expected`）。
- 演示数据是建库当时登记的，所以「月初有结存」的物料要到下个月才有，盘点提醒在新建的演示库里不出现；单据日期在上个月的演示收货会让「对账」视图里出现上月待对账的月结供应商（看建库的日期）。
- `check` 共 42 项（v0.7.12 是 40 项），新加：台面日耗品在部门小仓没有结存、领料与急采的自动耗用与数量一致；对账登记的收货单属于这个供应商、一张最多登记一次、合计与明细一致。
