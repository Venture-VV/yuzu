# 8.1.20 出入库台账（库存页面导入台账调整）

店主 2026-11-21 转来《ERP 需求汇总更新：库存页面导入台账调整》与新模板（宝安店 4 楼仓库出入库记录，2026 年 12 月）：「在现有ERP系统“库存页面”这一次局部更新，根据文档需求开发」。默认做法见 `docs/PENDING_DECISIONS.md`「8.1.20」LD1–LD10。

## 1. 需求原文的要点

1. 库存模块「库管入库」页右上角放「导入出入库台账」，不影响原有布局与流程。
2. 导入模板换成新模板，旧模板同步停用。
3. 导入时按新模板的字段核对，提示清楚。
4. 其他功能不动。
5. 同一个地方还要能「导出台账」「下载模板」。

## 2. 入口

- 「库管入库」页（`/inventory/direct/new`，新建时）标题栏右上角三个按钮：**导入出入库台账**（去导入页）、**导出台账**（这个月）、**下载模板**。只有能办库存（`inventory.operate`）的看得到。页面其余部分不变。
- 导入页 `/inventory/direct/import`（原 8.1.9「导入入库台账」的地址）：右上角能选月份导出、下载模板；上方列出还没确认结果的导入（新旧两种）。
- 库存页「库管入库」旁的按钮改叫「出入库台账」。

## 3. 模板（`GET /api/inventory/ledger/template`）

照门店的《仓库出入库记录》：第一行标题，表头两行（上一行分组，下一行分组里的列），一种物料一行。

| 列 | 说明 |
| --- | --- |
| 序号、日期 | 只是给人看的（日期是建表的日期，不用来记账） |
| 供应商 | 有入库的行必须写；名称或编码 |
| 物料名称、规格 | 按名称对物料（可以写编码）；同名的再看规格 |
| 库位 | 写了且与档案不一样，导入时改档案（LD3） |
| 上期库存量 | 只核对，对不上提醒 |
| 入库 × 2（日期、数量） | 每组一次入库；数量按库存单位 |
| 出库 × 3（日期、数量、领料人及部门） | 每组一次出库；「领料人及部门」里要有部门名 |
| 库存量 | 只核对，对不上提醒 |
| 单价 | 新加的一列（LD2）：每采购单位，空着取参考价 |
| 备注 | 不导入 |

导入时按表头的名字认列，入库、出库有几组认几组（比模板多也行）；第二个工作表是填写说明，第三个是选项（物料与规格、单位、参考价、库位，供应商，部门），台账里的供应商、物料名称有下拉。

8.1.9 的旧模板停用（LD9）：页面上没有入口，`GET /api/inventory/direct-receipts/template` 回 410 `TEMPLATE_RETIRED`。

## 4. 核对与导入

- `POST /api/inventory/ledger/import/preview`：逐行核对，返回每一行对上的物料、供应商、库位、每次入库与出库、单价（是不是参考价）、问题（挡导入）与提醒（不挡），以及会生成哪些单据。
- `POST /api/inventory/ledger/import`（带 `clientKey`，业务类型 `ledger_import`）：整份没有问题才导入，一个事务里生成全部单据（LD6）：
  - 同一天同一供应商的入库 → 一张库管入库（收货单，直接入库，马上生效）；
  - 同一天同一部门同一领料人的出库 → 一张部门领料（马上生效）；
  - 一张最多 100 行，多了分开；同一天先入库后出库。
- 挡导入的问题（LD7）：没对上的物料、供应商、部门；有入库没写供应商；日期、数量写错；没有单价也没有参考价；按批次管保质期的物料有入库；同一种物料两行入库单价不一样；按日期推算出库会让总仓库存变负；导出的文件（标题有「系统导出」，`IMPORT_EXPORTED`）；同一份文件已经导入过（`IMPORT_REPEAT`）。
- 提醒：上期库存量、库存量与系统对不上；同一种物料写了两行。
- 封顶：一份最多 500 行物料；入库、出库各最多 62 组；一份最多生成 200 张单，超过的整份拒绝（`IMPORT_TOO_MANY`，Codex 安全审查 1ddc70a），请分成几份导入。
- 预览返回一个摘要（逐行核对结果与要生成的单据），导入时带上；服务端锁住物料以后重新核对，与这个摘要不一样（预览以后参考价、档案、结存被改过）就整笔拒绝（`IMPORT_STALE`），页面自动重新预览（Codex 审查 1ddc70a）。
- 预览与导入记的合计金额按合成以后的单据算（每张单每一行各自取整），与生成的收货单、应付一致。
- `GET /api/inventory/ledger/imports/:id`：查回一次导入与它生成的单据（「结果待确认」用）。

## 5. 加锁

见 `docs/LOCKING.md` 第 3 节「出入库台账导入」：操作编号 → 文件摘要 → 导入记录 → 占单号 → 全部物料（id 升序）→ 重新核对 → 逐张生成单据。

## 6. 导出（`GET /api/inventory/ledger/export?month=YYYY-MM`）

总仓这个月的出入库（LD10）：上期库存量是月初的结存，入库按天合计，出库按天与部门、经办人（同一天同一类流水有进有出的——如盘盈和盘亏——进、出分开记，不相抵）（不是领料的出库，如盘亏、报损、调拨，写明是什么），库存量是月末的结存（这个月还没过完就是今天的）；带库位与参考价。次数比模板的组数多时往后加列。标题写「系统导出，只用来对账」，不能原样再导入。期初、期末与明细在同一个只读快照里取。只读（`inventory.read`）。

## 7. 数据（迁移 `200_ledger_imports.sql`）

- `materials.location`：库位（最多 20 个字），物料资料可改。
- `ledger_imports`：一次导入一行（文件摘要唯一、只追加）。
- `inv_docs.ledger_import_id`：单据挂着生成它的导入（只能是库管入库或部门领料）。
- `idempotency_keys`、`op_fences` 的业务类型加 `ledger_import`。
