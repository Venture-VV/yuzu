# v8.0.13 交接说明 · 电子菜单整改（中英切换、搜索适配键盘、动效）

8.0.12（管家部，PR #97）2026-11-12 合并为 main `a2560ec`、`v8.0.12` 已打上；Codex 在 PR #98 上的主线验收（main `v8.0.12`）没有发现新的失败。店主 2026-11-13 发来门店同事整理的《电子菜单整改需求汇总》：「下一版请做这个需求」，三件事：

1. **缺少外宾中英一键切换**：外宾点单时全中文菜单看不懂。在菜单首页加「中 / EN」切换按钮，点一下整页菜单、菜品名、介绍切成英文，再点切回中文。
2. **搜索时页面不适配弹出的键盘**：点搜索框后键盘弹起，菜品图被压缩变小。键盘弹起时搜索栏和菜单区域自适应，菜品图片比例不变、不被挤压。
3. **平板端电子菜单 UI 交互优化**：界面偏静态、点击滑动生硬。页面进入放大、退出缩小；滑动有惯性与回弹；菜品按下有轻微光影与浮起；分类选中有柔和高亮；整体舒缓。

设计在 `docs/EMENU.md` 第 11 节；默认规则 EN1–EN12 在 `docs/PENDING_DECISIONS.md`「8.0.13 电子菜单整改」（待确认）。这一版只动平板电子菜单（8.0.10）这个模块，不碰会员、钱包、结账、库存；下单接口没有变。

## 1. 范围

| 哪里 | 改了什么 |
| --- | --- |
| 平板 · 中英切换 | 起始页右上角、菜单顶栏搜索左边各一个「中 \| EN」开关。切到英文：英文菜名为主、中文名缩成下面一行小字；介绍、名称后的小字、属性行、单位（`/份` → `/portion`）、规格（大份 → Large）、分类页签、封面大标题、弹窗、抽屉、备注选项、搜索、提示条、售罄等状态都是英文。没录英文的地方显示中文，不留空白 |
| 平板 · 不换的 | 给服务员看的仍是中文（确认下单时门店系统的拒绝原因、「结果待确认」「没有下成」、退出登录）；进厨房的备注仍是中文选项；账单上仍是价目项目的中文名 |
| 平板 · 语言什么时候回中文 | 结束点餐、没人动回到起始页；在起始页切到 EN 后 1 分钟没人开始点。页面被系统刷新，这一次点餐的语言还在 |
| 平板 · 键盘 | 整页的缩放按「稳定的窗口大小」算：正在输入时窗口变矮当作键盘弹起，不重新缩放，页面与菜品图大小不变；搜索结果的高度按键盘上面剩下的空间收（放不下的在列表里滑）；输入框在下半屏时（备注抽屉的自定义备注）整页往上挪到它露出来 |
| 平板 · 动效 | 菜品详情从被点的位置放大出来；弹窗、抽屉、详情、搜索关掉时有退场（缩小淡出、向右滑出）；点分类页签直接到那一页、轻微放大缓入；左右翻页改成跟手拖动、带惯性与两头的回弹；抽屉与搜索结果滑到头有回弹；菜品图按下微微浮起、带阴影与一道扫光；加菜时小圆点飞向订单图标；选中的分类下面有渐变光晕、换分类时滑过去；起始页大图极慢地放大缩小；图片加载完淡入。系统「减少动态效果」或后台设成「简洁」时全部关掉 |
| 后台 · 菜品图文 | 多了「英文」一块：英文介绍、名称后小字的英文、属性行的英文、单位的英文、每个规格的英文（灰字是系统自带的写法）。排进了菜单、缺英文名或英文介绍的菜带「缺英文」标记，可以只看这些 |
| 后台 · 英文对照表 | 「菜品图文 → 英文对照表」：导出所有菜（编号、中文各列、英文各列）成 CSV，填好再导入。只更新英文、空着的格子不动、编号对不上的跳过并列出、同样的内容再导一次不变 |
| 后台 · 设置 | 多三项：中英切换（默认开）、忌口与起菜方式各选项的英文（灰字是自带的）、动效（丰富 / 简洁，默认丰富） |
| 后台 · 版面预览 | 可以切「预览：中文 / EN」 |

## 3. 验收要点

照 `docs/EMENU.md` 第 11.6 节：

1. 后台给两道菜填英文介绍、一道不填；设置里给一个忌口选项填英文。平板点「EN」：填了的显示英文、中文名在下面小字；没填的仍显示中文；再点回到中文，各元素的位置与 8.0.12 一样（顶栏多了开关；分类多于 3 个时页签比原来挤一点）。
2. EN 下加菜、备注选「No cilantro」、服务员输密码下单：厨房屏与账单上的备注是「不加香菜」；确认下单时密码不对的提示是中文。
3. 导出英文对照表 → 填几格 → 导入：只改填了的；再导一次提示没有变化；编号乱填的行被跳过并列出。
4. 安卓平板点搜索：页面不缩小，结果列表在键盘上面。没有安卓平板时，把浏览器窗口在输入时拖矮可以看到同样的效果。
5. 逐项看 11.3 的动效；系统开「减少动态效果」或后台改「简洁」后全部没有。
6. 结束点餐后回到中文；后台关掉中英切换后开关不显示。
7. 回归：8.0.10 的整套流程（`docs/EMENU.md` 第 10 节）照旧，特别是「结果待确认」三条路径、估清与时段。

阻断项照 `AGENTS.md`：账错、串单、越权、数据丢失、重复扣款、破坏旧模块自检。这一版下单路径没有改；要留意的是页面这边——**同一单会不会因为动效或语言切换被提交两次**（退场用的是不能点的影子，原来的弹窗照旧马上卸掉；用例里核对过影子不带任何可点的东西）。

- 本机逐屏看过截图：英文模式 13 页版面、菜品详情、搜索、订单抽屉、备注、输入信息、结束点餐；中文模式 13 页与 8.0.12 的对照。新截图在 `docs/screenshots/emenu/`（`en-1`–`en-4`、`admin-5`、`admin-6`）。

## 5. 要店主定的

- EN1–EN12 是否按默认（`docs/PENDING_DECISIONS.md`「8.0.13」）。几条比较要紧的：
  - **EN2**：切到英文后保留中文菜名的小字（服务员看得懂客人指的是哪道）。要「纯英文、一个中文都不留」请说。
  - **EN3**：英文由店里录，或导出对照表交给翻译的人；系统不调用外部的自动翻译。把导出的对照表发给我，我也可以先翻一遍给您过目再导入。
  - **EN6**：服务员那几步的提示仍是中文。
- 升级后中英切换默认开着；英文没录完之前要不要先关掉，由您定（见第 2 节）。
- 动效的快慢（进入约 0.5 秒、退出约 0.3 秒）与样子请门店同事在真平板上看过再说要不要调。
