## 1. 现在有什么、缺什么

- **报销**：每张报销单记部门、用途、发票（类型、税点、号码）、付款来源（备用金 / 公司直付），明细行记费用科目（办公费、固定资产、低值易耗、运费）与金额；超过门槛（默认 ¥2,000）要负责人确认，v0.7.30 起按审批中心的规则。
- **发票**：v0.7.32 的「登记发票」只管供应商开来、分到采购单上的发票（三单匹配）；报销单上的发票只是报销单里的几个字段，没有台账。
- **缺**：没有预算，部门花多少没人管；发票没有台账，不知道哪些专票还没认证、哪张发票报过两次。

## 2. 费用预算

### 2.1 额度怎么设（BI01、BI05）

- 按「部门 × 费用科目 × 月份」设额度。费用科目就是报销明细上的四个：办公费、固定资产、低值易耗、运费。
- 额度**从某个月起生效、之后每月沿用**，直到下一次修改：在 11 月把客房部的办公费设成 ¥2,000，12 月、1 月……都是 ¥2,000；1 月改成 ¥3,000 只影响 1 月及以后，11、12 月不变。
- 每一格可以设成「不控制」（清空）：从那个月起这一格不算预算。没设过的格子就是不控制，所以**升级以后在店主设额度之前，报销的行为一点不变**。
- 在「费用与备用金 → 费用预算」里按月看、改（新权限「设定费用预算」，默认只有店主）；能看费用报销的人能看预算与占用。
- 保存时带上页面看到的额度，对不上（别人刚改过）拒绝（`BUDGET_CHANGED`）；每一格的修改写审计。

### 2.2 占用怎么算（BI02）

- 某部门某科目某月的「已占用」= 这个部门、费用日期在这个月、状态是待确认 / 已退回 / 已确认的报销单里，这个科目的明细金额之和。撤回、冲销的不算（冲销以后额度自动回来）。
- 备用金的支出就是付款来源为「备用金」的报销单，一样算；打款本身是给部门的钱、还没花，不算。
- 页面上分开显示「已确认」与「审批中」（待确认、已退回）。

### 2.3 黄灯与超预算（BI03、BI04）

- 已占用达到额度的 **80%**（费用报销规则里可以改，50%–100%）亮黄灯；**超过 100%** 亮红灯。
- **登记报销时**（以及退回后重新提交时），按这张报销的明细逐个科目核对：「这张以前的已占用 + 这张这个科目的金额」超过额度的，这张报销就是**超预算**：
  - 不拦登记（不打断正常报销），但不再「登记即确认」，要走审批中心，单据类型是「**超预算报销**」；
  - 店主在审批中心为「超预算报销」建了规则的，按规则；
  - 没有规则时，在这张报销原来的审批链后面**加一级「店主」**：原来不用审批的（门槛以内、没命中规则）就是一级店主；原来要负责人确认的就是 负责人 → 店主；原来已经是三级的（审批链最多三级），或者最后一级已经是店主的，照原链。
  - 超预算报销不能批量同意，要逐张看；审批页上显示超了哪个科目、额度、之前已占用、这张多少。
- 报销单上记下登记（或重新提交）时的核对结果（`over_budget`、`budget_check`），列表与详情上标「超预算」。
- **登记页**带出这个部门这个月各科目的额度、已占用、剩余，填明细时就看得到「这张报完剩多少 / 超了多少，要多一级店主审批」。

### 2.4 并发（BI06）

同一部门同一科目的报销登记、重新提交与预算修改按「部门 + 科目」的咨询锁串行（科目按固定顺序取），两张同时登记不会都按「还没超」放过去。

## 3. 进项发票台账

### 3.1 台账里有什么（BI07、BI08）

在 v0.7.32 的「登记发票」（`supplier_invoices`）上扩成完整的进项发票台账：

- **三单匹配登记的供应商发票**（照旧在付款页登记、分到采购单）；
- **报销单上的专票、普票**：8.0.3 起登记报销时自动进台账，或者关联台账里已有的那张；收据、无票不进台账；8.0.3 以前的报销单不补进台账（报销列表里照样看）；
- **财务在台账里直接登记的**（先拿到票、后报销，或者别的进项票）。

每张记：发票类型（专票 / 普票，按费用报销规则里的发票类型）、发票号码、开票方（供应商，或填名称）、开票日、价税合计、税额、税率、来源、关联的采购单或报销单、照片（拍照上传，最多 9 份、不能删）、认证状态。

### 3.2 认证（BI09）

- 专票登记时是「待认证」，普票是「不用认证」。财务在增值税发票平台勾选以后，在台账里标「已认证」并填所属期（年月）；可以一次勾一批。标错了可以改回待认证（写审计）。8.0.3 以前登记的供应商发票都当作专票、待认证，是普票的财务标「不用认证」。
- **认证期限**：专票开票日起 **360 天**（费用报销规则里可以改，0 = 不设期限）。国家 2020 年起已经取消专票的认证期限，这里是店里自己要求的期限，默认沿用以前的 360 天，想更快入账可以改小。
- 到期前 **7 天**（可改）进待办：ERP 导航「发票台账」上显示张数，台账里有「将到期」筛选；过了期限还没认证的标异常。

### 3.3 异常票（BI10，只标记、不拦）

- **重号**：同一发票号码在台账里有两张以上没作废的（不同开票方也算，财务自己判断是不是同一张）；
- **税额不符**：税额与「价税合计 × 税率 ÷ (1 + 税率)」相差超过 ¥1（可改）；
- **税率不符**：税率不在这类发票允许的税点里（费用报销规则的发票类型）；
- **超过认证期限**：待认证、过了期限；
- **金额不符**：关联的报销单金额与发票的价税合计不一样；
- **开票方未填**：报销时没填开票方的。

### 3.4 报销与发票（BI11）

登记报销选了专票或普票（要填号码的发票类型）时：

1. 在登记页选了台账里的某张发票：直接关联（要没作废、没挂在别的有效报销单上、不是三单匹配里分到采购单的发票）。
2. 没选：按号码在台账里找没作废的（填了开票方的按开票方再筛）：
   - 找到一张、还没被报销用过：关联它；
   - 挂在别的有效报销单上：**拦**（`INVOICE_ALREADY_CLAIMED`，同一张发票不能报销两次）；
   - 是三单匹配里分到采购单的供应商发票：**拦**（`INVOICE_IN_PAYABLES`，这张票走货款付款，不能再报销）；
   - 找到好几张：请在登记页选是哪一张（`INVOICE_AMBIGUOUS`）；
   - 没有：自动登记进台账（来源「报销」）。开票方、开票日、税额可以在登记页填；不填的开票方记「未填」（标异常）、开票日按费用日期、税额按税点算。按采购单报销的开票方默认是采购单的供应商。
3. 报销撤回、冲销以后，这张发票空出来，重新登记报销时按号码找回它；也可以在台账里作废（挂在有效报销单上的不能作废）。

同一个发票号码的登记（三单、报销、台账）按号码的咨询锁串行；关联时锁住发票一行（`FOR KEY SHARE`），锁住以后再核对没作废——与作废串行（作废锁发票一行、在锁里核对没有有效报销单挂着）。

### 3.5 权限（BI12）

- 新权限「管理进项发票」（台账里登记、标认证、上传照片、作废）：默认店主与财务（对账付款、成本核算职责）。
- 能看货款或费用报销的人能看台账。
- 三单里分到采购单的发票照旧在付款页登记，作废照旧要「登记期初未付、付款、核销与供应商退款」权限。
- 「发票台账」是 ERP 里单独的财务模块（`/erp/invoices`），默认开，依赖库存模块（供应商档案）。

### 3.6 台账页面

- 视图：全部有效、待认证、认证将到期（含已过期）、已认证、不用认证、异常票、已作废；可以再按来源、开票日、号码或开票方筛。
- 每个视图都在数据库里先筛、再按开票日从新到旧取前 1000 张；超过的页面上写明「只列出最新的」，缩短开票日范围或导出（最多 5 万张）看全部。上方「待认证」「将到期」「异常票」的数字按全部有效发票数，不受张数限制。（测试会话在 `1a1069a` 上报的 P2：原来先取最新 1000 张、再在内存里筛「将到期」「异常票」，旧的逾期票会漏掉。）
- 待认证的可以勾选一批标已认证（一次最多 200 张，填所属期）；单张在详情里改认证状态、上传照片、作废。
- 「登记发票」在台账里直接登记（先拿到票、后报销，或别的进项票），没收到结果时记在页面上方的「结果待确认」里，查回、按原内容重新提交或作废（与付款页登记发票同一类业务）。

## 4. 数据（迁移）

- **`086`**：
  - `expense_budgets`（部门、科目、从哪个月起、额度（空 = 不控制）、版本、改的人与时间，「部门 + 科目 + 起始月」唯一）；
  - `expense_claims` 加 `over_budget`、`budget_check`；
  - 报销单的守护：要不要审批（`needs_approval`）与超预算的核对在待确认、退回时随提交更新，已确认、撤回、冲销以后不能改。顺带修了一个潜伏的问题：门槛以内、但命中了审批规则的报销，登记时要把 `needs_approval` 改成「要」，原来的守护不让改，会报错；
  - 审批中心的单据类型加「超预算报销」（`expense_over_budget`）。
- **`087`**：
  - `supplier_invoices` 加发票类型、开票方名称（供应商可以空）、来源、认证状态与所属期、认证的人与时间、认证版本；
  - 守护改成：内容不能改；作废只能一次；认证状态只在没作废时能改；
  - 「开票方名称 + 号码」对没有供应商的发票唯一；
  - `supplier_invoice_attachments`（发票照片或 PDF，只追加）；`erp_files` 的用途加「发票」；
  - `expense_claims.invoice_id` 外键与「一张发票同时只挂一张有效报销单」的部分唯一索引。
- 都只加列、加表、放宽约束；8.0.2 以前的数据不改（发票登记补上默认的类型与认证状态，用列默认值，不改已有的行）。

## 5. 自检

- 有效报销单关联的发票都没作废；
- 一张发票同时只挂一张有效报销单（索引兜底，自检再看一遍）；
- 「没作废的发票分到采购单的金额合计 = 价税合计」只查三单匹配登记的发票（报销、台账登记的没有分到采购单）；
- 已认证的都有所属期与认证人。
