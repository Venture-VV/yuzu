# 浴族设计语言

**城市度假 × 山野自然 × 年轻当代。** 一间开在城市里的年轻山野汤泉：米白纸感的底色、石材般的线条、松林绿的秩序，再用一点柚黄让界面有呼吸感。品牌表达集中在登录页、侧栏和少数氛围位置，工作区保持清楚、轻快、数字好读。

令牌定义在 `src/client/styles.css` 的 `@theme` 中，组件在 `src/client/components/`。

## 色彩

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `paper` / `paper-2` / `paper-3` | #F6F3EC / #EFEBE2 / #E8E3D7 | 页面底色与分区底色（米白、石色） |
| `card` | #FFFDF8 | 卡片、输入框 |
| `line` / `line-strong` | #E4DED1 / #D3CBBB | 分隔线、边框 |
| `ink` → `ink-4` | #1C231F → #B2B6AE | 正文、次要、辅助、占位 |
| `pine` | #24493A | 主色：主按钮、侧栏、**本金** |
| `yuzu` / `yuzu-deep` | #F2C230 / #A87508 | 点缀：消费入口、选中项；**赠金**数字用深柚黄保证对比度 |
| `lake` | #2C6066 | **实收**（真正收到的钱）、收款方式 |
| `moss` | #6A7C44 | 余额增加 |
| `clay` | #B0503A | 撤销、危险操作、错误 |
| `ember` | #DC7432 | 提醒：跨日撤销、演示数据 |

**金额语义固定**：本金 = 松林绿，赠金 = 柚黄，实收 = 湖水青，撤销 = 陶土红。同一种钱在所有页面颜色一致，避免把收款、储值消费、赠金混成一个含义不清的数字。

## 字体

- 中文：设备系统字体（苹方 / 鸿蒙 / 微软雅黑），保证阅读与离线可用。
- 拉丁字母与数字：**Plus Jakarta Sans**（可变字重，随应用打包），金额统一使用等宽数字（`.num`）便于纵向核对。
- 品牌展示：**Instrument Serif** 斜体，只用于 `yuzu` 字标与少量英文 / 数字标题，不用于中文。
- 金额组件 `<Money>`：¥ 符号缩小、分位弱化，一眼读出整数部分。

## 形状与层次

- 圆角：8（小按钮、标签）/ 12（按钮、输入框）/ 16（卡片）/ 22（弹层）。
- 阴影克制：卡片只有极浅的投影，弹层使用较深的柔和阴影。
- 触控区域：主要操作按钮高 48–56px，列表行 ≥ 56px，步进器按钮 36px。

## 布局

- **会员工作台**（≥1280px）：左栏搜索与会员列表，中栏会员身份与余额，右栏为「今日概览」或正在进行的充值 / 消费流程。会员信息在操作期间始终可见、位置不变。
- 900–1279px（平板横屏）：两栏，流程以右侧面板滑出。
- < 900px（平板竖屏）：单栏，列表与详情切换。
- 流水在宽屏为表格，平板为卡片列表。

## 流程与状态

- 充值、消费都是三步：**填写 → 核对 → 完成**。核对页展示会员、金额、扣款构成和「之前 → 之后」余额；完成页用数字过渡动画说明余额变化。
- 每种状态都同时用文字和图形表达：成功（描线勾）、失败（红色提示）、待确认（黄色提示 + 查询按钮）、空状态（线描小图 + 一句话 + 操作）、加载（骨架屏）。
- 动效只用于帮助理解结果（弹层滑入、余额数字过渡、勾选描线），尊重系统「减少动态效果」设置。

## 键盘

`/` 搜索会员 · `↑ ↓ Enter` 选择 · `R` 充值 · `X` 消费 · `N` 新建会员 · `Esc` 关闭面板。按钮上以小键帽提示。
