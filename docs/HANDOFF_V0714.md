# v0.7.14 交接说明 · 飞书需求 RQ-004 第一段：空间台账，客房房间挂接空间

店主 2026-11-01 定 v0.7.13 之后开工 RQ-004，这一版做第一段「空间台账」，并把客房的房间挂到台账上（RQ-003 剩余项）；同一版修正 v0.7.13 合并后 Codex 审查的 4 处问题。设计见 `docs/SPACES.md`；默认做法（待确认）见 `docs/PENDING_DECISIONS.md`「空间台账」。

- **迁移 `032`**：
  - 新表：
    - `floors` 楼层，预置 L1「一层」、L2「二层」、L3「三层」；
    - `zones` 区域，同一层不重名；
    - `spaces` 空间，编码大写字母开头、最多 8 位、唯一，建好后不能改、不能删，区域要在同一层；
    - `space_aliases` 别名，只追加、停用一次，同一空间在用的别名不重复；
    - `space_imports` 导入记录，只追加，文件摘要唯一。
  - `rooms` 加 `space_id`，唯一，一个空间最多挂一间房。
  - 操作编号与「确认作废」登记认 `space_import`（空间台账导入）、`supplier_recon_void`（撤销对账登记）。
  - 只加表、加列、放宽约束；升级后台账是空的，房间都没挂接，照旧手工房号。
- **阻断项**：
  - 挂接不一致：房号不是空间编码、挂了非「客房」或停用的空间、一个空间挂两间房、有人住时换了挂接。
  - 越权：值班经理、前台能改台账或导入。
  - 导入：有错误的文件写进了一部分；同一个文件或同一编号写了两次；编码已在台账里的被覆盖。
  - 编码能改或能删。
  - `check` 不是全 ✓。
  - 破坏原有客房、库存、货款功能。

## 1. 范围

| 项 | 内容 |
| --- | --- |
| 台账结构 | 楼层 → 区域 → 空间。空间的字段：编码、楼层、区域（可空）、业态、容量（人，可空）、面积（㎡ 两位小数，可空）、显示名、英文名、可售、核对状态、编码图原始标注、备注、在用。缺号不补 |
| 核对状态 | 已核对 / 推断 / 待现场核对。导入时按备注标出：「推断」「推测」「近邻标签」→ 推断；「现场核对」「待核对」→ 待现场核对；有「核对状态」列时以它为准。在空间详情里改状态要写说明（至少 2 个字），记经办人与时间 |
| 别名 | 品牌名 / 编码图原始标注 / 旧名 / 其他。只追加，不用了停用（留着能搜）。不同空间可以同名（如 4 间「客房 C5」）；同一空间在用的不重复（`ALIAS_EXISTS`）；停用过的再停用 `ALIAS_RETIRED`。导入的「编码图原始标注」自动记为别名 |
| 导入 | 「空间台账 → 导入」：区域清单（楼层、区域名(中文)、区域名(英文)、备注）、空间清单（楼层、区域字母、编码、业态、容量(人)、建议显示名、面积、编码图原始标注、备注；可选 区域、英文名、可售、核对状态），列名与需求文档附件一致。<br>CSV（UTF-8 / GBK）或 Excel。<br>先预览：新建几个、已在台账里几个、推断几个，问题按行列出，已在台账里的列出不同的字段。<br>有错误整份不写（`IMPORT_INVALID`）；全是已有的拒绝（`IMPORT_NOTHING_NEW`）；同一个文件只写一次（再提交得到原来那次）。<br>写入带操作编号，结果不明时页面上方可以查回、按原内容重新提交或作废 |
| 逐条维护 | 新建空间：编码自动转大写，重复的 `SPACE_CODE_TAKEN`，区域不在这一层的 `ZONE_FLOOR_MISMATCH`。<br>编辑、停用：挂着客房房间的不能停用、不能改业态（`SPACE_HAS_ROOM`）。<br>批量设区域：空间要在区域那一层。<br>楼层、区域可以新建、编辑、停用（里面还有在用的就不能停用：`FLOOR_IN_USE`、`ZONE_IN_USE`） |
| 汇总与提醒 | 台账页上方显示在用的空间、区域、楼层、客房与已挂接的数目；没核对的、客房还没有品牌名的分别提醒，点一下只看这些 |
| 导出 | 「导出空间清单」CSV：楼层、区域、编码、业态、容量(人)、面积、建议显示名、英文名、编码图原始标注、别名（不含原始标注）、可售、核对状态、备注、在用 |
| 只读树 | `GET /api/spaces/tree`：在用的楼层 → 区域 → 空间（含别名、挂着的房间），给第三段房态图、第四段导览用 |
| 客房挂接 | 「客房 → 房间」的对话框里选空间（只列在用、没挂的「客房」空间），房号就是编码，挂着时不能另改。<br>台账里有在用的客房空间后，新建房间必须选空间（`ROOM_SPACE_REQUIRED`）。<br>第一次挂接不用写原因，换挂、取消挂接要写原因（`LINK_REASON_REQUIRED`）。<br>有人住时不能挂接、换挂、取消挂接（`ROOM_IN_USE`）。<br>挂别的业态 `SPACE_NOT_ROOM`，挂已挂的 `SPACE_LINKED`，挂停用的 `SPACE_INACTIVE`。<br>已有的房间不强制挂接，后台提示还有几间没挂 |
| 显示 | 房态看板的房间格子在房号下面显示空间的显示名；入住对话框标题「编码 · 显示名」；后台房间列表标「空间 编码」或「未挂接」 |
| 谁能用 | 店主、店总（与后台「客房」同一组权限：经营规则设置、价目与套餐）；值班经理、前台 403；只读树另外给前台客房、客房服务员、收银 |
| 自检 | `check` 加两项：「空间台账编码唯一、区域与楼层一致」「客房房间与空间台账挂接一致」 |
| v0.7.13 审查的修正 | ① 撤销对账登记带操作编号（P1）：提交前存本机，断网后可以查回、重提、作废；同一编号只撤销一次，作废过的晚到 `OP_ABANDONED`。<br>② 对账记录可以往前翻页（「加载更早的记录」），月结「登记后有变动」那一行与按批次的变动提醒里直接「撤销登记」。<br>③ 物料改成台面日耗品后，冲销会让部门小仓留下它的结存的单据被拒绝（`COUNTER_USE_NOT_ALLOWED`，提示先取消标记）。<br>④ 称重物料多到以后，采购单照样能改版：数量不变、或改小后容差上限仍盖住已收数量的都可以，再小 `PO_QTY_BELOW_RECEIVED` |
