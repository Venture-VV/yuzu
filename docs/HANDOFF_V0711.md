# v0.7.11 交接说明 · 飞书需求 RQ-002 第一步：总仓 + 部门小仓两级库存、收货必须有采购单与急采、当月冲销与分工

RQ-002「ERP 多项需求」先补 Batch 4 已定未做的四项（店主 2026-10-27 定的 #13、#17、#19、#21）。设计见 `docs/WAREHOUSES.md`；默认做法（待确认）见 `docs/PENDING_DECISIONS.md`「两级库存」。

- **迁移 `029`**：仓库与部门小仓的结存；流水、单据按仓；急采、一起验收、部门签收几列；盘点差异「耗用」；急采上限设置。只加表、加列；**原有库存与流水全部算总仓**，迁移前已生效的领用没进部门小仓（退回只进总仓，不用签收）。
- **阻断项**：账错（结存与流水对不上、领料只扣一头、冲销后某个仓不平）、越权（部门看到别的部门或总仓的结存与价格、负责人能冲销、部门能替别的部门签收或补单）、没有采购单还能收货、急采超上限还能生效、跨月还能冲销、`check` 不是全 ✓、破坏原有库存 / 采购 / 货款 / 费用功能。

## 1. 范围

| 项 | 内容 |
| --- | --- |
| 两级库存 | 总仓（名称沿用「库存范围名称」，默认「后勤总库」）+ 每个部门一个小仓（新建部门自动建）；领料：总仓出、部门小仓进；领料退回反过来；部门小仓的期初、耗用、报损、盘点由部门登记 |
| 第一次验收（#17） | 按采购单收货必须选「一起验收的采购」（在职的采购经办或店主，不能是自己） |
| 部门签收（#17） | 领料仓库登记即生效；部门在「本部门小仓 → 待签收」签收，有差异写明；超过 3 天没签收在库存工作台提醒 |
| 部门小仓的盘点 | 提交即生效、不用负责人确认，差异原因默认「耗用」；成本核算可以给任何部门盘点、登记耗用 |
| 收货与急采（#19） | 没有采购单不能收货；急采由部门登记（不超过上限，默认 2000 元，「模块设置 → 库存」可调）→ 仓库到部门验收确认（登记的人不能自己验收）→ 进部门小仓、记货款 → 部门补采购单并自己确认 |
| 冲销（#21） | 单据日期所在的月份过了不能冲销（期初未付按确认日期）；库存单据：物资经办、成本核算；付款、期初未付、报销、备用金：对账付款、成本核算；负责人不再冲销 |
| 页面 | ERP「本部门小仓」（`/erp/dept-stock`）；库存页的仓库切换、各仓结存与按仓库存卡、提醒；收发汇总按仓 / 全部合计；单据详情的仓、一起验收、签收、急采验收；规则总表的急采上限 |
| 部门停用 | 小仓有存货或待确认的单据时不能停用 |
| 同版小项 | 「图片还在上传时不能提交」的 E2E；`npm audit` 清零（`overrides` 把 `@fastify/static` 的 glob 升到 14.0.3） |

## 3. 验收要点

| # | 操作 | 预期 |
| --- | --- | --- |
| W1 | 新建演示库（seed-demo、seed-inventory-demo），库存页切到「浴区小仓」 | 列出第 2 节的结存；物料详情列各仓结存，点「浴区小仓」看浴区的库存卡（只有领料一条） |
| W2 | 收发汇总选总仓、浴区小仓、全部合计 | 总仓与以前一致；浴区小仓的「从总仓领料」为正、期末 = 第 2 节；全部合计里迁移后的领料、退回抵消，期末 = 总仓 + 各部门小仓 |
| W3 | 物资经办新建收货：不选采购单 / 不选一起验收的采购 / 选自己 | 不能提交；接口直接调：`PO_REQUIRED`、400；选非采购的人 `CO_ACCEPTOR_INVALID` |
| W4 | 给部门申购（员工档案填所属部门）登录，进 ERP | 只有「本部门小仓」（及原有的需求单）；只看得到本部门；`/api/inventory/materials` 403；别的部门的小仓 403 |
| W5 | 部门申购在「待签收」签收一张领料，写差异 | 显示签收人、时间、差异；再签不变；别的部门、物资经办签不了；库存单据详情显示「部门已签收」 |
| W6 | 部门盘点：实盘比账面少 | 提交即生效，差异原因「耗用」，只动本部门小仓；页面上的账面与库里不一致时拒绝（`COUNT_STALE`） |
| W7 | 部门登记急采：1 箱 2,100 元 | `URGENT_OVER_CAP` 拒绝；300 元的提交后「等仓库到部门验收」，库存、货款不变 |
| W8 | 登记急采的人点验收 / 物资经办在库存单据里「到部门验收确认」 | 前者 403；后者生效：进部门小仓、挂账供应商记应付；工作台「急采待补采购单」+1 |
| W9 | 验收前店主把上限调到 200 元 | 验收 `URGENT_OVER_CAP`（按当时的上限再核对） |
| W10 | 部门在急采单上「补采购单」 | 采购单「已确认」，确认记录写「急采补单，部门确认」；收货单关联这张采购单；库存、货款不变；别的部门补不了 |
| W11 | 领料退回：部门小仓不够时 | `INSUFFICIENT_STOCK`，写明是哪个部门小仓 |
| W12 | 冲销：负责人冲销库存单据 / 付款 / 报销；物资经办冲销本月的库存单据；成本核算冲销本月的报销；任何人冲销上月的单据 | 负责人 403；本月的成功、各仓按原流水反向；上月的 `VOID_CROSS_MONTH`，详情里写「跨月不能冲销」 |
| W13 | 停用一个小仓有存货的部门 | `DEPT_STOCK_NOT_EMPTY`，写明有哪些；盘点到 0 后能停用；停用后不能再领料给它 |
| W14 | 新建部门 | 自动有「部门名 + 小仓」；仓库不能在数据库里删或改归属 |
| W15 | `check` | 库存部分新加的各项全 ✓：部门小仓结存与流水一致、各仓流水连续、流水记在单据的仓、收货都有采购单（急采除外）、每个部门都有小仓且停用的已清空 |
| W16 | 从 v0.7.10 的演示库升级 | 只多应用 `029`；原有库存、流水全部在总仓；还没生效的领料改为进领料部门的小仓；`check` 全 ✓ |
| W17 | 规则总表 / ERP「模块设置 → 库存」 | 「无采购单直接收货」开关没有了，改为「急采上限」（默认 ¥2,000.00） |
| W18 | 成本核算登录 ERP | 能看库存、采购单（只读）与「本部门小仓」（所有部门）；默认进的第一页因此变成「库存」（ERP 按模块顺序进第一个能用的模块）；不能录入总仓的收发 |
| W19 | 负责人登录（测试服回归报告的缺陷 1） | 能审核需求单（通过、退回、不采购），看不到「待转采购单」；采购单关闭后需求行显示「采购单已关闭」；需求单修改、审核、撤回的操作审计都有 IP |
