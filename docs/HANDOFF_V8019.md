# v8.0.19 交接说明 · 后台架构重新整理第三步：门店的日常入口

`docs/IA_V8017.md` 第 3.4 节；IA4（批量发券、无记名券、停车登记、会员的微信解绑当作日常操作挪到门店的会员工作台）店主 2026-11-13「按照默认」。这一版是三步里的最后一步（第一步 8.0.17 后台、第二步 8.0.18 ERP）。

## 1. 范围

| 哪里 | 改了什么 |
| --- | --- |
| **发券**（`/coupon-issue`，新页 `features/coupons/CouponIssuePage`） | 会员工作台右上角「发券」，两个页签：批量发券、无记名券。用的是原来那两张卡片、原来的接口与权限（`coupon.manage`，无记名券作废另要 `coupon.void`）。后台「券」只剩发券规则、券模板、统计、使用率，右上角有「去发券」 |
| **停车登记**（`/parking-log`，`features/membership/ParkingLogCard`） | 会员工作台右上角「停车登记」（能登记权益使用的、维护会员权益的看得到）。原来在后台「会员权益」最下面；现在默认看今天（原来默认本月 1 号到今天）。登记本身一直在会员详情「本月可享」的停车优惠那一行，没动 |
| **会员详情「微信小程序」一行**（`features/workbench/MemberWechatCard`） | 看这位会员绑没绑小程序；有 `mp.unbind` 的可以在这里解绑（写原因）。只引用小程序线现成的接口（`/api/admin/mp/members/:id/bindings`、`/api/admin/mp/bindings/:id/unbind`）与 `sendUnbind` / `useMpPending`，**没有改小程序线的文件**。后台「微信小程序 → 绑定」照旧 |
| **用户菜单「本机终端」** | 头像菜单里多一项，右边写着这台电脑设成了哪台终端（没设写「未设置」）；点了到「设备」页并定位到「本机终端」那一块。有 `device.view` 的看得到 |
| **ERP 导航与首页** | 不再列营业数据、员工食堂、安保巡场（8.0.18 留的三条跳转去掉）。模块开关仍在「ERP 设置 → 模块开关」；页面在后台 |

## 2. 新旧对照

| 原来在哪 | 现在在哪 |
| --- | --- |
| 后台 → 券 → 批量发券 | 门店 → 会员工作台 → 发券 → 批量发券 |
| 后台 → 券 → 无记名券 | 门店 → 会员工作台 → 发券 → 无记名券 |
| 后台 → 会员权益（最下面）→ 停车登记 | 门店 → 会员工作台 → 停车登记 |
| 后台 → 微信小程序 → 绑定（找会员 → 解绑） | 会员详情「微信小程序」一行直接解绑（后台那一页照旧也能办） |
| 门店 → 设备 → 右边「本机终端」 | 同一处；另外头像菜单「本机终端」一点就到 |
| ERP 导航 → 已挪到后台 → 营业数据 / 员工食堂 / 安保巡场 | 后台 → 数据看板 → 营业数据；后台 → 人员与行政 → 员工食堂 / 安保巡场 |

**旧地址照旧能用**：`/admin/coupons/campaigns`、`/admin/coupons/batches`（以及更早的 `?tab=` 写法）跳到 `/coupon-issue`；`/erp/revenue`、`/erp/canteen`、`/erp/patrol` 的跳转一直留着。

## 5. 验收要点

1. 店主 / 店总：会员工作台右上角有「停车登记」「发券」。发券里两个页签能照常预览、发券、生成无记名券、导出券码；后台「券」只有四个页签，「去发券」到门店的发券页。
2. 店员：工作台没有「发券」（没有维护券的权限），有「停车登记」；直接打开 `/coupon-issue` 回工作台。
3. 会员详情往下翻，「会员卡」下面有「微信小程序」一行：没绑的写「没有绑定」；绑了的写微信尾号、手机号、绑定日期，值班经理及以上有「解绑」。解绑后小程序里那位客人要重新绑定（与原来在后台解绑一样）。
4. 任意一页点左下角头像 → 「本机终端」：到「设备」页，「本机终端」那一块描边两秒；在那里选了终端，头像菜单里跟着写出编号。库里一台设备都没登记时「设备」页是空的提示（原来就是这样）。
5. ERP 侧栏只有：概览、审批、供应链、财务、合同、设置；旧地址 `/erp/revenue` 等仍跳到后台。

## 6. 已知的限度

- 「微信小程序」一行在小程序功能没开的门店也会显示「没有绑定」（读绑定的接口一直在）；读不到时这一行不显示。
- 解绑没收到结果时，查回、按原内容重新提交仍要到后台「微信小程序 → 绑定」上方办（那套「结果待确认」的界面在小程序线的文件里，主线没有另写一份）。
- 第 3.2 节留下的两件后台分区的事（会员规则 / 会员权益 / 渠道与标签合成「会员体系」；对客导览从空间台账单列）不在这一版（W6）。
