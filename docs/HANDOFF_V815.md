# v8.1.5 交接说明 · 平板电子菜单的品牌调整

主线 [PR #122](https://github.com/Venture-VV/yuzu/pull/122)。店主 2026-11-16 转来品牌方的《平板电子菜单、工作台页面UI及功能调整》，附两款字体文件与中英切换的两张图标。设计 `docs/EMENU.md` 第 14 节，默认做法 `docs/PENDING_DECISIONS.md`「8.1.5」PP1–PP8（待确认）。同一版里还有用例隔离（`npm test` 不受终端里给应用设的开关影响，测试会话在 PR #117 报）。**迁移 `180`**；不改账、不改下单与挂账的路径。

## 0. 升级后会看到的变化

- **平板顶栏**：右上角的「中 | EN」开关换成品牌给的图标（深棕方块上的「En」「中」）——中文时显示 En，点了换英文；英文时显示中，点了换回来。左上角的汤崎字标在「放大」一档（默认）变大了：现在是切换图标高度的 0.7 倍，与右边几样对齐在同一条线上。
- **菜单页的加号**：紧跟在菜名后面。带图片的菜，间距是加号大小的 4.5 倍（比原来宽一点）；文字陈列的饮品酒水、图文列表右边的六格，间距 2.5 倍（原来文字陈列的加号在价格下面、图文列表的按列对齐）。
- **早中晚时段**：升级以后什么都不变（原来的分类都算全天）。店主在后台把早餐、午餐、晚餐的分类各自勾上，平板就只显示现在这一段的菜单，到点自动换。
- **英文字体**：没变，仍是 Average Sans（给的 ABC Arizona Flare 是试用版，见第 1 节第 2 条）。

## 1. 范围

1. **早、中、晚三个时段**（PP1–PP3、PP8）
   - 后台「电子菜单 → 设置」最后一行「早中晚时段」：三段的名称、英文名、开始时间；结束是下一段的开始（默认早餐 06:00、午餐 11:00、晚餐 17:00，晚餐到第二天 06:00）。保存时核对早 < 午 < 晚、名称不空。
   - 后台「分类与版面」编辑分类：「在哪几段供应」三个按钮可多选，都不选是全天；原来的「供应时段」改叫「另外限定时间」（不限 / 指定时间），与时段同时满足才供应。左边分类列表写着每类什么时候供应。
   - 平板：只显示现在这一段与全天的分类；别的段的照「不在供应时段的分类」那个设置（默认不显示）。门店系统在菜单里给出下一次可能切换的时刻，平板到点（多等 1.5 秒）马上重新取菜单，不等 15 秒一次的刷新；停在菜单里的弹「已到午餐时段，菜单已换成午餐」。「未下单」里上一段的菜照旧显示菜名，标「当前时段不可售」，要减掉才能下单；菜名、规格与价格由门店系统随菜单的 `later` 给，刷新页面以后也一样（Codex 预检 `0f7c701` 报的 P2，`e2e/emenu.spec.ts` 的时段那一条加了刷新）。下单时门店系统按下单那一刻再核对（`DISH_NOT_AVAILABLE_NOW`）。
   - UI 工作台：平板菜单的菜单页、版式（卡片模板）工具栏多一个「时段」——现在 / 早餐 / 午餐 / 晚餐 / 全部分类，只影响画布上看到的。按某一段看时分类另外限定的时间不算。
   - 规则总表多一条「早中晚时段」。
2. **字体**（PP4）
   - 中文朱雀仿宋 8.0.10 起就在用：打包的是 v0.212，这次给的文件是 v0.211，同一款字体，不用换。
   - 英文 ABC Arizona Flare：这次给的 TTF 是**试用版**——字体文件的名称里写着 "Unlicensed Trial"，Dinamo 的试用条款不许放在服务器上、不许随软件发出去，也只有 498 个字形。所以没有放进代码库（代码库是公开的）、也没有部署。
   - 做好了「放授权文件就换上」：向 Dinamo 买网页授权，把 WOFF2（Regular）改名 `en.woff2`，放到服务器上 `compose.yaml` 旁边的 `brand-fonts/` 目录（`compose.yaml` 把它只读挂进容器；换目录用 `.env` 的 `BRAND_FONT_DIR`）。应用只把它发给能打开平板菜单的账号（`GET /api/emenu/fonts/en.woff2`，没放 404；文件头不是 WOFF2 的当没放）。平板、工作台、后台的版面预览打开时试着取一次，取到了英文就换成它，并去掉给顶替字体补的字距；平板刷新页面就生效，不用重启、不用升级。`.gitignore`、`.dockerignore` 都排除了 `brand-fonts/`。
   - 工作台主题里英文字体的默认项改名「ABC Arizona Flare（品牌字体，默认；服务器没放授权文件时用 Average Sans 顶替）」，键不变，已保存的版面照常用。
3. **加号与菜名的间距**（PP5）：`@shared/studio` 的 `EMENU_PLUS_GAP`（带图片 4.5、纯文字 2.5），按加号看到的大小算（原样 12.6、放大一档 15，整块再放大 1.4 / 1.35 倍时比例不变）。实现是加号前面一段能缩的空：菜名长、地方不够时这段空往下收，最少 1 倍；菜名最宽给到「能用的宽 − 加号 − 1 倍的空」。图文列表六格原来的按列对齐（`plusAt`）去掉，卡片模板的六格记成纯文字（`plus: 'text'`）。
4. **中英切换图标**（PP6）：`src/client/features/emenu/assets/lang-en.png`、`lang-zh.png`（品牌给的原图，191 × 191 四倍图，打包时内联进页面）。22.3 见方，放大一档 × 1.3；顶栏里右边仍在 774（原来开关的右边）、起始页仍贴在 984；换语言时两张图交叉淡入（动效关着时直接换）。按钮上 `data-shows` 写着现在显示的是哪一张。工作台起始页的「中英切换」块还是原来的 48 × 22.3（已发布的版面照常用），图标靠右放在框里；「深浅」是浅色时外加一圈很淡的描边。
5. **左上角字标**（PP7）：高 = 切换图标的高 × 0.7（原样 15.6、放大一档 20.3），宽按字标比例（80.7 / 104.9），左边 40，中线对齐右边几样（55.45）。
6. **用例隔离**（PR #117 的报告）：`vitest.config.ts` 开跑前去掉只给应用用的开关（模拟、正式接口密钥、`YUZU_AI_*`、访问网段与频率限制），`docs/TESTING.md` 记了一条。

## 4. 验收要点

1. **时段**：后台「电子菜单 → 设置」改三段时间；给分类勾早 / 中 / 晚。平板只显示现在这一段与全天的分类；把下一段的开始时间设成一两分钟以后，平板到点自动换菜单、弹提示；「未下单」里上一段的菜标「当前时段不可售」，减掉才能下单。用接口直接下上一段的菜被拒（`DISH_NOT_AVAILABLE_NOW`）。工作台菜单页的「时段」切到每一段，画布是对应的菜单。
2. **升级不变**：没勾时段的库升级以后，平板上的分类、页与 8.1.4 一样。
3. **字体**：没放授权文件时英文是 Average Sans；在独立演示库的服务器 `brand-fonts/` 放一个别的 WOFF2（开源字体就行）改名 `en.woff2`，平板刷新后英文换成它（根节点带 `data-brand-en`），删掉后刷新换回。没登录的请求 `/api/emenu/fonts/en.woff2` 是 401。
4. **加号**：有图的版式加号离菜名约 4.5 个加号宽；文字陈列与图文列表六格约 2.5 个；名字很长时加号仍在这一块里、不压价格。中文、EN、原样、放大四种都看。
5. **切换图标**：中文时是「En」、英文时是「中」；顶栏、起始页的位置；工作台起始页那一块照常能挪、能缩放。
6. **字标**：放大一档时字标明显比 8.1.4 大，高是切换图标的 0.7、中线对齐；原样几乎不变。

## 5. 已知的限度

- 「加号间距倍率」「两个图标上下边角相互交叠」两处需求原文有不止一种读法，按 PP5、PP7 的默认做了；品牌方说的不是这个意思时告诉开发会话改（都是几个数或一处排法）。
- 英文原字体要买网页授权；换上以后全大写小标题另补的字距可能要照设计稿再微调。
- 时段只按一天里的时刻；不同的日子用不同的时段、节假日菜单不做（第 14.7 节）。
