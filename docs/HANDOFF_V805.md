## 2. 验收要点

1. 登录页与导航栏显示 `v8.0.5` 与 SHA；`check` 全 ✓。
2. 买一赠一：模板选了赠品出库，结账用券后反结账，确认赠品出库最后是「已冲销」、库存回来；数据库里把一条已出库的改成「已取消」（模拟 8.0.4 留下的中间状态），一分钟内对账改成待冲销并冲销。
3. 额度：期初 ¥100 的会员，今天先用掉 ¥100、再充 ¥100、撤销那笔消费：会员详情显示「今日储值可用 ¥170.00」。撤销的是赠金批次已经到期的老消费（例：35 天前充 ¥500 送 ¥100、赠金 30 天有效、第二天全用掉；今天充 ¥100 后撤销）：本金 ¥500 回来、赠金 ¥100 随即作废，显示「今日储值可用 ¥570.00」。
4. 会员详情的券、小程序的券：买一赠一券写「买 X 送 Y」。
5. 批量发券：点「预览人数」后马上改圈选，旧的人数不出现、「发给 N 位」点不了；重新预览后照常发。
