# v0.7.19 交接说明 · 平面图收尾：派对房等开单即占用（D39）、对客导览、PDF 底图、图纸治理、例外补画轮廓

店主 2026-11-02 合并 v0.7.18 后定：这一版把平面图相关彻底收尾，下一版开始做别的模块；除 RQ-006（收银完善）与 RQ-001（硬件，P2 排最后）外的开发需求全部在这一版做完——按飞书需求台账与 ROADMAP 核对，剩下的就是 RQ-004 第四段与 D39。迁移 **`036_floorplan_finish.sql`**。设计（定稿）见 `docs/FLOORPLAN_FINISH.md`；默认做法（待确认）见 `docs/PENDING_DECISIONS.md`「平面图收尾」。

- **阻断项**：
  - 使用单记错账：开单、结束、撤单改了手牌账单、流水或收款；结账、撤销来访后还有开着的使用单（`check`「派对房等使用单与在店客人一致」不 ✓）；同一间房同时有两张开着的使用单。
  - 断网时开单、结束、撤单重复生效，或确认作废后原请求又生效；没有「客房入住、退房」权限的人能开单或作废使用单的操作。
  - 对客导览的接口或页面带出房号、房态、人员、会员信息或任何经营数据；没有「看对客导览」权限的人能看导览或去掉文字的底图。
  - 底图批次的入库登记、原图纸、在用历史、补画轮廓能被改、被删（除了补画作废一次）；换回旧底图在「页面看到的在用批次」对不上时照样换了；已换下的批次能补画。
  - PDF：扫描件、没比例的 PDF 转出了底图；DWG / DXF 的转换结果与 v0.7.18 不同。
  - 升级后原有数据变了，或升级前的批次启用记录丢了；`check` 在升级后的库上不全 ✓。
  - 演示数据命令在试用、正式环境写入了数据（与 v0.7.18 相同）。
