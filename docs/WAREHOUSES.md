# 两级库存：总仓 + 部门小仓（v0.7.11，RQ-002 第一步）

飞书需求 RQ-002「ERP 多项需求」先补 Batch 4 已定未做的部分（`PENDING_DECISIONS.md` #13–#25），分两版。这一版做四项：

| # | 店主结论（2026-10-27） | 这一版的做法 |
| --- | --- | --- |
| #13 | 公司一个大仓库（备各部门常用物品）+ 每个部门一个小仓库（从仓库领来的和本部门申购的），各自管库存 | 总仓 + 部门小仓两级库存，每个物料按仓记结存与流水 |
| #17 | 到货采购和仓库一起第一次验收；仓库通知部门领料后部门再验收一次（仓库自己备货的不用）；领料由仓库登记、部门确认签字；仓库物料差异由仓库确认，部门物料差异由部门自己管；每月 1 号财务到部门盘点 | 收货单写明一起验收的采购；领料仓库登记、部门签收；部门小仓的盘点由部门或财务做，差异由部门管 |
| #19 | 不允许没开采购单先收货；急采后补单由部门自己确认，仓库再到部门验收一遍；急采金额上限 2000 元（可调） | 收货必须按采购单；急采单独登记（不超过上限），仓库验收后进部门小仓，部门补采购单并自己确认 |
| #21 | 已入库物品的库存冲销由仓库或财务成本岗操作，账务冲销由财务负责；当月发生的当月冲销完，跨月不能冲销 | 冲销只限单据所在的月份；按库存 / 账务分工 |

v0.7.12（RQ-002 第二步）：退货待供应商确认、预付款与供应商退款、运费单独记费用、按可用天数提醒、供应商与期初未付批量导入、仓库 / 采购 / 部门 / 财务分岗不兼任（#17 的后半句）。

默认做法（待确认）见 `PENDING_DECISIONS.md`「两级库存（v0.7.11）」。

## 1. 现状（v0.7.10）

- 只有一个库存范围「后勤总库」：结存在物料上（`materials.stock_milli`），流水在 `stock_moves`（只追加，每条记下变动后的结存）。
- 「领用」出库后就算部门用掉了，部门手上有多少不记账。
- 可以没有采购单直接收货（规则开关，默认允许），事后补采购单（`purchase_orders.backfill_receipt_id`）。
- 冲销由负责人做，不限月份。

## 2. 仓库与结存

- **仓库**（新表 `warehouses`）：一个总仓（名称沿用「库存范围名称」，默认「后勤总库」）；每个部门一个小仓（名称「部门名 + 小仓」），新建部门时自动建。部门停用前，它的小仓要先清空（退回总仓或盘点到 0）。
- **结存**：总仓的结存仍记在物料上（`materials.stock_milli`、`last_move_id`），原有按总仓算的收货、领料、盘点、报表、采购单上的「当前库存」都不变；部门小仓的结存记在新表 `warehouse_stock`（部门小仓 × 物料）。
- **流水**：`stock_moves` 加 `warehouse_id`，原有流水都算总仓；每条流水的「变动后结存」按它所在的仓算，各仓各自逐笔连续。
- **锁**：沿用「锁物料行」，同一物料在所有仓的收发都串行（门店单店，量不大）；锁顺序不变（原单 / 采购单 → 物料）。

## 3. 单据怎么走

| 单据 | 谁登记 | 动哪个仓 | 说明 |
| --- | --- | --- | --- |
| 收货（按采购单） | 仓库（物资经办） | 总仓 + | 必须对应已确认的采购单；单上写明**一起验收的采购经办**（必选，#17 第一次验收）；生效与应付、现付的规则不变 |
| 急采收货 | 部门（部门申购，本部门） | 部门小仓 + | 没有采购单；合计金额不超过急采上限（默认 2000 元，可调）；提交后**仓库到部门验收、确认后才生效**；之后部门补采购单、自己确认（#19）；没补单的列在部门待办与账目自检 |
| 领料（原「领用」） | 仓库 | 总仓 −，部门小仓 + | 仓库登记即生效（东西当面交给部门）；部门在自己的待办里**签收**，有差异写明；超过 3 天没签收标出（#17 第二次验收、确认签字） |
| 领料退回 | 仓库 | 部门小仓 −，总仓 + | 对应原领料单；迁移 `029` 之前的领料没进部门小仓，退回时只进总仓（与以前一样） |
| 耗用、报损 | 总仓：仓库；部门小仓：本部门或财务（成本核算） | 选的仓 − | 报损的确认规则不变 |
| 盘点 | 同上 | 选的仓 ± | 总仓的差异仍要负责人确认；**部门小仓的差异由部门自己管，提交即生效**，差异原因默认「耗用」（新增，客用、日耗品用掉的就是这一项） |
| 期初 | 同上 | 选的仓 + | 每个仓每个物料只能一次（部门小仓的现有存货用它录入）；确认规则不变 |
| 退供应商 | 仓库或采购 | 原收货单的仓 − | 不变；退货待供应商确认在 v0.7.12 |

部门按员工档案里的「所属部门」认（v0.7.8 起有）：部门申购职责的员工只能操作本部门的小仓；店主不限。

## 4. 收货必须有采购单（#19）

- 取消「允许无采购单直接收货」开关：收货一律按已确认的采购单；没有采购单只能登记急采（部门小仓、限额）。
- 急采单合计超过上限整单拒绝（登记与仓库确认时都核对，上限按当时的规则）。
- 急采补单：沿用原来的「补单」（采购单关联这张收货单），补单由**本部门确认**（也可以由负责人确认）。
- 迁移前已有的无单收货照常保留、照常可补单。

## 5. 冲销：当月发生的当月冲销完（#21）

- 库存单据、付款、期初未付、费用报销、备用金打款与退回补付：**单据日期所在的月份过了就不能冲销**，提示用本月的单据更正（盘点、退回、退货、另登记一笔）。期初未付没有业务日期，按确认那天的月份算。月份按门店时区的自然日。
- **谁冲销**：库存单据由仓库（物资经办）或财务成本岗（成本核算）；付款、期初未付、报销、备用金由财务（对账付款、成本核算）。负责人不再冲销（确认、退回不变）。店主不受限。

## 6. 页面

- **ERP「库存」**：顶部切换仓（总仓 / 各部门小仓 / 全部合计）；结存、流水卡、汇总都按所选的仓；部门小仓的结存一目了然。
- **单据**：耗用、报损、盘点、期初先选仓；领料单显示部门签收状态；收货单选「一起验收的采购」。
- **新页「本部门小仓」**（ERP，部门申购职责）：本部门小仓的结存；待签收的领料（签收 / 写差异）；登记急采、补采购单；本部门的耗用、报损、盘点。
- **待办**：仓库看到「急采待验收」「领料未签收」；部门看到「待签收」「急采待补单」。

## 7. 迁移 `029`（只加不改）

- 新表 `warehouses`（总仓 id = 1；现有每个部门各建一个小仓，以后新建部门由触发器自动建；仓库不能删、不能改归属）、`warehouse_stock`（部门小仓 × 物料的结存，`CHECK (stock_milli >= 0)`；流水仍只追加）。
- `stock_moves` 加 `warehouse_id`（原有流水都填总仓）。
- `inv_docs` 加：`warehouse_id`（原有的非领料单据填总仓；还没生效的领料填领料部门的小仓；迁移前已生效的领料、退回为空，表示没进部门小仓；还没生效的领料退回跟着原领料单，原单都是迁移前的、没有仓，所以也为空、生效时只进总仓）、`urgent`（急采）、`urgent_cap_cents`（登记时的上限）、`co_acceptor_id`（一起验收的采购）、部门签收（签收人、时间、差异说明）；单据保护触发器把这几列一并纳入（生效后不能改，签收三列只能从空写一次）。
- 盘点差异原因加「耗用」。
- 规则：急采上限（默认 200000 分）；「允许无采购单直接收货」不再使用。

## 8. 自检

- 每个仓的结存 = 该仓流水合计；各仓流水逐笔连续；总仓结存与物料上的结存一致。
- 迁移后的领料每行都是一出一进（总仓出、部门小仓进）；退回同理。
- 迁移后生效的收货都有采购单，急采除外；急采合计不超过登记时的上限。
- 部门停用时它的小仓没有存货。

## 9. 实现备注（v0.7.11）

- **接口**：库存页 `/api/inventory/warehouses`（仓库列表）、`/api/inventory/warehouses/:id/stock`（部门小仓结存）、库存卡与收发汇总带 `?warehouse=<仓>`（汇总另可 `all`）；急采验收 `POST /api/inventory/docs/:id/verify-urgent`；一起验收的采购 `/api/inventory/co-acceptors`。部门入口 `/api/erp/dept-stock`（基础资料、结存、单据、登记与修改、签收、补采购单），按能看的部门限定，单据的生效、冲销仍走库存单据的同一套逻辑。
- **锁**：沿用「原单 / 采购单 → 物料（id 升序）」；部门小仓的结存行在物料锁之后；动部门小仓时对部门行加共享锁（确认部门没停用），停用部门时对部门行加排他锁、核对小仓已清空。
- **部门的员工**（部门申购）没有「查看库存与物资单据」，只能进 ERP「本部门小仓」；成本核算默认加了「查看库存与物资单据」（冲销库存单据要看得到单据），不能录入总仓的收发。
- **单据上的部门**：部门小仓的期初、耗用、报损、盘点、急采记下部门（列表、库存卡的「对象」显示部门）。
- **退回跟原单的仓**：领料退回、退供应商动的仓取自原单，生效时在原单锁内再核对一次（不一致拒绝 `SOURCE_WAREHOUSE_MISMATCH`）。
- **物料的单位锁**：任何一个仓有流水（部门小仓的期初、急采也算）就不能再改库存单位、精度，也不能改成候选物料；「总仓已有流水」只用于总仓的期初。
- **部门入口的单据**：行上的「当前结存」是这个部门小仓的，不带与全公司历史成交价的比较。

## 10. 验收要点（摘要，详见交接说明）

两级库存的结存与流水；领料与签收；急采与补单；没有采购单不能收货；跨月不能冲销与冲销分工；从 v0.7.10 的演示库升级只多应用 `029`、原有库存全部在总仓、`check` 全 ✓。
