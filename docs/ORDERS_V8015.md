## 1. 管家部：内网 HTTP 下点「新增会员」没反应

- **原因**（与需求里写的一样）：页面在点按钮时直接调用 `crypto.randomUUID()` 生成操作编号。这个接口只在安全上下文（HTTPS 或 localhost）里有；门店内网用 `http://192.168.x.x` 打开时不存在，一点就出错、弹窗出不来。8.0.12 整改时的浏览器验收是在 `127.0.0.1` 上跑的，没有碰到。
- **改法**：全店统一用 `src/client/lib/utils.ts` 的 `uuid()`（用 `crypto.getRandomValues` 拼 v4，HTTP 下也有）。管家部 3 个文件（工作台、拍凭证、名称库）与审批规则、审批代理 2 个文件里直接调用的 8 处全部换掉；加一条静态检查，页面代码里再出现 `crypto.randomUUID` 测试就不过。
- 录入窗原来就有称呼、联系方式、备注（偏好与注意事项）等项，不用加；提交后名单与「在册会员」数本来就即时更新，这次用例里一并核对。
- 代录预约、拍消费凭证、名称库这几处用的是同一个生成方法，一起好了。

## 2. 前台「流水」页：订单查询与逐行明细

### 2.1 在哪

「流水」页最上面多一排页签：**余额流水**（原来的页面，一点没动）与 **订单查询**（新的）。

### 2.2 怎么查

- 一个搜索框，输入下面任意一种（DD3）：
  - 结账单号、退款单号（输一部分也行，如 `JZ20261113-0001`、`0001`）；
  - 手牌号（`A8067` 整号、不分大小写，或只输数字 `8067`；只输一半如 `A80` 查不到）；桌号（输一部分也行）；
  - 会员手机号：后 4 位，或 11 位全号（不支持只输中间几位）；
  - 会员姓名、客人称呼（输一部分也行）。用储值付款、享受会员折扣的那位会员也算（按他的手机号、姓名查得到这张单）。
- 退款单：退款单号对得上，或者它的原结账单对得上（搜手牌、称呼、结账单号时退款单跟着一起列）；搜退款单号只列退款单（DD12）。
- 不输的时候，列所选营业日的全部账单（可以翻营业日）。
- 输了以后跨营业日查，按时间倒序，最多列最近的 200 张（DD4；不输、按营业日列时不限张数，DD11）。没有「查看历史营业日」权限的岗位（默认前台店员、客户经理）只查得到当天的，页面上写明。
- 列出来的是**结账单**（已反结账的标「已反结账」、有退款的标退了多少）与**退款单**（作废的标「已作废」）；每条显示单号、时间、营业日、手牌 / 桌号、会员 / 称呼、金额、收款方式、状态、经办人（DD5）。会员充值、储值消费这些余额变动仍在「余额流水」里。

### 2.3 点开一张单

右侧抽屉，内容与现场打印的结账单一致，另加部门与优惠（DD6）：

- 单号、营业日、时间、收银；已反结账的写谁、什么时候、为什么；补录的写纸质单号。
- 每张手牌（或桌台）一段：会员 / 称呼、停留时长、门票档；下面逐行——项目、技师、**所属部门**、数量、单价、金额、**优惠**。
- 明细按结账那一刻算（与打印的结账单同一个取法）：反结账以后作废的门票照样在，之后新挂的不算。
- 优惠：结账时的优惠 / 免单、券抵扣、会员折扣，系统在结账时已经按项目分摊并记下（看板、对账包用的同一份快照）；这里再按金额比例摊到每一行，合计与那份快照一分不差。
- 下面是收款：各方式的金额、储值扣款前后的余额、团购券、优惠的授权人；再下面是这张单的退款单。
- 退款单点开：退了哪几项（部门、项目、数量、金额）、退款方式、原因、记到的班次。
- 可以从抽屉直接打印结账单、退款单（原来的打印页）；两个打印按钮只在有「查看在店手牌」权限时显示（打印接口本来就要这个权限，DD13）。

个别老单（按实际时间补录到更早时刻的结账）按时刻取不全明细：这时改按结账时记下的项目快照显示（没有手牌与技师两栏；同一个项目合成一行，单价只在数量是 1 时显示），页面上有一行说明。演示库与测试数据里的结账单都走不到这一步（用例核对了演示库每一张都是逐行的）。

### 2.4 导出

「导出明细 CSV」（要「导出流水与日结」权限，记审计）导出**当前搜索结果的逐行明细**（DD7）：一行是一个消费项目，不是一张单一行。列：营业日、时间、单号、类型、状态、手牌 / 桌号、会员 / 称呼、部门、项目、技师、数量、单价、金额、优惠、实收（金额 − 优惠）、整单收款方式、经办人、原结账单号（退款单）。退款单的行数量与金额是负数、优惠是 0。「手牌 / 桌号」「会员 / 称呼」两列按这一行所在的那张手牌填（合并结账的不是整单全列）。文件名：按营业日时是 `浴族订单明细-<营业日>.csv`，带搜索词时是 `浴族订单明细-搜索结果.csv`。「余额流水」页签原来的「导出 CSV」不变。

### 2.5 权限

- 查询、看明细：「查看当日流水与日结」；看之前营业日的单要「查看历史营业日」。
- 导出：「导出流水与日结」。
- 不用「查看在店手牌」权限（客户经理没有前台权限，也能在流水页查当天的单）。
- 没有历史权限的岗位：今天结的、今天反结账的结账单都能看明细；退款单按退款的营业日判断——今天开的退款单看得到，点它的「原结账单」如果是之前的单会被拒。
- 地址：`/ledger?tab=orders&oq=<搜索词>&date=<营业日>`（搜索词用 `oq`，不和余额流水的 `q` 混）。

## 3. 后台「数据看板 → 经营总览」：部门 × 项目

- 「部门（项目分类）构成」下面多一张**部门项目明细**表，时间范围跟着页面上方的选择（今天、昨天、近 7 天、近 30 天、本月、上月、自定义）。
- 按部门分组、部门内按销售金额从大到小；点部门行折叠 / 展开（默认展开），可以一键全部折叠。
- 列（DD8）：部门、项目、销售数量、销售金额（应收）、占该部门金额比、优惠、退款、净额。
- 口径与日结、对账包的部门参考表一致：按营业日；时段内结的计入、时段内反结账的冲回；退款单按退款的营业日冲减数量与净额。
- 三方对得上：每个部门各项的销售金额相加 = 上面「部门构成」里这个部门的数；全表销售金额合计 = 应收；全表净额合计 = 净营业额（= 日结的净营业额相加）。表尾把这几个数写出来。
- 部门行另写「n 个项目 · 占全部 xx%」；优惠、退款是 0 的显示「—」；部门的销售金额不是正数（这段时间里只有反结账冲回）时占比显示「—」。
- 表尾照实写：合计等于应收、净营业额时写「=」，不等时变红写「≠」并提示去看日结自检（不藏）。
- 「导出 CSV」（Excel 直接打开，带 BOM）：一行一个项目，另有部门小计与合计，最后两行是对照用的应收与净营业额；金额列的表头带「元」；记审计（DD9）。

## 4. 数据与接口

没有迁移，都是只读。

| 接口 | 权限 | 用途 |
| --- | --- | --- |
| `GET /api/ledger/orders?q=&date=` | 查看当日流水 | 订单查询 |
| `GET /api/ledger/orders/checkouts/:id` | 同上（历史营业日另要权限） | 结账单的逐行明细 |
| `GET /api/ledger/orders/refunds/:id` | 同上 | 退款单明细 |
| `GET /api/ledger/orders/export?q=&date=` | 导出流水与日结 | 当前搜索结果的逐行明细 CSV |
| `GET /api/reports/executive`（原有） | 经营总览 | 多带一项 `items`（部门 × 项目） |
| `GET /api/reports/executive/items.csv?from=&to=` | 经营总览 | 部门项目明细 CSV |

- 每一行的「所属部门」与结账时记快照的规则相同（门票 / 客房 / 派对房的业态 / 其他（手动金额、赔偿等）/ 价目里的分类 / 未分类）；用例里拿演示库的每一张结账单核对「按行算出来的」与「结账时记下的快照」一致。
- 都在只读快照里读，不加锁。
- 订单查询是对结账单逐张匹配（没有另加索引，这一版没有迁移）：门店的量够用，结账单到几十万张以后可能要加索引。

## 5. 这一版不做

- 在订单查询里直接反结账、开退款单（仍在前台「结账记录」里做）。
- 按项目、按技师、按收银筛选订单；按金额区间查。
- 看板的部门项目明细按天展开、环比。
- 导出 Excel 原生格式（.xlsx）：CSV 用 Excel、WPS 直接打开。

## 6. 验收要点

1. 内网 `http://IP:端口` 打开「管家」：点「新增会员」1 秒内出录入窗；填称呼、联系方式提交，名单里马上有、「在册会员」数加一；代录预约、拍消费单、名称库同样打得开；控制台没有 `crypto.randomUUID` 的报错。
2. 流水页「订单查询」：分别输手机号后 4 位、手牌号（带字母与只输数字）、结账单号、客人称呼，都能列出对应的账单；已反结账、有退款的标得出来。
3. 点开一张单：逐行明细与打印的结账单一致（项目、技师、数量、单价、金额），多出部门与优惠；各行优惠相加 = 这张单的优惠 + 券抵扣 + 会员折扣。
4. 导出明细 CSV：一行一个消费项目；金额列相加 = 列表里这些结账单的金额相加。
5. 前台店员（没有历史权限）搜一张昨天的单：查不到，页面写明只查当天；直接打开昨天那张单的明细接口被拒。
6. 看板「近 7 天」：部门项目明细里每个部门各项相加 = 部门构成的数；净额合计 = 净营业额 = 这 7 天日结净营业额相加；切时间范围表跟着变；导出的 CSV 与页面一致。
7. 回归：结账、反结账、退款单、日结、对账包的数字不变；`check` 全部 ✓。
