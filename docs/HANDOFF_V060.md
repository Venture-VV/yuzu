# v0.6.0 交接说明 · 管理后台、岗位权限可调整、会员渠道与等级、按岗位的数据看板

本版不改资金计算（钱包、结账、交班、日结、对账包的口径都不变），但**岗位权限从写死在代码里变成店主可在后台调整**，属于「越权」相关改动，验收时重点核对第 4 节。门禁为 T0（每个 PR）；测试会话在独立演示库预检，店主安排的 AI 在测试服演示库上按第 5 节过一遍页面。

## 1. 范围

| 项 | 内容 |
| --- | --- |
| 管理后台 | 主导航「管理」改为「后台」，进入单独的一套页面（左侧分区，窄屏在顶部横排；顶栏常显实例标识与「版本 + SHA」；「返回前台」）。新分区：后台首页、规则总表、会员与渠道、岗位权限；原有分区（经营规则、价目与套餐、手牌与前台、员工账号、期初导入、操作审计）地址不变 |
| 岗位权限 | 岗位 × 权限可勾选，保存后立即生效；存为相对默认的增减（`settings.role_permissions`）；店主一栏固定；管理员工账号、修改经营规则、导入期初只属于店主 |
| 新岗位 | 客户经理（`account_manager`）：查找、建档、充值、当日流水、会员总览；不做前台收银 |
| 会员 | 渠道来源（`members.channel`，选项在后台维护）；会员详情：会员号、注册时间与经办人、渠道、等级卡片（当前等级与名称、达到时间、到下一级差额、升降级记录、有效期）、赠金明细（可用 / 已用完 / 已过期）；各级名称可在后台设置 |
| 看板 | 今日（新增分时、部门构成、在店最久）、经营总览（任选时段、环比）、会员总览；按权限显示，每人可设默认页 |

## 2. 迁移与数据

- 迁移 `019_admin_members.sql`：`members` 加 `channel`（可空，格式 `c` + 数字）与按建档时间的索引；员工岗位约束加上 `account_manager`。只加不改，旧数据不动：已有会员的渠道为空（显示「未登记」）。
- 新设置项都有代码默认值，迁移不写入：`member_channels`（渠道选项）、`role_permissions`（岗位权限的增减，没有时按默认）、前台规则里的 `vipLevelNames`（各级名称）。
- 演示数据没有改（`src/server/seed*.ts` 归测试会话）：演示会员没有渠道，会员总览的渠道一栏只有「未登记」。需要时测试会话可以给演示会员补上渠道。
- 前台演示数据的固定预期（`src/server/demo/frontdesk-expected.json`）的前台规则多了 `vipLevelNames`（看板接口原样返回前台规则）。

## 4. 验收要点（越权是阻断项）

| # | 操作 | 预期 |
| --- | --- | --- |
| P1 | 店主在后台「岗位权限」取消值班经理的「查看历史营业日」并保存 | 值班经理（已登录的会话也一样）下一次请求起：`GET /api/ledger?date=<历史日期>` 403，流水页没有「前一天」；`/api/auth/me` 的权限里没有这一项；其他岗位不变。恢复默认后照常 |
| P2 | 店主想把「管理员工账号」「修改经营规则」「导入期初」勾给店总 | 这三行只有店主一栏可勾（带锁）；直接调接口返回 400「只属于店主」；手工往 `settings.role_permissions` 写入也不生效 |
| P3 | 值班经理、店总调用 `PUT /api/admin/permissions` | 403（店总能看不能改） |
| P4 | 店主给值班经理加上「当场授权超过单笔上限」 | 值班经理可以签发超限授权；签发后店主又收回，这次授权在充值 / 消费核销时作废（`GRANT_INVALID`） |
| P5 | 客户经理账号（新建岗位「客户经理」） | 能建档、充值、看会员总览；前台、结账、消费扣款、经营总览、后台都 403 / 看不到 |
| P6 | 店员、后勤打开 `/admin` | 回到首页；接口 `/api/admin/*` 403 |
| P7 | 值班经理打开后台 | 只看到后台首页与「手牌与前台」（维护手牌池）；前台规则卡片不显示（只有店主能改）；后台首页没有变动记录 |
| M1 | 后台「会员与渠道」新增渠道、停用一个旧渠道 | 新渠道按顺序编号；停用的渠道新建会员不能再选，已登记的会员编辑其他资料时保留原渠道；渠道不能删除、名称不能重复 |
| M2 | 会员详情 | 会员号、注册时间与经办人、渠道、等级卡片（达到时间、「再充值 ¥X 升至 …」、升级记录）、赠金明细；改「各级名称」后详情与会员总览随之改变；VIP 柜核对与改之前一致 |
| D1 | 看板 | 店主有「今日 / 经营总览 / 会员总览」；店员只有今日，直接打开 `/dashboard/overview` 回到今日；经营总览选「今天」时净营业额、结账客人与今日一致，应收 = 日结营业额（净额），部门构成合计 = 应收 |
| D2 | 手机（393 宽）打开看板三页与后台首页、规则总表 | 不横向滚动；后台顶栏常显实例标识与版本 |
