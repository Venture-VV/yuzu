## 3. 环境与配置

yuzu 的 `.env`（只在要接小程序的实例上加，见 `.env.example`）：

| 变量 | 说明 |
| --- | --- |
| `MP_PORT` | 小程序端口，例如 `8081`；不设就不开。只让网关经 Tailscale 连，不对公网 |
| `MP_HOST` | 默认 `0.0.0.0` |
| `MP_GATEWAY_KEY` | 网关密钥，32 位以上；与网关的同名变量一样 |
| `MP_CODE_SECRET` | 会员码签名密钥，32 位以上；不设时会员码返回 503（请到前台报手机号），其余照常 |

网关（`node dist/gateway/index.js`，与 yuzu 同一个镜像里就有）：

| 变量 | 说明 |
| --- | --- |
| `MP_UPSTREAM_URL` | yuzu 的小程序端口，例如 `http://<门店的 Tailscale 地址>:8081` |
| `MP_GATEWAY_KEY` | 同 yuzu |
| `MP_SESSION_SECRET` | 网关会话的签名密钥，32 位以上，只在网关 |
| `WX_APPID`、`WX_APPSECRET` | 小程序的 AppID 与 AppSecret（只放网关服务器的 `.env`） |
| `MP_MOCK_WECHAT` | `true` 时用模拟微信（只给本机与测试服的演示库）；正式、演练的 yuzu 拒绝模拟绑定 |
| `GATEWAY_PORT`、`GATEWAY_HOST` | 默认 `8300`、`127.0.0.1`：前面放本机的 HTTPS 反向代理（Caddy 或 nginx，备案域名的证书），公网只开 443 |
| `GATEWAY_TRUST_PROXY` | 有反向代理时设 `true`，按真实 IP 限流 |
| `MP_SESSION_DAYS` | 会话天数，默认 7（MP11） |

网关服务器的部署（Codex 负责，等域名备案下来）见 [`DEPLOY_GATEWAY.md`](DEPLOY_GATEWAY.md)：单独的小镜像（只有打包好的网关一个文件）、Caddy 管 HTTPS，公网只开 443，Tailscale 只放行网关到 yuzu 的小程序端口；正式、测试两个网关进程（测试网关连测试服的演示库，正式网关等 yuzu 正式切换后再开）。yuzu 那边在 `.env` 里叠加 `compose.mp.yaml` 开小程序端口。小程序后台的 request、downloadFile 合法域名填网关域名。网关容器的健康检查用 `/v1/live`（不问门店，门店断外网时网关照样健康）。

## 5. 验收要点

1. **只认网关**：员工端口（8080）上没有 `/api/mp/*`；小程序端口不带网关密钥一律 401；小程序端口上没有员工会话、后台和静态页面。
2. **默认关闭**：开关关着时公开接口与会员接口都是 403 `MP_DISABLED`（网关健康检查除外）；店员、客户经理进不了后台「微信小程序」，值班经理能看（管解绑）不能改内容。
3. **绑定**（MP3、MP6）：手机号对不上会员不建会员；一个微信、一位会员同时各只有一条有效绑定（并发也不会多出一条）；操作编号重提不重复；冻结的会员能看不能用会员码；模拟绑定在 trial、production 实例被拒绝。
4. **只给顾客该看的**：会员卡、流水、券里没有手机号、经办人、单号等内部字段；导览只到区域，没有房号、房态、人员。
5. **会员码**（MP9）：每 60 秒换，前一分钟的也认；改一位、过期、解绑后、冻结都认不出；签名里有当前有效的绑定记录编号，换绑到别的微信后旧微信的码也认不出；只用来认人，不代替用储值付款时的核对。
6. **结果待确认**：小程序绑定、后台新建轮播在断网或超时后不会多绑、多建，也不会在告诉对方「没绑上」之后又绑上：作废登记之后原请求晚到被拒（`OP_ABANDONED`）；已经生效时作废只返回查回的结果。后台的解绑、改开关与内容刷新后照样显示待确认；改开关与内容放弃之后，原来那次晚到因为版本号对不上被拒（`VERSION_CONFLICT`），例如没收到结果的「开放」放弃后不会再把小程序打开。本机的记录读不出来时，小程序不能绑定、后台不能新建、修改或解绑，原来的记录不会被盖掉。
7. **不影响主线**：迁移 043、044 只建新表；`check` 全部 ✓；升级测试通过；小程序线没有改 yuzu 的版本号与主线负责的模块。
8. **页面**（本地 AI、真手机）：照品牌书与 VI（米白亚麻底、木色 `#937051`、细线与留白、英文小标题大写加字距、版头大图加标志）；门店连不上时展示内容标「之前的信息」、会员相关显示「门店系统连接中」；会员码页调亮屏幕、不息屏，离开后恢复。
