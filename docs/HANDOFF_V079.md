# v0.7.9 交接说明 · 飞书需求 RQ-005 第三步：采购台账与四个视图、导出、12 条账目自检

RQ-005「采购与费用闭环」的第三版：11 月起的新账有台账、视图、导出与自检。设计见 `docs/LEDGER.md`；默认口径（待确认）见 `docs/PENDING_DECISIONS.md`「台账、四个视图与账目自检」。8–10 月旧账只读对照拆到 v0.7.10（迁移 `028`）。

- **没有迁移**：都是对已有单据的查询；「约定到货天数」存在已有的费用报销规则里（没设置过的按默认 7 天）。
- **只读**：台账、自检、下单物料、导出都不改数据；导出记审计日志。
- **阻断项**：台账与单据对不上（漏笔、重复、金额或日期错）、导出的 Excel 丢图或打不开、越权（店员看到台账、部门申购导出、物资经办导出台账）、破坏费用报销 / 备用金 / 采购 / 需求单原有流程。

## 1. 范围

| 项 | 内容 |
| --- | --- |
| 采购台账 | ERP「费用与备用金 → 采购台账」：按日期逐笔列打款、已确认报销的每一行、退回与补付，每天小计，合计按全部算；导出 CSV（逐笔 + 合计） |
| 账目自检 | ERP「费用与备用金 → 账目自检」：12 条规则逐条列出，分「录入时拦截」与「每日预警」，点开看是哪几张单 |
| 下单物料 | 「采购 → 下单物料」：已确认的采购单每一行的缩略图、规格、已到 / 未到、应到日期，超期标红；导出带图片的 Excel 与 CSV |
| 需求单 | 按提交日期筛选；导出 CSV（每一行需求带进度与采购单号） |
| 规则 | 费用报销规则加「下单后几天没到货算超期」（默认 7 天） |
| 权限 | 台账、自检：查看费用（店主；物资经办、采购经办、对账付款、成本核算、负责人）；台账、需求单导出：导出费用（店主、对账付款、成本核算、负责人）；下单物料与导出：查看库存 |

## 2. 验收要点

| # | 操作 | 预期 |
| --- | --- | --- |
| L1 | 登记一笔打款、用这笔钱的报销（两行）、一笔公司直付的报销、一笔退回，打开采购台账 | 当天逐笔看到打款、三行支出、退回；每天小计与合计 = 各笔之和；点单号打开对应的打款或报销单 |
| L2 | 导出台账；按部门筛选后再导出 | CSV 逐笔一行，末尾有合计；Excel / WPS 打开不乱码；按部门筛选的只有这个部门的笔（笔数上限也只数这些）；物资经办导出 403 |
| L3 | 打开账目自检 | 第 1、5、6、7、8、11、12 条（录入时拦截）都是「没有问题」 |
| L4 | 用备用金按次报销（没有采购单） | 第 2 条列出这张报销单，点开能打开 |
| L5 | 打款后不退回；把打款日期登记成 10 天前 | 第 3 条列出那个付款日与部门（未退回金额）；第 4 条列出超期的打款 |
| L6 | 采购单预计到货日填过去的日期、确认后不收货；没填预计日的，在规则里把约定天数改成 1；再建一张下单日期一年多以前、没收货的采购单 | 第 9 条列出这些行（一年多以前的也在）；下单物料「超期」里能看到，标红 |
| L7 | 同一物料同一天下两张采购单 | 第 10 条提示 |
| L8 | 部门档案里建一个「前厅/水吧」 | 第 7 条列出这个部门 |
| L9 | 采购单行挂一张手机照片后确认，下单物料导出 Excel | Excel（或 WPS）里那一行的第一列能看到图片，图片随文件走（拷到别的电脑仍在）；CSV 写图片张数 |
| L10 | 需求单按提交日期筛选、导出；成本核算在采购台账页「导出需求单」 | 列表只剩这段日期的；CSV 每一行需求一行，带进度，提交时间是门店时间（凌晨提交的不会写成前一天）；成本核算进不了需求单页，但在台账页能导出；部门申购导出 403 |
| L11 | 平板、手机打开三个新页面 | 不横向滚动 |
| L12 | 从 v0.7.8 的演示库升级 | 没有迁移；`check` 全 ✓；采购单、报销、备用金不变 |
| L13 | 报销（或备用金打款）提交时请求卡在路上，关掉页面再打开；在「结果待确认」里按原内容重新提交，让服务端明确拒绝（例如临时去掉职责）；之后原请求才登记 | 重提被拒后记录保留、标成结果不明，这一行写明「之前那次提交可能仍会登记」，不能另填一张；原请求登记后点「查回结果」找到它，只有一张单（v0.7.8 上会重复登记） |
