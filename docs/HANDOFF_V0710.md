# v0.7.10 交接说明 · 飞书需求 RQ-005 收尾：8–10 月旧账只读对照；班次跨营业日提醒

RQ-005「采购与费用闭环」的最后一版：店主的四份原始 Excel 按原样导入只读表，不进正式账、不参与 11 月起的统计；核验按「账目问题清单」重算。设计见 `docs/LEGACY_LEDGER.md`；默认做法（待确认）见 `docs/PENDING_DECISIONS.md`「8–10 月旧账只读对照」「班次跨营业日的提醒」。

- **迁移 `028`**：旧账导入记录与六张只读表；只加表，不改已有数据。
- **只读、不进正式账**：费用报销、备用金、采购台账、账目自检、日结、`check` 的原有各项都不读旧账表；`check` 新加一项「旧账只读表与导入记录一致」。
- **原始文件是真实业务数据，不进 Git**；验收用合成样例（`legacy-samples` / `seed-legacy-demo`），每一个数写在 `src/server/demo/legacy-expected.json`。门店正式库导入原始文件须店主同意；**测试服演练库不导入原始文件**。
- **阻断项**：旧账的数进了正式账或统计、导入改了原值、只读表能改能删、越权（店员看到旧账）、核验的数与固定预期不一致、破坏原有功能。

## 1. 范围

| 项 | 内容 |
| --- | --- |
| 导入 | `import-legacy <文件.xlsx> --operator <店主账号>` 默认只预览（认出是哪份表、每张表多少行、核验结果），`--apply` 写入；同一个文件再导入返回原来那次；换文件要 `--replace "原因"`；`void-legacy-import <编号> --operator <店主账号> --reason <原因>` 作废 |
| 页面 | ERP「费用与备用金 → 旧账对照」（`/erp/legacy`）：核验、采购台账、付款台账、采购物资明细、已下单物料（原图）、品牌寻款清单、导入记录 |
| 合成样例 | `legacy-samples <目录>` 写出四份；`seed-legacy-demo` 导入演示库（试用 / 正式环境拒绝） |
| 班次跨营业日 | 本人还没交班的班次从前一个营业日开到现在：前台与交班页顶部提醒先交班，只提醒、不拦截 |
| 日期提示 | 查询接口缺日期或格式不对，提示中文（「请填写日期（YYYY-MM-DD）」等） |
