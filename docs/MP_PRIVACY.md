# 小程序「用户隐私保护指引」草稿（店主在小程序后台照填；小程序线）

微信要求：小程序用到手机号这类「隐私接口」之前，要在小程序后台「设置 → 服务内容声明 → 用户隐私保护指引」写明收集什么、做什么用、存多久、怎么联系开发者；顾客同意之后接口才能用，代码审核时也会核对。本稿按第一期（只读）的代码实际用到的写，**标「店主定」的几处要店主填**；以后第二、三期加了功能（例如线上充值、预约），小程序线先改这一稿，店主再到后台更新。

后台的栏目与选项以微信后台当时的页面为准；那一页会列出代码里检测到的隐私接口，与下面第 1 条对不上时以后台为准，并告诉小程序线。

## 1. 小程序用到了哪些隐私接口（按第一期的代码）

| 接口 | 在哪 | 做什么 | 要不要写进指引 |
| --- | --- | --- | --- |
| 手机号快速验证（`<button open-type="getPhoneNumber">`） | 「我的」页「用微信手机号绑定」「换个手机号」 | 微信验证过的手机号等于会员档案的手机号，就绑定这位会员（`MINIPROGRAM.md` 第 4 节） | **要**：收集你的手机号 |
| 微信登录（`wx.login`） | 打开小程序时 | 换出这个小程序里的用户标识（openid），网关发 7 天的登录会话 | 不是隐私接口；写进补充说明（第 3 节） |
| 查看门店位置（`wx.openLocation`） | 首页门店信息里的「导航到店」 | 用微信地图打开**门店**的位置，不读顾客的位置 | 不是读取位置的接口，不用写 |
| 拨打电话、调亮屏幕、预览图片 | 联系门店、会员码页、价目与导览的图片 | 不收集信息 | 不用写 |
| 微信支付（`wx.requestPayment`，第二期 2a） | 「我的 → 充值」 | 调起微信支付付款；银行卡、支付密码都在微信支付里，小程序和门店都拿不到 | 不是隐私接口；充值单写进补充说明（第 3 节） |
| 订阅消息（`wx.requestSubscribeMessage`，第三期 3a） | 「我的券」、会员卡、余额页的「到期提醒我」 | 顾客在微信的弹窗里同意一次，门店系统记下这次同意，到时候经网关发一条到期提醒（一次同意只发一条） | 不是隐私接口；写进补充说明（第 3 节第 5 条） |
| 手机号快速验证（第三期 3b） | 好友打开邀请卡片后的「验证手机号领取」 | 验证过的手机号用来找会员档案；还不是会员的，用这个手机号和好友自己填的姓名当场开卡，顺带绑定这个微信 | **要**：与绑定同一项「手机号」，用途补上「领取好友的邀请」（第 2 节） |
| 分享（`open-type="share"`，第三期 3b） | 「我的 → 邀请好友」的「发给好友」 | 分享卡片里只有邀请码，不带手机号、会员信息 | 不收集信息，不用写 |
| 扫码（`wx.scanCode`，第三期 3c） | 「我的 → 点餐」的「扫桌码」 | 调起微信的扫一扫读桌上的点餐码（只认本店的桌码），小程序不拍照、不存图片 | 以后台当时列出的接口为准：后台若把扫码列为隐私接口，按「摄像头」一项填，用途写「扫桌上的点餐码」；点的菜写进补充说明（第 3 节第 7 条） |

没有用：头像昵称、位置、相册、摄像头组件、麦克风、剪切板、通讯录、蓝牙、微信运动、地址、发票。

## 2. 后台每一栏怎么填

| 栏目 | 填什么 |
| --- | --- |
| 开发者处理的信息 | 添加一项：**手机号**。用途写：「绑定你在汤崎的会员档案，用于在小程序里查看会员卡、余额与消费记录、券和本月可享，并出示会员码；领取好友的邀请时，用来找到或当场开立你的会员档案」 |
| 存储地点 | 境内：门店系统（深圳宝安店的服务器）与小程序网关（阿里云深圳） |
| 存储期限 | 「绑定期间保存；解绑后绑定记录再保存 3 年，用于核对会员服务，期满删除」（店主 2026-11-04 定：按法规的最长期限。说明见本表下面） |
| 信息对外提供 | 不对外提供（不共享、不转让给第三方） |
| 你的权益（后台自带的撤回授权说明之外） | 「你可以随时到门店前台解除小程序与会员档案的绑定；解绑后小程序不再显示你的会员信息。查看、更正会员信息也请到前台办理。」 |
| 联系开发者 | 宝安店前台的电话：与小程序首页「联系门店」的电话是同一个，即店主在后台「微信小程序 → 门店信息」里填的那个（店主 2026-11-04 没有另指定人，按默认） |
| 补充文档（选填） | 可以把第 3 节整理成一份上传 |
| 更新日期、生效日期 | 填写当天 |

**保存期限为什么是解绑后 3 年**：店主说按官方规定的最长时限。法律没有规定个人信息「最长」能存多久，《个人信息保护法》第十九条反过来要求：保存期限应当为实现处理目的所必要的**最短**时间，法律、行政法规另有规定的除外。能找到明确年限依据的，是《电子商务法》第三十一条：交易信息自交易完成之日起保存不少于三年。所以取 3 年：绑定期间要用它认人，解绑之后再存 3 年，用于核对会员服务、处理纠纷，期满删除。会员档案与储值流水是门店的账目，按账目的规定保存，不在这份指引里。

- **到期删除（已做，迁移 `050`，2026-11-04）**：门店系统每小时清一次（`src/server/modules/mp/retention.ts`）。
  - 解绑满 3 年的绑定记录：手机号、微信标识（openid）清空，解绑原因换成「解绑满 3 年，已清除」（原因是员工写的，可能写了手机号），记下清除时间。记录本身留着，后台写「已清除」。
  - 同一条绑定下的线上充值单、领券记录、到期提醒的同意：去掉微信标识，单子与记录照留（会员档案与储值是门店的账目，按账目的规定保存）。
  - 「结果待确认」的作废登记（只在当时有用）满 3 年的删掉。
  - 各表的触发器只放开这几种改法：清除过的不能再改，没满 3 年的、还绑着的清不了。
- 依据：[个人信息保护法（国家网信办）](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)第十九条；[电子商务法（国家网信办）](https://www.cac.gov.cn/2018-09/01/c_1123362506.htm)第三十一条。

## 3. 补充说明（全文草稿，可作补充文档）

> **汤崎 TOUCHILL 小程序 · 个人信息说明**
>
> 本小程序由汤崎（宝安店）提供，用来查看门店信息、价目与楼层导览，以及已在门店办理会员的顾客查看自己的会员信息。
>
> **我们处理哪些信息、做什么用**
> 1. **微信用户标识**：你打开小程序时，微信给出你在本小程序里的用户标识，用来识别你、保持登录。登录状态最多保持 7 天，里面只有这个标识。
> 2. **手机号**：你点「用微信手机号绑定」并同意后，微信把验证过的手机号交给我们。手机号与你在门店登记的会员手机号一致时，小程序与你的会员档案绑定；不一致时不绑定、不建新档案，请到前台办理。一个微信只能绑定一位会员，一位会员也只能绑定一个微信。
> 3. **会员信息**：绑定之后，小程序显示门店会员系统里你的会员卡、余额与消费记录、券、本月可享，并生成动态会员码（每 60 秒更换，只用于在前台认出你，不代替付款时的核对）。这些信息来自门店，小程序只读、不修改，也不存在你的手机上。
> 4. **线上充值的订单**：你在「充值」里下单时，门店会员系统记下这张充值单（会员、金额、套餐、下单与到账时间、微信支付的交易单号）。付款由微信支付处理，银行卡、支付密码等支付信息门店拿不到；到账以后与前台充值记在同一本账上。
> 5. **到期提醒**：你点「到期提醒我」并在微信的弹窗里同意后，门店会员系统记下这次同意（哪张券、会籍或赠金，哪天提醒），到时候发一条微信消息提醒你。一次同意只发一条；不同意就不会发。
> 6. **邀请好友**：你发出邀请时，门店会员系统记下邀请码、有效期与谁领了；你在邀请记录里只看到好友名字的第一个字。好友领取时要用微信验证手机号；好友还不是会员的，用这个手机号和好友自己填的姓名在门店开卡（与到前台开卡一样），并绑定领取用的这个微信。
> 7. **扫码点餐**：你在店里点餐时，点的菜、份数、金额和口味备注记在你手牌的账单上，送到哪张桌写在厨房的出品单上，与服务员点单一样；结账照旧在前台。扫桌码只读桌上的码，不拍照、不存图片。
> 8. **预约**：你在小程序预约技师或派对房时，门店会员系统记下这张预约（项目、技师号或房间、时间、人数、备注），与打电话预约一样由前台确认、到店核对；你可以在「我的预约」里查看、在开始前按规则取消。没按时到店的记一次爽约，次数多了一段时间内不能在小程序预约。
>
> **存在哪里、存多久**
> - 绑定记录（用户标识、手机号、绑定时间）存在门店会员系统，与你的会员档案一起保存在境内；绑定期间保存，解绑后再保存 3 年，期满删除。
> - 线上充值的充值单、点餐记录、预约是门店的账目，与前台的单据一样按账目的规定保存；到期提醒的同意、邀请记录不另存手机号，绑定记录解绑满 3 年清除时，一并去掉里面的微信标识。
> - 你的手机上只保存登录状态（最多 7 天）与门店信息、价目、导览的副本（最多 7 天，门店系统连不上时先显示旧的）。
> - 小程序网关（境内的云服务器）只转发请求，不保存你的手机号与会员信息；它的运行日志里有访问的时间、路径与 IP，用于排查故障，滚动覆盖。
>
> **谁能看到**：门店有相应权限的员工在会员系统里能看到你的绑定记录。我们不向第三方提供、出售你的信息。
>
> **你的权利**：可以到门店前台解除绑定（解绑后小程序不再显示你的会员信息），查看、更正会员信息也请到前台办理；也可以在小程序右上角「…」→「设置」里撤回对手机号的授权。
>
> **未成年人**：不满 14 周岁的未成年人请在监护人同意并陪同下到前台办理会员与绑定。
>
> **联系我们**：宝安店前台电话【填门店信息里的电话】
>
> 更新日期：【填写当天】

## 4. 顾客那边会看到什么

按微信现在的做法，顾客第一次点「用微信手机号绑定」时，微信会先弹出本小程序的用户隐私保护指引请顾客同意，同意后才出现手机号授权（具体以微信当时的规则为准）。第一次上传体验版后，在真手机上走一遍、截图发在 PR 上：弹出的指引内容与本稿一致，拒绝后不会绑定、页面提示照常。
