# 后台整体 UI 优化 · 动效套件（8.0.16）

店主 2026-11-13：「8.0.16，我希望你对整个后台系统的 UI 进行优化，可以参考 github 上 motion harness 这个项目，学习参考，一些好的动效套件内化到我们的项目里。」

这一版做**怎么动、怎么顺**：把一套动效规矩做进公共部件（弹窗、抽屉、提示、菜单、分段开关、按钮、卡片、表格、导航、页面切换、加载占位），所有页面跟着生效。页面放在哪、怎么收纳是 8.0.17 的事，这一版不挪入口。默认规则 UI3–UI9 在 `PENDING_DECISIONS.md`「8.0.16」。没有迁移，不改接口。

## 1. 参考了什么

GitHub 上叫 motion harness 的项目不止一个，开工前读了三个（都是 MIT 许可；只学做法，没有搬代码、没有加依赖）：

| 项目 | 是什么 | 学到的 |
| --- | --- | --- |
| `mad-helpers/motion-harness` | 用 GSAP 生成动效视频的流水线，带一份「动效守则」 | 不用匀速；进入用明显的缓出、退出要快；同一块内容朝同一个方向动；字要停留够久才看得完；对比度够 |
| `bilbillm/dsh-motion` | 给一个网页应用加「克制的、按语义来的界面动效」的插件 | 只动透明度、位移、缩放、颜色；进场与退场成对；退场用一份不能点、读屏不念的副本播完就删；列表筛选、刷新时不重复播进场；系统「减少动态效果」时关掉；不加设置页、不开常驻的动画循环 |
| `Scorp1o117/dsh-motion-ui` | 把回答变成可交互图解与动画的插件 | 控件的变化在本地马上有反应，不等服务器 |

如果店主说的是别的项目，告诉我仓库地址，我对照着补（UI3）。

电子菜单 8.0.13 的动效（退场的影子、缓出曲线、减少动态效果时全关）已经是同一个路子；这一版把它整理成全站共用的一套。

## 2. 规矩

1. **只动四样**：透明度、位移、缩放、颜色。高度只在页面上的折叠块展开、收起时动。不动会引起整页重排的属性。
2. **不用匀速**。进入：缓出（先快后慢，像落定）；退出：比进入快（约六成的时间），不拖。
3. **进出成对**：弹窗、抽屉、菜单、提示条关掉时都有退场。做法是「影子」——页面逻辑照旧马上把它卸掉（不会有两份能点的弹窗，关掉以后马上能点后面的页面），卸掉前复制一份放进页面最后面一个「关着的」容器里播退场，播完自己删掉。关着的容器从外面查不到里面的东西：按文字、按标签找不到影子，读屏不念，浏览器用例也认不到（刚关掉的弹窗里有一个「保存」、页面上也有一个「保存」，不会变成两个）。影子只是个样子：输入框带着当时的值，「选文件的框」不带（浏览器不让程序写它；8.0.16 这里写了，选了文件再关弹窗整页报错，8.0.17 修）；留影子时出任何错都只是不播退场，不影响页面。
4. **方向一致**：抽屉从右边来、回右边去；弹窗从下面略微升起、退回去；提示条从右边进、往右边出。换页面时内容区只淡入、不带位移（位移会让页面里固定定位的东西跟着跳，也会让滚动条闪一下）。
5. **只在出现时播一次**：列表筛选、定时刷新、翻页不重播进场；一次进场最多带前 12 项依次出现，后面的直接显示。
6. **有反应**：按钮按下去有一点缩，能点的卡片悬停时浮起一点，分段开关与导航的滑块滑过去——都在 0.2 秒内，不挡操作。导航里离得远的（隔了三四项以上）不横扫过去，直接在新位置淡入。
7. **字要看得完**：提示条停留的时间按字数算（至少 3.6 秒，每多 10 个字加 0.6 秒，出错的至少 6 秒，最长 10 秒）。
8. **尊重系统设置**：系统开了「减少动态效果」时全部关掉（原来就有，新加的都遵守）。
9. **不加依赖**：全部用 CSS 与浏览器自带的动画接口，不引入动画库。

时间与曲线（`src/client/styles.css` 里的变量）：

| 名称 | 值 | 用在 |
| --- | --- | --- |
| `--dur-micro` | 120ms | 按下、悬停、颜色 |
| `--dur-fast` | 180ms | 退场、菜单、滑块 |
| `--dur-base` | 260ms | 弹窗、提示条、页面内容进场 |
| `--dur-slow` | 380ms | 抽屉、折叠块 |
| `--ease-out-soft` | `cubic-bezier(0.22, 1, 0.36, 1)`（原有） | 进场、滑块 |
| `--ease-out-expo` | `cubic-bezier(0.16, 1, 0.3, 1)` | 抽屉、页面内容 |
| `--ease-in-quick` | `cubic-bezier(0.4, 0, 1, 1)` | 退场 |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 勾选、数字角标这类小东西的回弹 |

## 3. 套件（`src/client/lib/motion.tsx`）

| 部件 | 作用 |
| --- | --- |
| `useExitGhost` | 这一层卸掉时留一个影子播退场（规矩 3） |
| `Stagger` | 一组卡片、一列行依次出现（规矩 5） |
| `useSlidingIndicator` | 分段开关、导航里跟着当前项滑动的那一块 |
| `usePageEnter` | 换页面时内容区淡入（不重新挂载页面，不丢页面上填的东西） |
| `dwellMs` | 按字数算提示条停留多久（规矩 7） |

样式表里另有几个直接能用的类：`mo-lift`（能点的卡片悬停浮起）、`mo-shimmer`（加载占位的微光）、`animate-dialog-in` / `animate-sheet-in` / `animate-toast-in` / `animate-menu-in` / `animate-notice-in` / `animate-tick`（各种进场）。新页面直接用这些，不另写一套。

## 4. 用在哪

公共部件改了，所有用到它的页面一起生效：

| 部件 | 现在 | 这一版 |
| --- | --- | --- |
| 弹窗 `Dialog` | 淡入升起；关掉直接消失 | 遮罩淡入、面板略升并从 0.98 放到 1；关掉时面板略缩下沉、遮罩淡出 |
| 抽屉 `Sheet` | 从右滑入；关掉直接消失 | 滑入用更柔的曲线；关掉往右滑出 |
| 提示条 `Toast` | 升起；到时间直接消失 | 从右边滑入；到时间往右滑出；停留时间按字数 |
| 用户菜单等弹出菜单 | 升起；关掉直接消失 | 从按钮的位置放大出来；关掉缩回去 |
| 分段开关 `Segmented` | 选中的那格直接换底色 | 白色滑块滑到选中的那格 |
| 按钮 | 按下往下 1 像素 | 按下略缩；转圈与图标交替时不跳 |
| 能点的卡片、表格行 | 没有或直接变色 | 悬停浮起一点（卡片）、底色缓变（行） |
| 侧边主导航、后台与 ERP 的分区导航 | 当前项直接换底色 | 当前项的底块滑过去 |
| 页面切换 | 直接换 | 内容区淡入 |
| 加载占位 `Skeleton` | 整块明暗闪 | 一道微光扫过 |
| 勾选框、ERP 导航上的待办数字 | 直接出现 | 小幅回弹（数字变了再弹一下） |
| 状态横幅 `Notice`、空状态 | 直接出现 | 第一次出现时淡入略升 |
| 页面上的折叠块（`<details>`，全站 15 处） | 直接展开收起 | 高度平滑变化（Chrome / Edge 129 起；别的浏览器照旧，功能一样） |

另外在几处信息多的地方用上「依次出现」与「悬停浮起」：后台首页的概况卡片与入口、ERP 首页的模块卡片、数据看板的指标卡。

## 5. 不做

- 挪页面、改导航的层级（8.0.17）。
- 换配色、换字体、重画页面。
- 数字滚动（金额从 0 滚到实际数）：钱的数字不做会让人看错的中间值。
- 给后台加「动效强弱」的设置：跟系统的「减少动态效果」走。
- 平板点餐页：它有自己的一套（8.0.13），这一版不动。

## 6. 验收要点

1. 开、关一个弹窗与一个抽屉：进场、退场都顺，关掉后马上能点后面的页面；连着开第二个弹窗，新的画在正在退场的影子上面，不会卡住。
2. 提示条：从右进、往右出；字多的停得久。
3. 分段开关、侧边导航：滑块滑过去（导航里隔得远的直接淡入）；用键盘操作一样。
4. 系统开「减少动态效果」：全部没有动画，功能照常。
5. 全量浏览器用例照旧通过（退场用的是影子，不改变页面上「还在不在」的判断）。
