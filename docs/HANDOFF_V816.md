# v8.1.6 交接说明 · 平板电子菜单与工作台的二次整改

主线 [PR #123](https://github.com/Venture-VV/yuzu/pull/123)。店主 2026-11-17 转来《二次需求：平板电子菜单、工作台页面UI功能整改》，要求细致地做、改完在小米平板 6S Pro 12.4 上演示。设计 `docs/EMENU.md` 第 15 节，默认做法 `docs/PENDING_DECISIONS.md`「8.1.6」QZ1–QZ10（待确认）。**没有迁移**；顶栏的位置存在工作台版面的 `templates.header` 里（与 8.1.2 的卡片模板同一处）。不改账、不改下单与挂账的路径。

## 0. 升级后会看到的变化

- **3:2 的平板（小米平板 6S Pro 12.4）**：弹窗、抽屉、搜索的压暗层，起始页的底，菜品大图铺满整块屏，不再左右两条亮着；点两边也能关掉搜索、抽屉。4:3 的平板（iPad、1024 × 768）上看不出变化。
- **菜品大图**：设计师在工作台里加在菜单页上的装饰（字标、文字、图片）不再画到大图上面。
- **切到英文**：服务员那一步（确认下单被拒、「结果待确认」、「没有下成」、退出登录）英文在上、中文小字在下，弹窗长高一点；切换时整屏淡入淡出。
- **工作台**：「版式」最上面多了「顶栏」。没改过顶栏的版面，平板上与 8.1.5 一模一样。
- **后台「电子菜单」**：开着中英切换、还有没录英文的地方时，顶上写「英文还缺 N 处」。
- **「网络与同步」页**（`/network`）：多一行「本机屏幕」。

## 1. 范围

1. **页面错位 → 铺满屏幕（出血）**（QZ2）
   - `features/emenu/viewport.ts` 的 `stageLayout` 多算 `bleedX` / `bleedY`：屏幕比设计稿多出来的那一圈（设计稿像素）。小米平板 6S Pro 12.4（1355 × 903）放大 1.176 倍，左右各多出约 64。
   - `stage.tsx`：舞台分两层——外面一层铺满屏幕（在屏幕边上裁），里面一层仍是 1024 × 768 的设计稿（`data-emenu-stage`，位置不变、不裁）；`useBleed()`、`<Bleed sides=…>` 给要铺到屏幕边的底用。
   - 铺到屏幕边的：每一屏的底色、起始页的氛围图（整块占满画布时）、弹窗 / 抽屉 / 搜索的压暗层（`modals.tsx` 的 `Backdrop`，测试钩子 `emenu-backdrop-fill`）、订单与备注抽屉的底（往右）、菜品大图的照片（`emenu-detail-photo`）。不铺的：菜单页（`strip.tsx` 在设计稿那一块里裁，左右翻时不露相邻的页）、顶栏、弹窗本身。
2. **菜品大图单独一层**（QZ3）：`DishDetail` 从 `menu.header` 那一块里拿出来，画在整个菜单页（含设计师加的装饰、翻页圆点）之后，只让出顶栏那一条；顶栏里的四样照常能点。
3. **卡顿**（QZ4）
   - 菜单页 `memo(PageCanvas)`，每个分类一份稳定的上下文（点开、加菜的处理放在 ref 里）：开大图、开抽屉、加菜、弹提示不再重画整组页。
   - 点分类跳页：那一页用 Web 动画轻微放大缓入，不再换 key 重建（图片不重新出现）。
   - `brandFont.ts` 的 `warmEmenuFonts()`：开机就备好 Average Sans 与两个行框字体。
   - 分类光晕滑过去只动 `transform`。
   - 工作台：`model.ts` 的 `frameBatcher`，拖动、拉大小时每一帧最多交一次改动（`Canvas.tsx`、`TemplateCanvas.tsx`）。
   - CPU 降速 4 倍（这台虚拟机）量的长任务：开抽屉 73 → 0 毫秒、再点分类 105 → 0、关大图 50 → 0；开大图还有约 66 毫秒，主要是浏览器自己画大图（软件绘制），不是页面的脚本。
4. **中英切换顺滑**（QZ5）
   - `EmenuPage.tsx` 的 `toggleLang`：浏览器有 `document.startViewTransition`、后台开着动效、平板没开「减少动态效果」时，整屏交叉淡入 0.25 秒（`emenu.css` 的 `html[data-em-lang]::view-transition-*`，只在切语言那一下生效）；不然直接换。
   - `header.tsx`：分类名用页面上的字体在画布上量宽（`textWidth`，字体下载完再量一次）；放不下时整排缩小（最多到 `CAT_MIN_SCALE` 0.8），还放不下的末尾显示「…」。放得下时与原来一样。
5. **英文补齐**（QZ6）
   - `i18n.tsx`：`ERRORS_EN`（`errorEn(code)`，客人那一步沿用 `guestErrorEn`）、`uncertainEn(reason)`；`both(pick)` 两份词表各取一次，`bothText(t, lang)` 中文时只有中文、英文时「英文\n中文」。服务员那一步的提示在 `EmenuPage` 里存两种语言（`OpNote`），显示时按当时的语言挑。
   - `modals.tsx` 的 `BiText`：第二行（中文）小一号、淡一点（测试钩子 `emenu-zh-line`）；`ModalNote`、`Toast`、`SmallDialog` 都用它。`Frame` / `InfoModal` / `SmallDialog` 有 `extra`：英文时弹窗上下各长一半（确认下单 22、结果待确认 44、没有下成与退出登录 36）。
   - 剩下写死的中文都进了词表（打开菜单、连不上、平板点餐没开、没有排菜单、工作台预览、翻页圆点、数字键、弹窗标题的读屏名、字标的读屏名）。`store.ts` 的 `PENDING_STORE_FAILED` 挪进词表（`storeFailed`）。
   - 后台「电子菜单」：`@shared/emenu` 的 `emenuEnglishGaps(admin)` 列出启用的分类名、有小标题的版式里的页标题、排进启用分类的启用的菜（菜名、有中文介绍的介绍）、忌口与起菜方式（后台填的、系统自带的英文都没有的）、时段名里缺英文的（原文没有汉字的不算）；`EmenuAdminSection` 顶上「英文还缺 N 处」，「逐处看」→「去补」切到那个页签、打开那一处、光标放到那一格。
6. **右上角功能栏**（QZ7）：中英切换、搜索、订单、手牌在大图开着时照常能点；工作台里都能单独挪、改大小，不能删、不能藏。
7. **工作台：可编辑的顶栏**（QZ8、QZ9）
   - `@shared/studio` 的 `EMENU_HEADER_TEMPLATE`（`layout: 'header'`，六块 `logo` `cats` `lang` `search` `order` `tag`），数字照 8.1.5 的 `header.tsx` 写死的（原样与放大一档；用例核对两边一致）；`EMENU_ALL_TEMPLATES` = 11 种版式 + 顶栏，平板菜单的界面登记用它。
   - 平板：`templates.tsx` 的 `useHeaderSpots()`——版面里有 `templates.header` 时 `Header` 照各块的位置画（图标、手牌按高等比缩放；手牌原样一档左边贴住、放大一档右边贴住，与 8.1.5 一样），没有时照原来的写法画（逐像素一致）。各块带 `data-studio-head` 给工作台量位置。
   - 编辑器：`TemplateCanvas` 认 `layout === 'header'`——量 `data-studio-head` 的框；挪的时候往顶栏中线 55.45、左右页边 40 / 984、别的块上吸；字标、图标、手牌拉角等比缩放（0.5–2.5 倍），分类那一块拉左右两边改宽（最窄 120）；拖着或选中时画出与左右相邻两块（没有就是屏幕边）的间距线与数（`studio-gap-left` / `studio-gap-right`，`data-gap`），叠住了标「叠 N」；后台关了中英切换时那一块画成虚线框。
   - `features/studio/headerGaps.ts`：`headerGaps`（左页边、每两块之间、右页边，按框的中心从左到右排）、`editHeaderGap`（改一条只动那一条：分类左边的改了分类的左边收放，分类右边的改了右边一组靠右贴住、分类的右边收放；挪的量取到 0.1）、`neighborGaps`。
   - 右栏：`templatePanels.tsx` 的 `HeaderGapsPanel`（「间距」，`studio-head-gap-<n>`）；顶栏的块有「大小（%）」。左栏「版式」最上面「顶栏」（`studio-layout-header`）；菜单页选中顶栏那一块时右边「编辑顶栏」（`studio-open-header`）。
   - 核对（`check.ts`）：顶栏的每一块在顶栏那一条里（宽 1024、高 102）、等比缩放、0.5–2.5 倍、分类至少 120 宽，不过的存不进去；发布前的检查提醒两块叠在一起（黄）。
8. **「本机屏幕」**（QZ1）：`NetworkPage` 多一行——网页大小、像素倍数、约多少实际像素、平板点餐页按几倍显示、两边多出多少（`network-screen`）。

## 4. 验收要点（真机：测试服更新到 v8.1.6 以后，由店主或 Codex 在门店的小米平板 6S Pro 12.4 上走一遍）

1. 「网络与同步」页记下「本机屏幕」一行（网页大小、倍数），与第 15.1 节的数对一下。
2. 起始页、输入信息、搜索、订单抽屉、备注、确认下单、菜品大图、下单成功：底色与压暗层都铺到屏幕两边，内容的位置与 4:3 平板上一样；点两边空出来的地方能关掉搜索、抽屉。
3. 工作台在菜单页加一段字、发布；平板点开大图，那段字在大图下面，顶栏的四样照常能点；大图开着时切语言，大图里的菜名跟着换。
4. 切到英文：除了中文名的小字、门店没录英文的菜，看不到中文；确认下单被拒时英文在上、中文在下。
5. 工作台「版式 → 顶栏」：拖中英切换，间距线与数跟着变；右边把「搜索 ↔ 订单」改成 30，只有这一条变、右边贴着不动；发布以后平板上的顶栏与画布一样；「整个顶栏恢复默认」回到原样再发布一次。
6. 后台「电子菜单」：开着中英切换时顶上「英文还缺 N 处」，「去补」打开那一处。
7. 翻页、点分类、开大图、开抽屉、切语言：手感是否顺。真机比这台虚拟机快几倍，卡的话记下是哪一步。

## 5. 已知的限度

- 演示是在浏览器里按小米平板 6S Pro 12.4 的屏幕大小、像素倍数与触摸模拟的（QZ10），云端会话连不到门店的平板；真机上请按第 4 节走一遍。
- 门店没录英文的地方平板上照旧显示中文（不机翻，QZ6）。
- 顶栏的高（102）不能改；顶栏里加新的功能（例如「呼叫服务」）、换图标的样子要品牌方给样式再加（第 15.9 节）。
- 页面转场要浏览器支持（安卓 Chrome 111 起）；小米自带浏览器内核老的时候直接换，没有淡入。
