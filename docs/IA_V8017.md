# 后台架构重新整理 · 信息架构方案（8.0.17）

店主 2026-11-13：「对整个后台系统的架构进行重新整理，目前其实很乱，规则和规则不在一起，配置和配置不在一起，前台和后台混乱，erp 有一些非 erp 的功能，请你做重新搭建。并且现在很多地方，操作都不方便，没有类似一级页二级页，很多东西都一股脑放在一起没有收纳，请你也学习下 github 上好的 crm 的架构收纳逻辑，重新搭建。」

这份文档先讲现状哪里乱（盘点过全部页面），再讲整理成什么样、分几步做。**只动「东西放在哪、怎么进去」，不改业务规则、数据、接口**；旧地址全部自动跳到新地址。默认做法记在 `PENDING_DECISIONS.md`「8.0.17」（IA1–IA8，待确认）。

## 1. 现状哪里乱（盘点结果）

系统有三套外壳：门店（前台日常）、管理后台、ERP。

**规则散在 20 多处。**

- 后台：「规则总表」（只读汇总）、「经营规则」（一长页 5 张大卡、30 多项）、「会员规则」，另外手牌与前台、技师、餐饮、电子菜单、客房、预约、空间台账、小程序、券这些分区里各有自己的规则卡片。
- ERP：模块设置页里放着费用报销规则；采购规则藏在采购列表页的一个按钮后面；审批规则、付款规则各是某一页的一个页签；预算、备用金额度各是一个按钮进去的子页；食堂、巡场各有自己的设置页签。
- 「规则总表」并不全：付款规则、审批规则、预算、报销规则、采购规则、食堂与巡场的设置都不在里面。
- 「经营规则」里有一半其实是 ERP 的（审批、合同、供应链、应收的数值，库存与采购），却放在后台。

**配置（清单类的维护）与规则、日常操作混在同一页。** 例如「手牌与前台」一页里从上到下是：导入柜号、前台规则、按号段建牌、手牌池；「技师」是规则、名册、规则、规则、项目；「空间台账」的页签里又各有四五个小节。

**前台与后台互相串。**

- 门店主导航里有管理性质的入口：设备（监控与本机终端）、后台；管家页里藏着团队账号、常用项目、日志、备份。
- 后台里有天天要用的操作：批量发券、无记名券、停车登记、会员的微信解绑、打印任务、数据看板（值班经理每天看）。
- 「设备」在后台侧栏里根本没有入口（只能从后台首页的卡片进）。

**ERP 里不是 ERP 的**：员工食堂、安保巡场（行政后勤）；营业数据（与后台的数据看板重复）。另外应付货款是财务却归在供应链，审批中心是全店通用的流程却归在供应链。

**二级页的做法有四种，互不统一**：有的用地址里的子路径，有的用地址参数，有的只是页面里的分段开关（刷新就回到第一个），有的是一排按钮跳到子页面（采购 8 个、报销 6 个）；还有 9 个分区是一长页堆到底。

## 2. 参考了什么

看了几个开源 CRM / ERP 的收纳办法（Twenty、Odoo、ERPNext、EspoCRM），共同的几条：

1. **干活的地方与设置的地方分开**。每个业务有一个天天用的工作页，另有一个「设置」；设置集中在一处，不散在工作页里。
2. **设置按业务域分组，每个域里的顺序固定**：规则 → 清单（主数据）→ 导入与工具。到哪个域都一样，不用找。
3. **两级导航**：左边是一级（域），页面顶上是二级（页签），二级写进地址——能收藏、能刷新、能发给同事。
4. **一个总索引**：所有规则在一处能搜到、能点过去。
5. **列表 → 详情**：清单页只放清单，点进去才是这一条的全部内容。

- 员工食堂、安保巡场挪到后台「人员与行政」；营业数据并进后台的数据看板。ERP 导航里各留一条跳转（一个版本后去掉）。
- **8.0.18 做完后的样子**：ERP 设置的页签是「模块开关 · 采购规则 · 库存与审批开关 · 审批规则与代理人 · 付款规则 · 报销与备用金 · 其他数值」（备用金定额、预算额度在「报销与备用金」里各有一个入口，页面还在费用模块里）；代理人是日常要用的，审批中心里也留着。后台的分组「人员与权限」改叫「人员与行政」。
- 采购页的 8 个子页按钮、报销页的 6 个子页按钮改成与后台一样的二级页签。
- 各规则仍在原来的页面上也看得到入口（「规则在 ERP 设置里」的链接），不会找不到。

### 3.4 门店：只留当班要用的

- 主导航不变的：前台、钟房、餐饮、客房、预约、会员、管家、流水、日结、交班、导览、后台。
- **设备**：状态看板与测试打印留在门店（当班要看打印机好不好）；「本机终端」的设置同时放进用户菜单（哪一页都点得到）。
- **发券**：批量发券、无记名券是日常操作，从后台「券」挪到门店会员工作台的「发券」入口（权限不变）；后台「券」只留规则、模板、统计。
- **停车登记、会员的微信解绑**：同理是日常操作，入口放到会员工作台里对应会员的详情上；后台原处留一条跳转。
- 管家页里的团队账号、常用项目、日志、备份：这一版不动（管家部是从独立系统接过来的，单独排）。

### 3.5 二级页的统一做法

做一个全站共用的二级导航部件（页面标题下面一排页签）：

- 写进地址（`/admin/technicians/rules`），刷新、收藏、发给同事都到同一个页签；
- 页签上能带数字（待办）与「有没保存的改动」的提示，离开前提醒；
- 窄屏横向滑动；用 8.0.16 的滑块与淡入；
- 「规则总表」「去设置」的链接、后台首页的卡片都直接到页签这一级。

## 4. 不会变的

- 所有业务规则、数据、接口、权限的含义都不变；谁能看什么不变（挪过去的页面带着原来的权限）。
- **旧地址全部能用**：书签、文档里的链接、别的系统里存的地址自动跳到新位置。
- 页面里的表单、表格、按钮本身不重画（8.0.16 的动效照旧）。
