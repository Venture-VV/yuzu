# 待确认经营事项

系统里所有未确认的规则都使用**模拟规则**，并在界面上标注「待确认」。正式试用前需要店主逐项确认；确认后由维护人员按「修改位置」调整，并在这里记录结论与日期。

| # | 事项 | 当前模拟规则 | 候选 / 需要回答的问题 | 修改位置 |
| --- | --- | --- | --- | --- |
| 1 | **本金与赠金的扣款顺序** | 先本金，后赠金 | ① 先本金后赠金 ② 先赠金后本金 ③ 按当前本金:赠金比例扣除（零头计入本金）。三种都已实现并测试 | 页面「管理 → 经营规则」直接切换 |
| 2 | **实际充值与赠送方案** | 轻享 300（无赠送）/ 常泡 500 送 50 / 山野 1000 送 150 / 四季 2000 送 400 | 实际档位与赠送比例？赠金是否有有效期？ | 页面「管理 → 套餐与项目」 |

## 部署前需要核对

- [ ] Mac mini 型号、内存、磁盘空间；Docker Desktop / OrbStack 可用且开机自启
- [ ] Mac mini 在路由器上分配固定 IP；门店电脑与平板能访问 `http://<IP>:8080`
- [ ] 外置备份盘已挂载，`BACKUP_DIR` 指向它；做过一次实际恢复演练
- [ ] `.env` 中数据库密码、初始店主密码已改为强密码
- [ ] 断电 / 重启后服务能自动恢复
- [ ] 是否需要在局域网启用 HTTPS（当前为 http，适合封闭的门店内网）
