### 期初导入模板（EBC 导出用，2026-10-29 定义）

店主没有现成规范，EBC 导出后按下表整理：第一行是表头，列名照抄（空白模板见 [`docs/data/opening-template.csv`](data/opening-template.csv)），之后每位会员一行；用 Excel / WPS「另存为 → CSV UTF-8（逗号分隔）」。v0.3.3 起也能直接读 WPS / Excel 默认的 GBK 编码（自动识别），编码认不出或有乱码时报错、不导入。「管理 → 期初导入」与 `cli.js import-opening` 直接读这份文件，默认只预览。

| 列名 | 必填 | 格式 | 说明 |
| --- | --- | --- | --- |
| 姓名 | 是 | 文字 | 新系统里已有同手机号的会员时，姓名须一致 |
| 手机号 | 是 | 11 位数字 | 一人一个手机号；不合格或一号多卡的会员移到排除清单，到店建档后补导 |
| 旧卡号 | 否 | 最多 32 字 | EBC 卡号，留存备查 |
| 本金 | 是 | 元，最多两位小数，不能为负 | 没有余额填 0 |
| 赠金 | 否 | 同上 | 留空为 0 |
| 赠金到期日 | 否 | YYYY-MM-DD | 赠金最后一天可用的日期；留空为长期有效；已过期的行会报错 |
| 累计充值 | 否 | 元 | EBC 里累计充值的实收金额，只用于 VIP 柜等级，不计入充值实收 |
| 性别 | 否 | 男 / 女 | |
| 生日 | 否 | YYYY-MM-DD | |
| 备注 | 否 | 最多 200 字 | |

- 一个文件最多 5000 行；任何一行有问题整批不导入，预览列出行号和原因。
- 同时导出或打印 EBC 自带的总数报表作控制总数：会员人数、本金合计、赠金合计、累计充值合计。导入合计 + 排除清单合计 = 控制总数，否则不导入（v0.3.3 起预览自动比对：管理页填四个控制总数并可选排除清单，命令行用 `--control` 与 `--exclude`；不一致不能导入，正式环境必须填）。
- 真实文件不进 Git、不发给云端会话，只在店主电脑与正式服上处理。
