## 4. 验收要点

1. **卡片模板**：编辑器（平板电子菜单）左栏「版式」→ 选一种 → 拖一块、用数字定位置、给照片加圆角、藏一块；顶栏切「放大」单独挪一块；「这一块恢复默认」「整个版式恢复默认」；菜名价格那一块藏不了。发布以后平板上用这种版式的每一页都跟着变。
2. **菜的几种样子**：「版式」下面选已售罄 / 不可售 / 已下架，画布上这一页的菜变成那种状态；改成「左上角小标签」、换压暗颜色、黑白；恢复默认与设计稿一样。
3. **组件**：选中一块 ⌘/Ctrl+Alt+K 存成组件 → 「插入 → 组件」再放一处 → 「改组件」改一处、两处一起变 → 某一处「拆开」以后只改它；有人用的组件删不了。
4. **员工食堂**：后台「工作台 → 员工食堂」：首页调换几段的先后、藏一段、加一张图和一个按钮（打开柚子饭堂的一页）、换主题色 → 发布；员工账号在手机上打开柚子饭堂是新样子、饭卡码照常能扫；「亮出饭卡码」「按岗位的入口」「饭卡码」去不掉，饭卡码改不了大小。预览：员工账号在地址后面加 `?studio=预览码`。
5. **小程序的格式与样例**：`npx tsx scripts/studio-mp-samples.ts` 重新生成后与仓库一致（`tests/studio-mp-samples.test.ts`）；读取函数发布前返回空、发布后读得到、组件已经展开、图只给用到的。
6. **定时发布**：发布选「定时」、定在 10 分钟以后 → 顶上「几点几分换版」、版本列表「定在…生效」、平板与员工手机照旧用原来那一版 → 「撤销定时」以后不再生效；1 分钟以后、60 天以外的定不了；再定一版在 3 分钟以后、不撤，到点以后平板空闲回到起始页时换成它、版本列表里它变成「现在用的」。
7. **批注**：右栏「批注」→「加一条批注」→ 点画布写一句 → 另一个账号回复 → 标「解决了」以后画布上的圆点不见、「显示已解决的」里能重新打开；在「版式」里点「加一条批注」先回到普通画布；「别的屏」的点一下跳过去；后台「工作台」首页写着几条没解决。
8. **谁在改**：两个账号开同一个界面的编辑器，顶上写着对方「也在改」；关掉一个，一分钟内另一个顶上不再显示。
9. **中英文案**：「更多 → 中英文案」改英文 → 画布切 EN 看得到、可以撤销；「只看英文没填的」；导出 CSV 用 Excel 打开不乱码、改英文后「导回来」只改了那几处（字前后的空格原样回来）。
10. **设计包**：演示库「更多 → 设计包 → 导出设计包」→ 另一个独立库导进来，画布换成一样的、图都在、可以撤销，发布以后一致；改过的文件（图的内容和编号对不上）、别的界面的设计包被拒。
11. **权限**：设计师、店主能用上面所有；店员进不去工作台的接口（403）；撤销定时要「工作台：发布」。

## 5. 做过的反向验证

- 定时：1 分钟后、100 天后、写错格式的拒绝（`STUDIO_SCHEDULE` / 400）；已生效的（`STUDIO_ALREADY_LIVE`）、不是定时的（`STUDIO_NOT_SCHEDULED`）撤不了；撤过的再撤原样返回；店员 403。「到点前又发一版」：到点照样换成定时的那一版（按生效时间取，不按版本号）。
- 批注：同一操作编号改了内容 409；回复的回复 422（`STUDIO_COMMENT`）；回复不能单独标解决（404）；空的、太长的不收；店员 403。
- 设计包：别的界面的、图被改过的、少了图的拒绝（`STUDIO_PACK`）；导入不改草稿。
- 卡片模板、组件、员工食堂的核对：没有的版式与块、藏菜名价格、给文字加圆角、删掉的组件、功能块进组件、组件套自己、饭卡码改大小、去掉必需的块，都存不进去。
- 共用的 CSV 读法加了 `trim: false` 选项（中英文案用），默认照旧去空白：用到它的导入用例（会员期初、次卡、旧账、旧流水、OTA、银行流水、电子菜单英文对照）都过。

## 6. 已知的限度

- 「推荐」「新品」角标要后台先给菜加标记，没做（GZ24）；菜单页本身与顶栏的位置不动（GZ22）；员工食堂只开放首页、饭卡码页（GZ26）。
- 小程序里照版面画归小程序线：主线的样例与读取函数已交付（`docs/STUDIO_MP.md`），小程序那边接上以前小程序的样子不变。
- 换版的时机：平板每 15 秒问一次、空闲回到起始页时换；员工手机打开时、或从别的应用切回来（隔一分钟以上）时问；小程序线照 `docs/STUDIO_MP.md` 第 5 节每次进页面、回到前台问。
- 「谁在改」只记在应用进程里（重启清空；一家店一个应用实例足够），不锁、不拦，同时改照旧后存的提示刷新。批注不另发通知。
- 无头浏览器存下载文件时中文文件名会变成 `download`（真浏览器正常，见 `e2e/contract-templates.spec.ts` 的说明），用例只核对内容。
