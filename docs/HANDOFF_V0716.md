# v0.7.16 交接说明 · 飞书需求 RQ-004 第三段（上）：房态图

店主 2026-11-01 合并 v0.7.15 后开工 RQ-004 第三段。第三段拆两版：这一版 v0.7.16 做房态图（在第二段启用的那一批底图上按楼层画，颜色表达状态，点房间开房、查房、退房，按业态筛选），v0.7.17 做第一级实时位置。设计见 `docs/ROOMMAP.md` 第 2 节（定稿）；默认做法（待确认）见 `docs/PENDING_DECISIONS.md`「房态图」。

- **迁移 `034`**：
  - `technician_sessions` 加 `space_id`（服务的房间，引用 `spaces`，可空）与部分索引（记了房间、还没结束的钟单）；已有的钟单为空。
  - `technician_events.kind` 的约束放宽，加 `room`（换房间）。
  - 只加列、加索引、放宽约束；升级后钟单都没有房间，房态图上技师房都是空闲，提成、对账、报表不变。
- **阻断项**：
  - 状态色与房态看板、钟房不一致（例如在住的房画成空闲、服务中的技师房画成空闲），或颜色与图例对不上。
  - 越权：没有「客房」权限的岗位能取 `/api/floormap`；没有客房入住、退房权限的人在平面图上能开房、退房（按钮应不出现，接口照旧拒绝）。
  - 钟单记到非技师服务类、停用、不可售的空间；房间里有没结束的钟单时空间能停用或改成非技师服务业态。
  - 平面图上做的开房、退房、改房态与「客房」页结果不同（金额、押金、房态）。
  - 单层 300 个空间画不完或超过 2 秒；1280×720、平板上用不了（溢出、点不到）。
  - `check` 不是全 ✓；破坏原有客房、钟房、空间台账、底图功能。

## 1. 范围

| 项 | 内容 |
| --- | --- |
| 入口 | 「客房」页顶部「房态看板 / 平面图」切换，地址 `/rooms?view=map`；客房功能开着、看得到「客房」的岗位（客房入住、客房打扫、收银）都能看 |
| 平面图 | 楼层切换（默认编码最多的一层）；在用那一批的底图 + 空间多边形（没配上轮廓的编码画位置点）；编码，放大后写显示名；技师房写「钟单数 / 容量」；图例常显、带个数；台账里有、图上没有的空间列在图下面 |
| 状态 | 见 `docs/ROOMMAP.md` 2.3：空闲 / 在住 / 待上钟 / 服务中 / 待打扫 / 维修 / 未挂接 / 其他业态 / 停用·不可售 / 台账里没有；客房与房态看板同一个口径，技师房按钟单 |
| 筛选与定位 | 业态多选、只看空闲（不符合的变淡）；搜编码、显示名、别名，回车定位（换层、放大、居中、闪几下、打开侧栏） |
| 缩放平移 | 滚轮（以鼠标为中心）、双指、拖动；「缩小」「放大」「适应屏幕」；1–12 倍 |
| 刷新 | 状态与客房房态每 5 秒；底图与轮廓只取一次，启用了新的一批自动换 |
| 点房间 | 客房：开房 / 查房 / 续住 / 换房 / 押金 / 退房 / 改房态（打扫好了、维修好了），都是「客房」页原来的对话框；技师房：房里的钟（技师、手牌、项目、上钟时间、剩几分钟），「去钟房」；其他：业态、楼层区域、容量、面积、别名 |
| 钟房 | 派钟对话框「房间（可不选）」：在用、可售的技师服务类空间按楼层分组、写占用；钟单卡片显示房间，点开换房间 / 补选 / 清掉（带上看到的房间，对不上 409 `SESSION_SPACE_STALE`），记钟房日志 |
| 接口 | `GET /api/floormap`（空间台账的空间 + 记了房间、没结束的钟单 + 在用底图批次；`room.operate` / `room.housekeep` / `frontdesk.checkout` 任一）；`GET /api/clockroom/spaces`（可选的技师房与占用，`technician.dispatch`）；`POST /api/clockroom/sessions/:id/space`（`{ spaceId, expectedSpaceId }`，`technician.dispatch`）；派钟 `POST /api/clockroom/dispatch` 可带 `spaceId`；`GET /api/rooms` 的房间带 `spaceId`；钟房看板的钟单带 `space` |
| 拒绝 | 派钟、换房间到不是技师服务类的空间 422 `SPACE_NOT_SERVICE`，停用 409 `SPACE_INACTIVE`，不可售 409 `SPACE_NOT_SELLABLE`，不存在 404；同一个操作编号换了房间重发 409 `IDEMPOTENCY_CONFLICT`；空间台账停用或改业态时房间里有没结束的钟单 409 `SPACE_HAS_SESSIONS` |
| 自检 | `check` 加一项「钟单记的房间是在用的技师服务类空间」（比 v0.7.15 多一项） |
| 其他修正 | 入住单对话框一打开就要做的操作（续住、换房、押金、退房）等入住单先挂上再打开，子对话框不再被压在下面（入住单已经缓存过时会这样，原来的「去处理」也可能碰到） |
